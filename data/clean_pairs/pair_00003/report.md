年修改单二级标准限值外，其余五项基本污染物指标浓度均能达到《环境空气质量标准》（GB3095-2012）及 2018 年修改单二级标准限值；地表水顺德支流各项水质指标均达到《地表水环境质量标准》（GB3838-2002）Ⅲ类标准。 本项目生活污水经三级化粪池处理，然后通过槽车运至杏坛生活污水处理厂处理，尾水排入顺德支流。配料、混料粉尘经集气罩收集后通过布袋除尘设施进行处理，然后通过排气筒 G1（15m）引至楼顶排放；挤出、检测废气经集气罩收集后通过沸石转轮吸附浓缩+催化燃烧废气处理设施进行处理，然后通过排气筒 G2（15m）引至楼顶排放，以上废水废气均可达标排放，因此本项目的建设不会突破当地环境质量底线。 综合分析，本项目的建设不会突破当地环境质量底线。 # 资源利用上线： 本项目运营期所用的资源主要为水资源、电能、石油气。 有机废气经过沸石转轮吸附，沸石是一种硅铝酸盐矿物质材料，具有丰富的空隙结构，最早是作为干燥剂材料用于保持食品的干燥，后经技术研究开发出疏水性沸石， Si/AI 比值较高的适用于无极性或弱极性有机的吸附，其相对于活性炭吸附材料具有极大的优势。 图 4-1 沸石转轮吸附装置吸附效率对比 本工艺处理优势：①分子筛吸附效率可达 90%，采用双层吸附吸附效率可达 95%；②分子筛采用玻璃纤维作为载体，具有更高耐温性能，脱附气体温度可 180℃\~200℃，从而可脱附包含高沸点的酮类有机物；③分子筛具有高达 5\~7 年的使用寿命。 沸石转轮吸附装置包括壳体、组合式分子筛、分子筛固定转轮框架、驱动系统、脱附气道等。工作原理是：有机废气经风机输送进入转轮吸附区，废气经过分子筛时有机物被吸附到分子筛微孔中，达标气体通过排气通道排入烟囱；随着转轮的慢慢转动，当吸附区分子筛达到设定的吸附量时，其中一个分区进入脱附区，导入 180℃\~200℃热空气经过脱附气道对吸附在分子筛微孔中的有机物进行脱附，脱附出来的含有有机物带温高浓度气体被送入 RCO装置处理。 # （2）催化燃烧（RCO）设备原理： 催化燃烧装置内设加热室，启动加热装置，进入内部循环。当热气源达到有机物的沸点时，有机物从吸附剂内解吸出来，进入催化室进行催化分解成 $\mathrm { C O } _ { 2 }$ 和 $\mathrm { H } _ { 2 } \mathrm { O } ;$ ，同时释放出能量。利用释放出的能量再进行脱附，加热装置完全停止工作，有机废气在催化燃烧室内维持自燃，循环进行，直至有机物完全从吸附剂内部分离，至催化室分解，吸附剂得到了再生，有机物得到催化分解处理。 $$ C _ {n} H _ {m} + \left(n + \frac {m}{4}\right) O _ {2} \xrightarrow {\text {催化剂，加热}} n C O _ {2} \uparrow + \frac {m}{2} H _ {2} O \uparrow + \text {热量} $$ 废气在吸附风机产生的负压收集作用下，先利用吸附装置对废气中有机物进行连续吸附。吸附装置内沸石转轮吸附饱和后，控制系统自动打开脱附阀门，通过脱附风机用 $1 2 0 ^ { \circ } \mathrm { C } \cdot$ 热风进行脱附（催化燃烧装置到吸附装置间设有阻火器，防止热风输送时带有火焰燃烧到吸附装置），利用热风吹脱作用将低浓度有机废气浓缩成高浓度废气，最后经催化燃烧将有机气体转换成 CO 和 H O，净化后高温气体通过列管热交换器预热脱附气体，少部分经排气筒排放，其余补充新鲜空气后作为脱附热风返回。停止电加热管预热，通过放空阀和补冷风机来实现整个催化燃烧系统热平衡。为保证系统的连续运行，吸附装置采用多单元组合式结构，正常运行时，处在脱附状态的只有一个单元，而其它单元处于吸附或冷却状态。沸石转轮吸附浓缩+催化燃烧（RCO）对有机废气的净化效率可达 80%。 本项目采用的废气处理设施为《排污许可证申请与核发技术规范 橡胶和塑料制品工业》(HJ1122—2020)“表 7 简化管理排污单位废气产污环节、污染物种类、排放形式及污染防治设施一览表”可行性技术中的“吸附、催化燃烧”，故本项目废气治理设施可行。 # 1.5环境监测 根据《排污单位自行监测技术指南 橡胶和塑料制品》（HJ1207-2021），本项目运营期废气污染源自行监测计划如下表 4-9所示。 # 5.3 风险影响分析 # 1）火灾事故后果分析 当原材料使用和管理不善，生产过程中原材料出现大量泄漏而遇火源时可能产生火灾。火灾事故散发的烟气对周围大气直接造成影响。原材料现场火灾扑救主要采用干粉，大的火灾扑救产生消防水可能进入内河涌对水体造成危害。消防废水中含有塑料、色母，但考虑到本项目使用及储存的原料量较少，因此消防废水其进入水体后，不会对周边水环境造成危害。项目的火灾事故风险可控。 # 2）危险废物泄漏 危险废物暂存处废液出现大量泄漏时，可能进入水体，对环境造成危害。类比顺德同类型的企业安全管理，在加强管理和采取措施情况下是风险是可控的。 # 3）环保设施失效 项目生产废气的处理设施失效，可能造成废气未经处理直接排放，造成事故排放，危害人体健康及对空气造成污染。发生事故时，应立即停止生产并检查废气处理设施，在加强管理和采取措施情况下是风险是可控的。 # 5.4 风险控制措施建议
