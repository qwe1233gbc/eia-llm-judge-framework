热洁炉能高效、安全地洗涤在挂具附着的漆层。热洁炉又名在碳化炉、脱漆炉，是一种清理涂装线上的返工件及挂具上涂层的新型专用设备。首先，工件装在装载车上，由人力把装载车送入炉内，关好炉门，由热洁炉按程序全自动处理完成。热洁炉由两个相对独立的加热系统以及温度控制系统组成。利用高分子聚合物高于 300度隔绝空气可裂解焦化，高于 400 度在有少量空气可完全氧化的特性，加热系统将炉腔加热到 $4 0 0 \mathrm { { ^ \circ C } }$ 范围内。炉温是阶梯式上升，上升速度由微电脑计算，并由电脑控制，使表面有机物逐步分解成碳氢化合物可燃气体，进入二次废气燃烧系统。当分解物（废气）进入二次燃烧系统经 1000℃\~1100℃燃烧后大部分燃烧成 $\mathrm { C O } _ { 2 }$ 和水蒸气，少部分有机废气未被完全燃烧。炉内剩下的是工件和不受温度影响的无机物。热洁炉燃烧前后没有塑料制品参与燃烧反应，燃烧的漆层主要由水性漆、丙烯酸漆、固化剂、稀释剂组成，涂料成分不含氯原子及铜族化合物。 热洁炉尾气通过引风机将尾气引入热洁炉内的喷淋急冷室急冷，急速热交换 1s 时间冷却到 200℃以下，等炉温降到常温后排出炉外。热洁炉在处理过程中，是高温裂解，不产生明火，是空气热分解形式，不是焚烧，是空气加温，自然冷却，所以不会改变挂具的金属材质，不会产生退火现象。 热洁炉使用天然气作为燃料。燃烧完成后燃烧机就会自动关闭，但这时炉温较高，等炉温低于200℃时再打开炉门，加快降温速度。温度降下后推出小车，轻轻敲打挂具，热洁炉燃烧后产生的废渣（无机物）就会掉下，经收集后交给回收公司回收处理。 项目扩建后汽车门板生产工艺流程图（新增）： 图 2-5 项目扩建后汽车门板生产工艺流程图 项目汽车门板生产工艺流程图（新增）： 将外购的 ABS、PP 2个，分别为底漆房、面漆房，喷涂线采用机械手自动喷涂，每个漆房均设有一台机械手；喷涂线另外设有 2 个漆房对应的 2 个流平室以及烘干炉1个；还设有 1个调漆房。 在喷漆前先人工进行调漆，在喷漆前，先打开油漆桶，调丙烯酸漆时按比例（油漆：稀释剂：固化剂=1:0.5:0.1）加入稀释剂和固化剂，油漆经充分搅拌均匀后倒进调漆缸中，按比例调配后的油漆经密闭管道进入对应漆房的机械手。水性漆不需要进行调漆，但同样经过调漆房的漆缸经密闭管道进入对应漆房的机械手。建设单位需要喷漆的汽车内饰配件、汽车外饰配件需喷两道漆，根据客户需要，底漆和面漆均选用丙烯酸漆或均选用水性漆。工件通过人工上挂，经输送带送到喷涂室，首先经人工于喷涂线一侧检查工件表面有无杂质或工件悬挂稳妥否。然后工件输送到喷漆房，随着工件在输送带上的移动，机械手对工件喷上底漆；机械手利用气压将涂料雾化喷出，从而使涂料均匀地涂覆在工件表面。底漆喷涂完成后，工件随输送带进入流平室，流平的作用是使喷漆后喷在材料表面上的漆滴摊平，以防止在烘烤时漆膜上出现针孔。经过约 15min 的流平后，工件输送到面漆房，继而进行面漆喷涂、面漆流平工序。最后经流平后进入烘干炉，工件在$8 0 \pm 5 ^ { \circ } \mathrm { C }$ 下烘烤约 45min，烘干炉配套的燃烧机使用天然气为燃料。烘干结束后，工件输送到强冷室，经冷却后人工下挂进行检查即为成品。 喷漆过程产生的废气含有漆雾和有机废气，调漆、流平、烘干过程产生有机废气，项目喷涂线为连续生产线，整条喷涂线密闭，采用整室收集方式收集喷涂废气，项目使用“水帘机+过滤棉+蓄热式氧化器（RTO系统）”装置处理自动喷涂线漆雾和有机废气，废气经处理后通过15m 高排气筒G4排放。 项目调漆、喷漆、流平、烘干过程均会产生产生有机废气（VOCs、二甲苯），其中喷漆工序还会产生漆雾。项目自动喷涂线有燃烧机 3台，烘干炉、RTO 治理设施、常压热水炉（常压热水炉用于调节自动线车间内室温温度，为自动线通过换热、调节室温等功能提供合适的作业温度。）各配套 1台燃烧机，燃烧机均使用天然气为燃料，天然气燃烧产生 NOX、SO2等。喷涂线对调漆房、漆房、流平室、烘干炉以及 RTO 系统燃烧机、烘干炉燃烧机、常压热水炉燃烧机产生的废气进行收集。项目两个漆房分别配套一台水帘机和一个过滤棉装置除漆雾，过滤棉装置由多层过滤棉组成；含气溶胶（漆雾）的有机废气先后经水帘机（两台水帘机共用一个循环水池，水池尺寸为 8m\*3.4m\*2.2m）和过滤棉去除漆雾后，再与喷涂线调漆、流平、烘干工位以及 RTO 系统产生的废气经喷涂线内循环；喷涂线启动运作时，RTO 系统即处于开启状态，当 RTO 系统氧化室预热至设定的氧化温度时，废气即经抽风系统引至 RTO 系统处理，经处理后再通过 15m高排气筒DA004 排放。 根据自动喷涂线设计参数及建设单位提供资料，自动喷涂线采用自循环送排风结构，处理风量为 6000m3/h。 喷胶粘合：部分汽车内饰配件、汽车外饰配件根据客户要求用喷胶机粘合工件表面，再用通过干燥流水线电加热 40℃干燥烘干。门板车间共设有 5台喷胶机和 5条干燥流水线，每台喷胶机配套一条干燥流水线使用。 超声波焊接：少部分配件根据工艺特殊要求用超声波焊接焊接成型，使用次数极少。超声波焊接是利用高频振动波传递到两个需焊接的物体表面，在加压的情况下，使两个物体表面相互摩擦而形成分子层之间的熔合。焊头将接收到的振动能量传递到待焊接工件的接合部，在该区域，振动能量被通过摩擦方式转换成热能，将塑料熔化。一旦塑料开始熔化，运动就停止，两个工件的焊接部分将凝固并牢牢的连接在一起。超声波焊无需外加填充焊丝和焊剂，当被焊接材料焊接部位表面处理洁净时，没有焊接烟尘产生。接触面塑料熔化过程会产生非甲烷总烃，但由于项目超声波焊接频率较低，焊接时间极短，焊接面积极小，产生非甲烷总烃量极小，本项目仅作定性分析。 # 7.2、环境风险防范措施 为了避免仓库、危险废物贮存场所、火灾爆炸等事故造成不良环境影响，本项目采取以下风险控制措施： （1）项目仓库、危险废物暂存处需做硬化、防淋、防渗、防泄漏处理，并在仓库、危险废物暂存处位置周围设置截流沟或围堰，确保发生事故时，泄漏的机油、水性胶水、废机油、油水分离废液、检测废液、废胶水及清洗泄漏机油、水性胶水、废机油、油水分离废液、检测废液、废胶水时产生的废水能完全被收集。 （2）项目仓库、危险废物暂存处应设置在阴凉处，远离热源、火源，并设置为禁烟区。建设单位应按照消防部门的相关要求设置灭火器、消防栓等，消防措施须经相关部门验收合格，并定期检查消防器材的性能及使用期限。 （3）必须定期检查仓库内机油包装桶存放情况及危险废物贮存场所内危险废物的暂存情况，避免机油包装桶破裂引起机油泄漏，以备在发生化学品泄漏和危险废物泄漏时能及时得到控制。 （4）建立健全环境管理制度，防止类似事故发生。运营过程中加强监督检查，做到及时发现，立即处理，避免污染。 （5）建立环境风险应急预案，开展环境应急预案的培训、宣传和必要的应急演练。根据《佛山市生态环境局关于危险废物产生单位突发环境事件应急预案备案的指导意见（试行）》的通知》，本项目应按照《佛山市企业事业单位突发环境事件应急预案备案管理实施办法》（佛环〔2019〕140 号）要求编制企业环境应急预案，并向相应生态环境部门备案。 # 7.3、环境风险分析结论 建设单位应严格按照消防及安监部门的要求，做好防范措施，设立以建设单位为环境风险责任主体的突发环境事故应急组织机构，以便采取更有效的措施来监测灾情及防止污染事故的进一步扩散。在采取有效措施的情况下，项目风险事故发生概率很低，本项目环境风险在可接受的范围内。 五、环境保护措施监督检查清单
