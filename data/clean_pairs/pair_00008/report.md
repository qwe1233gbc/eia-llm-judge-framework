项目位于佛山市顺德区勒流街道办事处东风村勒流港集约工业开发区4-1-1号地块厂房之二，周边无自然保护区；根据广东省人民政府关于印发《广东省“三线一单”生态环境分区管控方案的通知》（粤府〔2020〕71号），《佛山市人民政府关于印发佛山市“三线一单”生态环境分区管控方案的通知（佛府[2021]11号）》、《佛山市顺德区人民政府关于印发佛山市顺德区“三线一单”生态环境分区管控方案的通知》（顺府发[2021]11号）的勒流街道生态保护红线单元可知，本项目不在生态保护红线范围内，故本项目的建设符合生态保护红线的要求。 # 理化性质分析 PMMA：有机玻璃(Polymethylmethacrylate)是一种通俗的名称，缩写为 PMMA。此高分子透明材料的化学名称叫聚甲基丙烯酸甲酯，是由甲基丙烯酸甲酯聚合而成的高分子化合物。是一种开发较早的重要热塑性塑料。有机玻璃分为无色透明，有色透明，珠光，压花有机玻璃四种。有机玻璃俗称亚克力、中宣压克力、亚格力，有机玻璃具有较好的透明性、化学稳定性，力学性能和耐候性，易染色，易加工，外观优美等优点。有机玻璃又叫明胶玻璃、亚克力等。 色粉：一般包括树脂成分、合成助剂、无机填料，有良好的色彩性能及耐热性易分散性、耐候性、耐迁移性、无毒性、耐化学药品性。 润滑油：即机油，英文名称：Engineoil。密度约为0.91×103（kg/m³）能起到润滑减磨、辅助冷却降温、密封防漏、防锈防蚀、减震缓冲等作用。润滑油由基础油和添加剂两部分组成。基础油是润滑油的主要成分，决定着润滑油的基本性质，添加剂则可弥补和改善基础油性能方面的不足，赋予某些新的性能，是润滑油的重要组成部分。 # 5、劳动定员及工作制度 # # 佛山市生态环境局关 # 科技有限公司新建项目环境影响报告表的批复 # 佛山市顺德区久新光电科技有限公司新建项目竣工环境保护验收意见 根据国家有关环境保护法律法规、《建设项目竣工环境保护验收暂行办法》《广东省环境保护厅关于转发[建设项目竣工环境保护验收暂行办法]的函》（粤环函[2017]1945号）、佛山市环保局关于转发省环境保护厅《关于转发环境保护部<建设项目竣工环境保护验收暂行办法>的函》的通知（佛环[2018]79号）、建设项目竣工环境保护验收技术规范、本项目环境影响报告文件和审批意见等要求，佛山市顺德区久新光电科技有限公司编制了《佛山市顺德区久新光电科技有限公司竣工环境保护验收报告》（以下简称“验收报告”）。 2020年6月16日，建设单位佛山市顺德区久新光电科技有限公司组织该项目的验收会议，对项目进行环境保护设施验收，验收工作组审阅了（验收报告》并对项目现场及项目环保设施进行了现场查验，经充分讨论，提出如下验收意见。 # 一、工程建设基本情况 # （一）建设地点、规模、主要建设内容 项目名称：佛山市顺德区久新光电科技有限公司新建项目 建设地址：佛山市顺德区杏坛镇麦村工业区二区16号 建设性质：新建 建设规模：占地面积约为2300m2，建筑面积约为2300m，主要从事塑料板的制造与销售，预计年生产塑料板1600吨。 主要生产设备：挤压生产线2条（每条生产线上包含1台上料机，1台螺旋挤压器，1台压板机，1台覆膜机，1台栽剪机）、破碎机1台、冷却塔1台、空压机1台、真空泵1台、循环水池1个。 # （二）建设过程及环保审批情况 项目已于2019年10月委托广西钦天境环境科技有限公司编写完成《佛山市顺德区久新光电科技有限公司新建项目环境影响报告表》，并于2019年11月18日取得（佛山市生态环境局关于佛山市顺德区久新光电科技有限公司新建项目环境影响报告表的批复》（佛环0310环审[2019]第0274号）。 项目于2019年12月20日竣工建设完成，并于2020年03月13日至2020年05月26日进行项目竣工调试并公示。根据《建设项目环境保护管理条例》等规定，建设项目需要进行峻工环境保护验收。因此佛山市顺德区久新光电科技有限公司于2020年5月委托佛山市顺德区振延环境检刷有限公司开展验收监工作，并于2020年05月15日至202020年05月16日进行废气，噪声现场监测。 本项目由立项至调试期间均没有产生环境投诉，违法或处罚记录。 # （三）投资情况 项目实际总投资为500万元，其中环保投资10万，占实际总投资2%。 # （四）验收范围 根据《佛山市生态环境局关于佛山市顺德区久新光电科技有限公司新建项目环境影响报告表的批复》（佛环0310环审[2019]第0274号）的相关内容进行现场查勘，针对项目的生产规模及配套环保设施进行验收。 # 二、工程变动情况 佛山市顺德区久新光电科技有限公司新建项目建设后，项目性质、规模、地点、采用的生产工艺和污染防治设施未发生重大变化，项目实际生产设备数较审批有所减少，减少挤压生产线1条（每条生产线上包含1台上料机，1台螺旋挤压器，1台压板机，1台覆膜机，1台载剪机），其余设备数与审批一致。项目实际建设内容与环评报批内容大概一致，不存在重大变动情况。 # 三、环境保护设施建设情况 根据验收调查报告的调查结论： # （一）废水 本项目无生产废水外排，项目载剪工序需要冷却，使用自来水进行冷却，冷却塔冷却水为循环水，定期排水可作为清净下水通过雨水管道排放。项目挤压工序剪使用真空泵对螺款挤压器进行抽真空，期间会将螺旋挤压器的高温气体抽出经管道进入真空票，气体中含有油性物质会因水的吸附力被吸附在真空泵冷却水表面。真空泵循环水池冷却水隔油后循环使用，不外排。隔油产生的废油污定期交由具有相应资质的单位处置 本项目不设饭堂和宿舍，外排废水主要为员工生活污水，生活污水经独立生活污水处理设施处理达到《城镇污水处理厂污染物持放标准》（GB18918-2002）二级标准后排入附近内河涌（东海河） # （二）厦气 本项目挤压过程中会产生一定量的有机废气，主要污染因子为非甲烷总烃。挤压有机废气经集气罩收集后通过UV光解+活性炭吸附处理设施处理后引至15米排气筒（排放口编号为：FQ-13101）排放。逸散都分于车间内无组织排放。本项目塑料板生产工艺中上料和破碎过程会有少量粉尘产生，主要污染因子为粉尘（颗粒物），项目产生的粉尘通过管道收集进入移动式布袋除尘器进行处理，处理后在车间无组织排放。 # （三）声 本项目噪声主要来源于生产设备运行时产生的噪声。本项目通过采取以下措施来减低噪声对周围环境的影响： （1）采用先进的，噪音低、震动小的生产设备： （2）合理安排生产时间，避免在午间（12:00\~14:00）和夜间（22:00-06：00）休息的时候进行生产： （3）对所有设备加强日常管理和维修，确保设备处于良好的运转状态，杜绝因设备不正常运转而产生的高噪声现象： （4）合理布局车间，将高噪声的机械设备布置在远离敏感区的位置： # （四）固体废物 本项目产生的固体废物主要是员工生活垃圾，一般团废、危险废物。 （1）生活垃极交由环卫部门集中清运，处置。 （2）一般固废主要为生产过程会产生的塑料粒和碎属，收集的粉尘和废包装材料，分类收集出售给专业公司回收利用。 本项目产生的危险废物包括废润滑油、废含油抹布、废油桶、废活性炭和废油污，项目设置危险废物放置场所，规范化缓存危废，贮存至一定量后交由有资质的单位处理。 # （五）其他环境保护设施 # （1）环境风险防范措施 本项目已制定了《佛山市顺德区久新光电科技有限公司环境污染事故污染应急预案），具体措施见本项目预案内容。 # （2）在线监测装置 本项目无在线监测装置。 # （3）其他设施 本项目制定了环境保护管理制度，加强生产、安全和环境管理，保证各类生产和环保设施同步正常运转，杜绝污染事件的发生。落实了环境影响报告表提出的各项环保对策要求，使污染物排放得到有效的控制，本项目对周围环境影响较 # 四、环境保护设施调试效果 项目委托山市顺德区振延环境检测有限公司对佛山市顺德区久新光电科技有限公司新建项目进行了废气、噪声的验收监测工作，验收监测期间，项目工作正常，各污染物治理设施正常运行，生产负荷达到设计规模的87.5%，满足验收组织废气颗粒物符合（合成树脂工业污染物排放标准》（GB31572-2015）中表9企业边界大气污染物浓度限值。 # （二）噪声监测结果 项目噪声监测结果满足《工业企业厂界环境噪声排放标准》（GB12348-2008）2类限值。 # 六、验收结论
