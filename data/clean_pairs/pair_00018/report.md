图 2-3 生产工艺流程及产污环节示意图 生产工艺流程简述如下： 投料：根据不同产品需求，将 ABS 塑料粒或HDPE 塑料粒、色粉采用人工投料方式按比例投入混料机（生产 ABS 板不需要使用色粉）。该过程因粉尘逸散产生少量粉尘。 混料：本项目生产ABS 板过程中不需经过混料工序，不需要使用色粉，直接进入挤出工序；生产汽车车顶旅行箱、汽车后备箱垫子的挤出工序前需要先进行塑料与色粉的混料工序，通过混料机对塑料原料及色粉进行混合均匀，同步对物料进行烘干（烘干温度为 60\~80℃），由于混料机于密闭空间内操作，因此无粉尘外溢。该过程产生少量噪声。（由于对物料进行干燥过程的烘干温度较低，不会导致塑料原料挥发成分挥发，该过程不产生有机废气。） 挤出：色粉或塑料原料混合均匀后通过管道进入板材挤出机，将原料加热挤出（加热温度约为 170℃），通过间接冷却后得到半成品。挤出生产过程中板材挤出机配套的水环式真空泵同时对挤出设备内进行抽气减压，目的是去除挤出材料中的气泡和水分，提高产品质量和稳定性，并防止挤出材料在挤出机中的分解或降解。真空泵工作过程会经排放口定期排水（抽出的废气也会同时排出），该部分排水经收集后循环使用于真空泵，并定期更换真空泵内废水交由佛山市顺德区绿点废水回收处理有限公司回收处理，不外排。此过程产生少量有机废气（非甲烷总烃）、真空泵废水、恶臭和噪声。 覆膜：板材挤出后通过板材挤出机使用 PE 膜进行覆膜，以保护板材表面，防止刮花。该过程由于 PE 膜受热产生少量有机废气（非甲烷总烃）、噪声。 剪板：通过剪板机对挤出后的塑料板材根据客户对尺寸的需求进行剪板，剪板后部分进行包装即得成品（ABS 板），入库待售；部分用于后续的吸塑工序。该过程产生少量塑料边角料及噪声。 吸塑：部分挤出并剪板后得到的ABS 板材或HDPE 板材放至原板吸塑机中进行吸塑工序，原板吸塑机将板材加热（加热温度约为 $1 5 0 ^ { \circ } \mathrm { C } )$ 成型至所需形状，并通过自然风干方式对半成品进行冷却。需使用冷却塔间接对设备进行冷却。该过程产生少量有机废气（非甲烷总烃）、恶臭和噪声。 雕刻：吸塑后的半成品通过雕刻机进行雕刻，该过程产生少量塑料粉尘及噪声。（雕刻工作温度为常温，仅由于摩擦生热提高的温度不高，不会导致塑料半成品中的挥发成分挥发，该过程基本不产生有机废气。） 检验：雕刻后的产品进行人工检验，不合格品经破碎及造粒后回用于生产。 包装：检验合格后的产品手工进行包装即得汽车车顶旅行箱或汽车后备箱垫子成品，入库待售。 破碎：生产过程中产生的不合格品或塑料边角料经破碎机破碎后（再经造粒）返回生产使用。此过程产生少量粉尘、噪声。破碎后基本成块状或片状，成块状或片状的物料少量散落地面清扫后回用生产，破碎产生的较少量颗粒粉尘无组织排放。 造粒：破碎后得到的块状或片状的塑料投加进入造粒机（该过程由于原料为非粉状原料，不产生投料粉尘），通过造粒机将原料加热挤出（加热温度为200℃）并切粒，得到 ABS 塑料粒或 HDPE 塑料粒回用于生产。该过程产生少量有机废气（非甲烷总烃）、臭气浓度、噪声。造粒机挤出后的条状半成品进入设备自带的冷却水槽中，通过冷却水对半成品进行直接自然冷却，冷却后的条状塑料经过造粒机的切粒装置剪切成塑料粒，该塑料粒成品作为本项目挤出工序的原材料。冷却水槽的直接冷却水定期更换，更换后委托佛山市顺德区绿点废水回收处理有限公司回收处理，不外排。 ## 2、主要产污环节说明 表 2-11 水环真空泵的工作原理是基于叶轮的旋转和水的离心力作用。泵内部装有带固定叶片的偏心转子，当叶轮旋转时，工作液（自来水）被抛向泵壳内壁，形成与泵壳同心的液环。这个液环与转子的叶片一起，构成了可变容积的旋转变容积真空泵。由于叶轮的偏心安装，液环与叶片之间形成了一个月牙形空间，这个空间随着叶轮的旋转而周期性地变化大小。具体来说：当叶轮从右上方旋转到下方时，两叶片间的空间容积由小逐渐变大，形成真空，从而吸入气体。随后，叶片由最下方向左上方转动过程中，两叶片间的空间容积逐渐由大变小，将吸入的气体压缩。压缩后的气体通过排气口排出泵外。随着叶轮的稳定转动，吸排气过程连续不断地稳定进行，因此可以连续不断地抽取气体。水环真空泵的结构包括泵壳、泵轴、叶轮、配气板等部件。在泵启动前应注入适量的水量，因为工作液（自来水）会随气体排出而减少，所以需连续向泵内补充工作液，以保持内部平衡，避免过多或过少的工作液影响泵的性能。水环真空泵整体结构简单，无需对泵内进行润滑，而且磨损很小，适用于多种工业应用场景。
