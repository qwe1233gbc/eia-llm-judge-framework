📋 数据集概览

本数据集从佛山市环评审批管理平台（达梦 DM8）的 hp_approve_info 和 hp_approve_tech 表中自动提取，覆盖废气治理领域的审批要求与技术审查经验。 每条 QA 对来自真实环评项目的批复意见或专家技术审查记录。

📄 数据格式

JSONL 格式，兼容 Dify、HuggingFace Datasets 等平台直接导入。

字段类型说明
qa_idstring唯一标识（DB_QA_=审批意见 / DB_TECH_=技术审查）
questionstring自然语言问题，含地区、公司、项目类型
answerstring批复要求或审查意见原文
regionstring行政区划（省市镇街）
companystring建设单位名称
project_typestring项目类型（一般项目等）
elementstring要素（废气/废水/噪声等）
review_pointstring审查维度
standards_normalizedarray引用的排放标准列表
approval_evidencearray批复原文证据片段
evidence_alignmentobject证据对齐等级
quality_scoreint数据质量评分（0-100）

🔍 QA 示例

类型 A：审批要求 QA

审批意见 顺德区龙江镇华美家具厂 一般项目
❓ 该项目废气的污染因子、治理设施、排气筒参数和排放标准是什么？
批复要求：原则同意项目环境影响报告表，废气排放执行DB44/27-2001第二时段二级标准，噪声执行GB12348-90二类标准（昼间65dB(A)夜间55dB(A)），其他要求按3-6条执行。

类型 B：技术审查 QA

技术审查 佛山市某塑料制品公司 一般项目
❓ 该项目的废气部分有哪些技术审查意见？
审查结论：原通过
审查意见：1. 核MSDS文件加强原料危化品识别，明确污染物产生环节；2. 细化活性炭吸附装置技术要求；3. 细化水平衡、挥发性有机物平衡。

🚀 使用方式

🔹 直接加载

import json
with open('qa_experience_base.jsonl') as f:
  qas = [json.loads(line) for line in f]
print(f"Loaded {len(qas)} QA pairs")

🔹 转换为 HuggingFace Dataset

from datasets import load_dataset
ds = load_dataset(
  'json',
  data_files='qa_experience_base.jsonl',
  split='train'
)

🔹 导入 Dify 知识库

在 Dify 中创建知识库 → 导入已有文档 → 选择 qa_experience_base.jsonl → 分段模式选「通用」→ 索引方式选「高质量」→ 检索模式选「混合检索」
