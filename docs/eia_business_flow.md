## 你的智能审核在流程中的位置

```
企业申报 → 资料准备 → 技术审查 → 审批流转 → 出具批复 → 后续管理
                          ↑
                    ┌─────┴──────┐
                    │  智能审核    │  ← 你的系统在这里
                    │  (AI辅助审查) │
                    │  11条规则     │
                    │  RAG知识库    │
                    │  问题清单     │
                    └─────────────┘
```

你的 **11条规则 Dify 工作流** 处于 **技术审查环节**，具体对应的是 `hp_approve_tech` 这个阶段——在审批人员（经办人）正式审报告之前或同时，用 AI 快速扫描 11 个审核点，生成问题清单辅助人工判断。
