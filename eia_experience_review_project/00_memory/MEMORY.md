## 研究主题

面向环评智能审核的领域经验库构建方法研究。

## 核心科学问题

历史审核经验能否被结构化，并提升低经验审核者关键问题识别能力。

## 当前聚焦行业

C2929 塑料零件及其他塑料制品制造，尤其是塑料注塑类报告表。

## 经验库定位

不是自动审批，而是辅助小白经办人发现高风险审核点。

## 证据等级策略

| 等级 | 定义 | 使用方式 |
|------|------|---------|
| A级 | 有明确法规/标准/地方文件支撑 | 可作为强规则 |
| B级 | 多个历史案例支持，需人工复核 | 作为强提示 |
| C级 | 单个案例或观察性归纳 | 只作为人工关注项 |

## 当前重点案例

佛山市盛之强电器有限公司建设项目（C2929，注塑，顺德大良）

## 关键路径

```text
原始报告 → MinerU/Word解析 → 结构化字段抽取 → 经验规则触发 → 审核流程标注 → 人工复核 → 规则迭代
```

## 禁止事项

1. 不覆盖原始文件
2. 不把 C 级规则当确定性规则
3. 不输出"合格/不合格"而不给证据
4. 不把经验库等同于标准库
5. 不把终审报告结论直接当事实
