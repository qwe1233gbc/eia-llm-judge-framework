# 环评报告经验库辅助审核 Skill

## 使用时机

当用户上传或指定一份建设项目环境影响报告表，并希望模拟政府环评经办人进行初审时，使用本 Skill。

## 核心原则

1. **不直接输出"通过/不通过"**——只输出审核关注路径和风险提示
2. **按真实经办人审核流程逐步审查**——跳读，不顺序读完
3. **所有问题必须对应**：报告位置 + 依据来源 + 经验规则
4. **严格区分证据等级**：
   - **A级**：可作为自动规则或强约束提示
   - **B级**：只能作为"建议复核"，不能直接判错
   - **C级**：只能输出"人工关注项"，绝对不能作为确定性结论
5. **输出必须区分**：确定问题 / 疑似问题 / 人工复核项
6. **不得把终稿报告中的自我结论直接当成事实**——必须核正文、表格、附图、附表一致性

## 审核流程（20步经办人跳读路径）

### 阶段一：项目身份与空间准入（S01-S04）

#### S01 项目身份审查
- **报告位置**：一、建设项目基本情况（基本情况表）
- **核查内容**：
  - 项目名称 ↔ 营业执照一致性
  - 行业类别代码（C2929）是否正确
  - 环评类别（报告表/报告书/登记表）是否正确
  - 建设性质（新建/改扩建/技改）
  - 环保投资占比是否合理
- **触发经验规则**：EXP_RULE_C2929_* (按 `project_type` 匹配)
- **输出**：项目名称、行业代码、建设性质 → 确定适用的规则子集

#### S02 报告类型与专项评价审查
- **报告位置**：基本情况表 R06, R11
- **核查内容**：
  - 是否首次申报
  - 专项评价设置是否正确
  - 是否适用告知承诺制
- **依据**：佛环〔2019〕142号、《建设项目环境影响评价分类管理名录（2021年版）》

#### S03 经纬度与三线一单审查
- **报告位置**：基本情况表 R04, R15；附图11-13
- **核查内容**：
  - 坐标是否落入声明的管控单元 → **用三线一单库 (#4_三线一单_顺德管控单元_完整.json) 交叉验证**
  - 是否涉及生态红线
  - 是否逐条对应管控单元的具体管控条款（不仅是"三线"层面）
  - 环境准入负面清单是否逐条对照
- **触发经验规则**：EXP_C2929_SPATIAL_001(A)
- **风险**：管控单元错误、遗漏限制类条款
- **是否需要人工**：是（需GIS/平台核验）

#### S04 规划与规划环评符合性审查
- **报告位置**：基本情况表 R12-R14
- **核查内容**：
  - 规划文件名称和文号是否齐全
  - 规划环评文件名称和审批机关是否明确
  - 是否符合产业准入、空间布局、缓冲距离要求
- **依据**：控规文件 + 规划环评批复

### 阶段二：环境现状与敏感目标（S05-S06）

#### S05 功能区划和环境质量现状审查
- **报告位置**：三、区域环境质量现状（表4 R00-R01）
- **核查内容**：
  - 水/大气/声功能区划是否正确
  - 环境质量公报引用年份是否为最新
  - 是否达标区——如不达标区，是否提出削减替代方案
  - 是否引用项目所在区域的现状监测数据
- **触发经验规则**：EXP_C2929_AIR_002(A)
- **风险**：不达标区未提削减方案、引用过期数据
- **是否需要人工**：是（功能区划需GIS确认）

#### S06 敏感点识别审查
- **报告位置**：表4 R01；附图9
- **核查内容**：
  - 厂界500m大气敏感点是否漏判
  - 厂界50m声敏感点是否漏判
  - 500m内有无饮用水源保护区
- **是否需要人工**：是（需实地或GIS确认）

### 阶段三：工程分析与产污识别（S07-S09）

#### S07 工程组成审查
- **报告位置**：二、建设项目工程分析 → 项目工程组成表
- **核查内容**：
  - 设备清单是否完整（注塑机数量、辅机、维修设备）
  - 产品方案是否明确（规格、产量）
  - 原辅材料年用量是否完整列出
- **风险**：原辅料用量缺失、设备清单不完整

#### S08 产能与物料平衡审查
- **报告位置**：工程分析 → 产品方案表+原辅材料表
- **核查内容**：
  - 产品产量+边角料+次品 = 原料用量 是否闭合
  - 边角料比例是否在行业典型值（注塑3-5%）范围内
  - 设备理论产能与实际产量是否匹配
- **触发经验规则**：EXP_C2929_MATBAL_001(B)
- **风险**：原料用量缺失、边角料比例异常（>8%）

#### S09 工艺流程与产污环节审查
- **报告位置**：工艺流程和产排污环节
- **核查内容**：
  - 各工序污染物是否完整识别
  - 产污节点图是否与实际工艺对应
  - 模具维修工序 → 废切削液(HW09)是否识别
  - 机加工工序 → 金属粉尘+金属边角料是否识别
- **触发经验规则**：EXP_C2929_PROC_003(A)
- **风险**：遗漏废切削液、遗漏含油金属屑

### 阶段四：源强与治理设施（S10-S13）

#### S10 执行标准适用性审查
- **报告位置**：表4 R02 嵌套表
- **核查内容**：
  - 所有排放标准是否引用最新版本
  - 厂区内VOCs无组织标准（DB44/2367-2022）是否遗漏
  - GB31572-2015是否含2024年修改单
- **依据**：标准条款库 (`standard_clause_library_from_reports.jsonl`)

#### S11 废水源强与排放去向审查
- **报告位置**：表5嵌套表
- **核查内容**：
  - 生活污水量核算是否正确（人数×天数×定额）
  - 纳管标准和污水厂是否明确
  - **间接冷却水排雨水管网是否符合顺德区口径**
- **触发经验规则**：EXP_C2929_WW_001(B)
- **是否需要人工**：是（地方口径确认）

#### S12 废气源强与治理设施审查
- **报告位置**：表6嵌套表
- **核查内容**：
  - 产污系数是否适用于本行业/本工艺
  - NMHC产生量、收集量、有组织排放量、无组织排放量是否闭合
  - 收集效率取值是否与实际集气设施条件一致
  - 设计风量是否由罩口尺寸/距离/风速推算
- **触发经验规则**：EXP_RULE_C2929_废气_新建(A) + EXP_RULE_C2929_废气_扩建/迁建(C)

#### S13 活性炭治理设施参数审查（★顺德重点）
- **报告位置**：表7嵌套表 + 风量核算表
- **核查内容**（按佛环函〔2024〕70号逐条）：
  - 活性炭类型（蜂窝炭/柱状炭）+ 碘值（≥800mg/g）
  - 过滤风速（蜂窝炭≤0.6m/s / 柱状炭≤0.4m/s）
  - 停留时间（≥0.5s）
  - 年用炭量核算
  - 废活性炭量 = 年用炭量 + 吸附量
  - **参数接近边界值时是否标注风险**
- **触发经验规则**：EXP_C2929_AC_001(A)
- **风险**：碘值不足、参数接近边界、废炭量核算错误

### 阶段五：专项审查（S14-S17）

#### S14 噪声审查
- **报告位置**：表5运营期
- **核查内容**：声功能区类别、厂界达标、治理措施
- **触发经验规则**：EXP_RULE_C2929_噪声_*(A/C)

#### S15 固废和危废审查
- **报告位置**：表10 + 表8 R10
- **核查内容**：
  - 危废名称、代码、产生量是否正确
  - 废切削液(HW09)是否遗漏（配合S09）
  - 废活性炭量是否闭合（配合S13）
  - 危废暂存能力和贮存周期
- **触发经验规则**：EXP_C2929_PROC_003(A) + EXP_RULE_C2929_危废_*(C)

#### S16 环境风险审查
- **报告位置**：表8 R13
- **核查内容**：
  - Q值（危险物质数量与临界量比值）是否计算
  - 雨水截止阀是否设置
  - 消防废水截留措施

#### S17 排污许可、验收、监测审查
- **报告位置**：表8 R14
- **核查内容**：排污许可管理类别、自行监测计划、验收要求
- **触发经验规则**：EXP_RULE_C2929_环境管理_*(C)

### 阶段六：一致性与完整性（S18-S20）

#### S18 附图附件完整性审查
- **核查内容**：营业执照、法人身份证、土地/厂房证明、排水证、原辅材料MSDS、环评合同
- **风险**：缺少土地证明

#### S19 附表与全文一致性审查
- **核查内容**：
  - 附表 vs 正文 污染物排放量是否一致
  - 废气、废水、固废、危废逐项对照

#### S20 批后监管与监督检查清单审查
- **报告位置**：表8
- **核查内容**：是否覆盖全部污染物、治理设施、排放标准、监测计划、排污许可、验收、台账

## 输出格式

完成审核后，输出以下五个部分：

### 1. 项目画像
```json
{
  "project_name": "",
  "location": "",
  "coordinates": "",
  "industry_code": "C2929",
  "process": [],
  "key_pollutants": [],
  "review_modules_with_risk": []
}
```

### 2. 经办人审核流程标注表

| 步骤 | 报告位置 | 抽取证据 | 核查问题 | 命中经验规则 | 风险等级 | 需人工复核 |
|------|---------|---------|---------|------------|---------|----------|
| S01 | ... | ... | ... | EXP_xxx | 🟢🟡🔴 | 是/否 |

### 3. 风险问题清单

| 编号 | 问题类型 | 问题描述 | 报告位置 | 判断依据 | 证据等级 | 修改建议 |
|------|---------|---------|---------|---------|---------|---------|

### 4. 人工复核项

列出模型不能直接判断、需要 GIS、实地踏勘、地方系统、专家确认的内容。

### 5. 经验库迭代建议

指出哪些规则需要新增、升级（C→B/B→A）、降级（A→B）或人工复核。

## 禁止行为

1. ❌ 不允许输出"合格/不合格"而不给证据
2. ❌ 不允许把 C 级规则当成确定性规则
3. ❌ 不允许直接覆盖原始报告文件
4. ❌ 不允许只给总结不给文件路径
5. ❌ 不允许把终审报告中的结论直接当成事实
6. ❌ 不允许跳过人工复核项直接下结论
7. ❌ 不允许把经验库等同于标准库
