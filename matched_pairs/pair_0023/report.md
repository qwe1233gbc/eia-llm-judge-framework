## 1.产业政策相符性分析

本项目属于“C3854 家用厨房电器具制造”行业，主要从事热波炉、光波烤炉、光波炉、多功能电锅、暖奶器生产销售，项目不涉及喷漆和电镀工艺；不涉及以再生塑料为原材料。则项目不属于国家《产业结构调整指导目录（2019年本）》（2021 年修改版）中的限制或淘汰类别，根据《促进产业结构调整暂行规定》（国发〔2005〕40 号）第十三条，项目属于允许类，且项目不属于《市场准入负面清单（2022 年版）》中所列行业，本项目生产的塑料制品为家电塑料外壳工件，不属于《广东省发展改革委 广东省生态环境厅关于印发<广东省禁止、限制生产、销售和使用的塑料制品目录>（2020 年版）的通知》（粤发改资环函〔2020〕1747号）中“一、禁止生产、销售的塑料制品”，则项目符合相关的产业政策要求。

## 2.用地规划相符性分析

本项目选址于佛山市顺德区均安镇均安社区居民委员会百安南路 280号，根据项目经营场所房地产权证（详见附件 2）及控制性详细规划图（详见附图 9），项目所在地为工业用地，与本项目的实际用途相符合，没有占用基本农业用地和林地，因此，本项目建设选址符合建设用地规划性质要求。

## 3.“三线一单”符合性分析

（1）与“三线一单”生态环境分区管控方案分析

根据《广东省人民政府关于印发广东省“三线一单”生态环境分区管控方案的通知》（粤府〔2020〕71 号，2020 年 12 月 29 日）、《佛山市人民政府关于印发佛山市“三线一单”生态环境分区管控方案的通知》（佛府〔2021〕11 号，2021年 7 月 5 日）、《佛山市顺德区人民政府关于印发佛山市顺德区“三线一单”生态环境分区管控方案的通知》（顺府发〔2021〕11 号，2021年 11月 24日），本项目与各级“三线一单”生态环境分区管控方案相符性分析如下：

a.项目位于珠三角核心区，本项目所用能源均为电能，不涉及高污染燃料的使用，本项目主要从事热波炉、光波烤炉、光波炉、多功能电锅、暖奶器生产销售，不属于区域布局管控要求中的禁止新建、扩建水泥、平板玻璃、化学制浆、生皮制革以及国家规划外的钢铁、原油加工等项目。项目涉及含VOCs物料为ABS粒料、PC 粒料、PP 粒料、色粉，不属于高挥发性有机物原辅材料，则本项目不属于新建生产和使用高挥发性有机物原辅材料的项目，符合区域布局管控要求。

b.本项目所用能源均为电能，不属于“高污染、高能耗”项目，本项目用水全部采用市政直供，不直接取用江河湖库水量，不会对项目所在地生态流量造成

影响，符合能源资源利用要求。

c.本项目挥发性有机物总量控制指标为 0.192t/a，项目挥发性有机物总量控制指标实行倍量削减替代（减二增一），本项目外排废水主要为员工生活污水，生活污水经三级化粪池预处理后经市政污水管网引入均安污水处理厂处理，处理后尾水排入海洲水道，则本项目水污染物总量控制指标计入均安污水处理厂的总量控制指标内，不再另设污水总量控制指标，则本项目废水排放方式为间接排放，不向河涌直接排放废水，项目不排放重金属污染物，不属于陶瓷、有色金属等重点能源消耗行业，则项目符合污染物排放管控要求。

d.项目位于佛山市顺德区均安镇均安社区居民委员会百安南路 280 号，不属于惠州大亚湾石化区、广州石化、珠海高栏港、珠西新材料集聚区等石化、化工重点园区等环境风险防控区域，不涉及西江、北江等供水通道干流沿岸以及饮用水水源地、备用水源环境风险防控区，不涉及西江、北江等供水通道干流沿岸以及饮用水水源地、备用水源环境风险防控区。项目不属于危险化学品生产、储存建设项目，不含低温等离子、UV 光解、RTO 燃烧炉等有机废气治理设施。项目产生的危险废物由专门容器收集后暂存于危废贮存间内，定期交由有相应资质的单位处理处置，并通过信息系统登记转移计划和电子转移联单，符合危险废物全过程跟踪管理的防控要求。

e.根据《佛山市人民政府关于印发佛山市“三线一单”生态环境分区管控方案的通知》（佛府〔2021〕11 号，2021 年 7 月 5 日）、《佛山市顺德区人民政府关于印发佛山市顺德区“三线一单”生态环境分区管控方案的通知》（顺府发〔202111 号，2021 年 11 月 24 日），项目所在地位于均安镇一般管控区（ZH44060630002），执行区域生态环境保护的基本要求。

主要原辅材料说明：

①ABS 粒料：化学名称丙烯腈-丁二烯-苯乙烯塑料。系丁二烯、丙烯腈及苯乙烯接枝共聚物，其中丁二烯呈微粒状均匀分布于丙烯腈-苯乙烯共聚物基体中；市售产品含丙烯腈20%\~30%，丁二烯 6%\~35%，苯乙烯 45%\~75%。综合性好但不耐气候老化。拉伸强度23\~55Mpa，弯曲模量 890\~3030Mpa，悬臂梁缺口冲击强度 64\~640J/m。主要用作电子电器、汽车零件、外壳及管件等，还可用于制造多种塑料合金。本项目所用 ABS 粒料熔融温度约为 170℃，热分解温度约为 $2 6 0 \mathrm { { ^ \circ C } }$ 。

②PC 粒料：中文名为聚碳酸酯，是一种无色透明的无定性热塑性材料。聚碳酸酯无色透明，耐热，抗冲击，阻燃，其热变形温度约 130℃，熔融温度约 220-230℃，热分解温度约 $3 4 0 ^ { \circ } \mathrm { C }$ ，在普通使用温度内都有良好的机械性能。同性能接近聚甲基丙烯酸甲酯相比，聚碳酸酯的耐冲击性能好，折射率高，加工性能好，不需要添加剂就具有 UL94V-0 级阻燃性能。但是聚甲基丙烯酸甲酯相对聚碳酸酯价格较低，并可通过本体聚合的方法生产大型的器件。随着聚碳酸酯生产规模的日益扩大，聚碳酸酯同聚甲基丙烯酸甲酯之间的价格差异在日益缩小。聚碳酸酯的耐磨性差。一些用于易磨损用途的聚碳酸酯器件需要对表面进行特殊处理。

③PP 粒料：化学名为聚丙烯，由丙烯均聚或与少量其他烯烃共二制得的一类热塑性树脂，在 $8 0 ^ { \circ } \mathrm { C }$ 以下能耐酸、碱、盐液及多种有机溶剂的腐蚀，能在高温和氧化作用下分解。聚丙烯广泛应用于服装、毛毯等纤维制品、医疗器械、汽车、自行车、零件、输送管道、化工容器等生产，也用于食品、药品包装。本项目所用 PP 粒料熔融温度约为 164\~170℃，热分解温度约为 350℃，连续耐热温度约为 $8 8 ^ { \circ } \mathrm { C }$

④色粉：又称塑料色粉，指赋予塑料各种颜色，以制成特定色泽塑料制品的颜料。色粉具有良好的色彩性能及耐热性和易分散性。

⑤焊条：项目焊接工序所用焊条为钛钙型焊条，药皮中含 30%以上的 $\mathrm { T i O } _ { 2 }$ 及 20%以下Ca、Mg 的碳酸盐。焊条在电弧的高温下熔化，其芯线中的铁、锰、硅等蒸发或升华并被氧化成氧化物。同时其表面保护层（即药皮）中各成分也会在高温下蒸发氧化形成 ${ \mathrm { T i O } } _ { 2 } , { \mathrm { C a O } } _ { 2 } ,$ $\mathrm { M g O } _ { 2 }$ 等粒径小于 1 微米的气溶胶（烟尘）和少量 CO 和 NOx 等。

⑥机油：密度约为 $0 . 9 1 \times 1 0 ^ { 3 } \mathrm { k g } / \mathrm { m } ^ { 3 }$ ，闪点约为 180℃，能对机械设备到润滑减磨、辅助冷却降温、密封防漏、防锈防蚀、减震缓冲等作用。机油由基础油和添加剂两部分组成。基础油是机油的主要成分，决定着机油的基本性质，添加剂则可弥补和改善基础油性能方面的不足，赋予某些新的性能，是机油的重要组成部分。

⑦电火花油：从煤油组分加氢后的产物，属于二次加氢产品。一般通过高压加氢及异构脱蜡技术精炼而成。电火花油也称为：火花油、电火花油、火花机油、放电加工油、火花机电蚀油、电火花机油，本项目所用电火花机油外观为无色透明液体，无刺激性气味、溶解力适中，闪点高安全性好。

⑧乳化油：乳化油是由基础油加入适量的防锈剂、乳化剂而制得的一种产品。油基外观在常温下为棕黄色至浅褐色半透明均匀油体。乳化油与水按一定比例混合，调制成乳化液，具有防锈、清洗、极压性能，适用于金属加工、切削等过程中作为冷却液使用，本项目乳化油稀释比例约为 1:20。

## 2.工艺流程说明

（1）各类家电生产工艺流程说明

①混料：根据产品需要按一定比例将 ABS 粒料、PC 粒料、PP 粒料、色粉投加到混料机中进行充分混合；

②注塑：通过注塑机加热系统将混合均匀的塑料原料加热至熔融状态，然后注入注塑模具腔体内，经冷却后成型即为家电塑料外壳工件；

③检验：通过人工对家电塑料外壳工件进行检验；

④外发涂装：将检验家电塑料外壳工件外发进行涂装加工；

⑤机加工：部分五金类配件需采用摇臂钻床、小磨床、大磨床、铣床、火花机、车床、剪板机、油压机、冲床等设备进行机械加工；

⑥焊接：采用焊机将需要焊接的五金类配件焊接在一起；

⑦组装：将外购电子类配件、五金类配件、塑料类配件、其他类配件与自产的家电塑料外壳工件组装在一起即为半成品；

⑧检测：采用调压器、变频电源、多路温度测试仪、数据采集仪、泄漏测试仪等设备对半成品进行检测；

⑨包装：检测合格的半成品经包装后即为成品；

## ③金属粉尘

项目五金类配件及模具维修过程机加工工序会产生少量金属粉尘，污染因子为颗粒物，参考《排放源统计调查产排污核算方法和系数手册》中机械行业系数手册，机加工金属粉尘的产生系数按 5.3kg/t 原料计，根据建设单位提供资料，本项目需进行机加工五金类配件量约 115t/a，模具维修量为 5t/a，则本项目金属粉尘产生量为 0.636t/a。由于金属粉尘比重较大，易于沉降，约 90%粉尘可在操作区域附近沉降，只有少部分约 10%排放到大气中形成粉尘，则金属粉尘排放量约为 0.064t/a，以无组织形式排放，通过加强车间通风换气措施改善影响，项目年运行 2400h，则金属粉尘的排放速率为 0.0267kg/h。沉降的金属粉尘纳入一般工业固废管理，其产生量约为 0.572t/a。

## ④焊接烟尘

本项目采用的焊接方式为手工电弧焊，所用焊料为钛钙型焊条，焊接过程中会产生少量焊接烟尘，根据《排放源统计调查产排污核算方法和系数手册》中机械行业系数手册，手工电弧焊焊接烟尘的产生系数按 20.2kg/焊条计，根据建设单位提供的资料，本项目焊条使用量为 0.025t/a，则焊接工序焊接烟尘产生量约为 0.0005t/a，以无组织形式排放，通过加强车间通风换气措施改善影响。项目焊接工序年工作 200h，则焊接工序焊接烟尘排放速率约为0.0025kg/h。

## ⑤臭气浓度

本项目注塑工序会产生轻微恶臭气味，其污染因子为臭气浓度，恶臭气味产生量因原辅材料使用类型、使用量、设备参数等而有较大差异，难以定量分析，本报告仅作定性分析。经勘察类比同类项目，生产过程恶臭气体产生量较小，注塑工序恶臭气体与非甲烷总烃一并收集后引入“二级活性炭吸附装置”处理后通过 25m 高的排气筒（DA001）引至高空排放，预计项目臭气浓度有组织排放值≤6000（无量纲），厂界臭气浓度≤20（无量纲）。

## （5）废气达标及环境影响分析

本项目注塑工序非甲烷总烃产生量为 0.478t/a，非甲烷总烃经收集后引入“二级活性炭吸附装置”处理后通过 25m高的排气筒（DA001）引至高空排放，收集风量为 7000m³/h，收集效率为 80%，处理效率为 75%，经处理后非甲烷总烃有组织排放量为 0.096t/a，无组织排放量为 0.096t/a。

采取以上措施后预计本项目非甲烷总烃排放达到《合成树脂工业污染物排放标准》（GB31572-2015）中表 5 大气污染物特别排放限值及表 9 企业边界大气污染物浓度限值；厂内有机废气无组织排放达到《固定污染源挥发性有机物综合排放标准》（DB44/2367—2022）表 3中厂区内无组织排放监控点浓度限值。

本项目投料过程及破碎工序会产生少量塑料粉尘，机加工工序会产生少量金属粉尘，本项目焊接工序会产生少量焊接烟尘，污染因子均为颗粒物，这些颗粒物粒径较大，容易沉降，扩散范围一般在加工工位附近，因此颗粒物为无组织排放，通过加强通风换气措施，减少废气对周围环境的影响。采取上述措施后，本项目颗粒物无组织排放可达到广东省地方标准《大气污染物排放限值》（DB44/27-2001）第二时段无组织排放监测点浓度限值及《合成树脂工业污染物排放标准》（GB31572-2015）中表 9 企业边界大气污染物浓度限值的较严值。

本项目注塑工序会产生轻微恶臭气味，其污染因子为臭气浓度，恶臭气味产生量因原辅材料使用类型、使用量、设备参数等而有较大差异，难以定量分析，本报告仅作定性分析。经勘察类比同类项目，生产过程恶臭气体产生量较小，注塑工序恶臭气体与非甲烷总烃一并收集后引入“二级活性炭吸附装置”处理后通过 25m 高的排气筒（DA001）引至高空排放，预计项目臭气浓度有组织排放值≤6000（无量纲），厂界臭气浓度≤20（无量纲）。

为了进一步减少废气对大气环境的影响和保障工人健康，建议建设单位采取下列措施：A.加强管理及强化员工操作规程，减少该过程产生的废气对周边环境的影响；  
B.加强生产车间内通风，并设置较强的排风系统；  
C.建议操作人员操作时佩戴口罩；  
D.定时维护废气处理设备，确保废气能得到有效的收集和处理。

采取上述处理措施后，本项目产生的各类废气污染物经处理后均可达标排放，根据本报告第三章可知，项目厂界外 500 米范围不涉及大气环境保护目标，其与项目的距离较远，项目周边各废气污染物经扩散后基本不对大气环境保护目标产生明显不利影响，则本项目大气环境影响可接受。

根据《社会区域类环境影响评价》（中国环境科学出版社），我国目前城市人均生活垃圾为 0.8\~1.5kg/人·d，办公垃圾为 0.5\~1.0kg/人·d，本项目不设员工宿舍及食堂，员工均不在厂内食宿，则每人每天生活垃圾产生量按 1kg 计算，本项目共有员工 80人，年工作 300天，则员工生活垃圾产生量约为 24t/a。

## ②一般工业固废

本项目包装工序及原料使用过程会产生少量废包装材料，根据建设单位提供资料，包装工序废包装材料产生量约为 0.3t/a，原料使用过程废包装材料产生量为 12.4t/a；则项目废包装材料产生量为 12.7t/a。本项目机加工工序会产生少量沉降的金属粉尘及五金边角料，根据建设单位提供资料，沉降的金属粉尘产生量约为 0.572t/a，五金边角料产生量约为 1t/a。

## ③危险废物

## A.废矿物油

本项目机油、电火花油使用过程中会产生少量废矿物油，本项目机油使用量为 0.1t/a、电火花油使用量为 0.05t/a，废矿物油产生量约占矿物油使用量的 10%，则废矿物油产生量为 0.015t/a。

## B.废矿物油桶

本项目生产过程中会产生少量含机油、电火花油、乳化油的废矿物油桶，根据建设单位提供资料，本项目废矿物油桶产生量约为 0.008t/a。

## C.废含油抹布

项目每年进行 4次设备维护保养，每次维护保养预计产生 0.001t 废含油抹布，则废含油抹布产生量为 0.004t/a。

## D.废乳化液

本项目机加工工序需采用乳化液对刀具进行冷却，本项目乳化液由乳化油加水稀释得到，乳化液循环使用，定期更换，其废乳化液产生量约为乳化液（稀释后）使用量的 1%，本项目乳化油使用量为 0.05t/a，稀释比例为 1:20，则废乳化液产生量为 0.011t/a。

## E.废活性炭

本项目二级活性炭吸附装置处理废气过程中会产生一定量的废活性炭，根据上文分析，废活性炭产生量为 3.364t/a。

## D.管理

根据《广东省危险废物产生单位危险废物规范化管理工作实施方案》（粤环〔2011〕70号，）企业须根据管理台账和近年的产生计划，制订危险废物管理计划。台帐应如实记载产生危险废物的种类、数量、利用、贮存、处置、流向等信息，以此作为向当地环保部门申报危险废物管理计划的编制依据。产生的危险废物实行分类收集后置于贮存设施内，贮存时限一般不得超过一年，并设专人管理。盛装危险废物的容器和包装物以及产生、收集、贮存、运输、处置危险废物的场所，必须依法设置相应标识、警示标志和标签，标签上应注明贮存的废物类别、危害性以及开始贮存时间等内容。企业必须严格执行危险废物转移计划报批和依法运行危险废物转移联单，并通过信息系统登记转移计划和电子转移联单。企业还需健全产生单位内部管理制度，包括落实危险废物产生信息公开制度，建立员工培训和固体废物管理员制度，完善危险废物相关档案管理制度；建立和完善突发危险废物环境应急预案。

项目产生的危险经上述措施妥善处理后，对周围环境影响不明显。

综上所述，本项目固体废物经上述“资源化、减量化、无害化”处置后，可将固废对周围环境产生的影响减少到最低限度，不会对周围环境产生明显的影响。

## ②大气

A.项目生产车间若发生火灾事故时，建筑墙体、设备燃烧爆炸等会产生二氧化硫、一氧化碳、有机废气有毒有害物质，同时项目内的火灾产生的颗粒物会飞扬，气体排放随风向外扩散，在不利风向时，周围企业、员工及村庄等均会受到不同程度的影响。

B.当废气处理设施发生故障时，可能会造成大量未经处理达标的废气直接排入大气中，对周围环境空气质量造成较大的影响，危害周围居民的人身健康。如果抽排风机发生故障或室内排气管道发生破裂，可能导致工作场所空气中的污染物浓度增加，危害员工的人身健康。

## ③地下水

车间地面有作水泥硬底化防渗处理，故对地下水影响不大。

## （4）环境风险防范措施

A.建立健全的公司突发环境事故应急组织机构，同时加强员工相关知识培训、提高安全意识，制定具体的现场处置方案，定期组织应急演练；

B.加强现场管理，定期检查维护项目内电气设施，生产场所内配备充足有效的火警报警系统及灭火器材，防止由于火灾导致的突发环境事故的发生，设置消防通道，消防通道不得堵塞，消防泵可随时开机使用；

C.按规定设置好危废贮存间；

D.在雨污管网总排口处设置截流阀；

E.厂区内配备充足的消防沙袋等应急物资；

F.车间地面必须作水泥硬底化防渗处理；

G.存放环境风险物质的场所、危废贮存间应以混凝土硬化地面作为基础，并做好防渗措施及截流措施；

H.加强员工的岗前培训，强化安全意识，制定操作规程；

I.建立污染治理设施运行台帐，对污染治理设施的运行、管理、维护情况进行记录；设立兼职环保员，认真填写好污染治理设施检修及维护运行情况记录，并将隐患整改及时反馈，接受各级领导检查，根据污染治理设施使用情况制定污染治理设施维护计划；
