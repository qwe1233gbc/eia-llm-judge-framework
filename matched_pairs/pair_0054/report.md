项目用水由市政给水管网供应。用水主要为生产用水及员工生活用水。

本项目劳动定员9人，年工作日280天，项目内不设员工宿舍和食堂，根据广东省《用水定额 第三部分：生活》（DB44/T1461.3-2021）表A.1中国家机构办公楼无食堂和浴室的先进值，生活用水按10m3 /（人·a）计，则生活用水量约为90m3/a。

## 设备清洗用水

根据第四章分析，项目设备清洗用水量约108m3/a。

项目设有实验室，主要用于产品研发和测试。产品研发工艺与生产工艺相似，故不再另外描述。研发过程会产生少量有机废气、粉尘和臭气浓度。废气经集气罩+帘幕收集与生产过程产生的废气一起引至“滤筒除尘器+二级活性炭吸附装置”处理，最后通过 57m 排气筒 G1 排放。

## 2、 大气污染物排放标准

生产车间中投料、分散工序以及实验研发中产生的粉尘、有机废气、恶臭经收集后，通过滤芯除尘器处理与经收集的实验测试有机废气和恶臭，一并通过“二级活性炭吸附”处理后引至57m的排气筒G1高空排放。实验测试粉尘在车间内无组织排放。

本项目属于化工项目，根据《广东省生态环境厅关于化工、有色金属冶炼行业执行大气污染物特别排放限值的公告》（粤环发〔2020〕2 号），本项目需执行大气污染物特别排放限值。有组织排放的颗粒物、非甲烷总烃和 VOCs 执行《涂料、油墨及胶粘剂工业大气污染物排放标准》（GB37824-2019）表 2 大气污染物特别排放限值要求。

厂界无组织排放的颗粒物参照执行广东省地方标准《大气污染物排放限值》（DB44/27-2001）中第二时段无组织排放监控浓度限值。

臭气浓度执行《恶臭污染物排放标准》（GB14554-93）中表 1 的新扩改建项目二级厂界标准和表 2 的排放标准值。

## 2）有机废气

项目生产水性吸墨涂料和水性离性涂料过程中会挥发少量的 VOCs，根据《排放源统计调查产排污核算方法和系数手册》（生态环境部公告 2021年第 24号）中“2641涂料制造业”中的“水性工业涂料”，水性工业涂料 VOCs 产污系数为 2.0kg/t·产品。运营期间，项目年产水性吸墨涂料 350t、水性离型涂料 250t，VOCs 的产生量是 1.2t/a。分散工序年工作 280天，每天运行 5h，VOCs 的产生速率为 0.857kg/h。在分散机上方废气挥发位置设置“集气罩+帘幕”，收集后与粉尘一并经滤芯除尘器和“二级活性炭吸附”处理后引至 57m 高排气筒 G1 排放。

## 3）实验废气

## ①实验研发废气

涂料生产前，需根据客户需求调配涂料成分组成，过程中会产生有机废气和粉尘，主要污染因子为 VOCs、颗粒物和臭气浓度。研发过程使用的原辅材料均来源于生产使用的原辅材料，研发时的原辅材料使用量和污染物产生量已纳入生产过程中原辅材料总使用量和污染物产生量中，故不再重复计算实验研发废气产生量。研发废气经集气罩+帘幕收集后与生产过程产生的废气一并经滤芯除尘器和“二级活性炭吸附”处理后引至 57m 高排气筒 G1 排放。

## ②产品测试废气

根据客户的要求，部分产品需要实验和测试使用效果。根据企业提供的资料，用于实验和测试的产品使用量较少，水性离型涂料和水性吸墨涂料年使用量约均为 50kg/a，平均每月测试 5 次，每次测试时间约为 1h。测试过程中会产生粉尘、VOCs、非甲烷总烃和臭气浓度。

手工刮涂水性离型涂料和水性吸墨涂料及其烘干过程会产生 VOCs。水性离型涂料和水性吸墨涂料在手工刮涂过程 VOCs 产生量较少，基本可以忽略，VOCs 挥发主要发生在涂料烘干过程中，主要对烘干废气进行收集。根据产品水性离型涂料原辅材料表可知，助剂中的润湿剂（1.05%）和固化剂（4.3%）为主要挥发份，即水性离型涂料 VOCs 含量为 5.35%。根据产品水性吸墨涂料原辅材料表可知，助剂中的均匀剂（0.25%）和固化剂（0.25%）为主要挥发份，即水性吸墨涂料 VOCs 含量为 0.5%。综上，手工刮涂水性离型涂料和水性吸墨涂料及其烘干过程 VOCs 产生量为 0.003t/a，产生速率为 0.05kg/h。

图案打印过程使用到烫画膜涂料墨水，该过程会产生 VOCs。根据《油墨中可挥发性有机化合物（VOCs）含量的限值》（GB 38507-2020）中表 1 油墨中可挥发性有机化合物含量的限值，水性油墨挥发性有机化合物（VOCs）限值最大值为 30%。项目测试过程烫画膜涂料墨水使用量为 0.05t/a，则打印过程 VOCs 产生量为 0.015t/a，产生速率为 0.25kg/h。

产品测试过程中，往图案撒热熔粉过程，会产生微量粉尘，操作中采取轻拿轻撒，降低粉尘产生量，因此该过程粉尘产生量可忽略不计。热熔粉烘干过程会产生非甲烷总烃和臭气浓度，根据《排放源统计调查产排污核算方法和系数手册》C2921塑料薄膜制造行业系数表，非甲烷总烃产污系数为 2.5kg/t-产品。项目热熔粉烘干后形成塑料膜，进行下一步的压烫转印，因此热熔粉的使用量即是塑料膜产量。测试过程热熔粉使用量为 0.1t/a，则非甲烷总烃产生量为 0.0003t/a。热熔粉烘干过程非甲烷总烃产生量极少，可忽略不计。

测试过程中压烫转印工序会产生少量非甲烷总烃和臭气浓度，测试过程压烫转印次数较少，且操作时间短，因此非甲烷总烃产生量较少，本次评价仅进行定性分析。

综上，项目测试过程 VOCs 产生量为 0.018t/a。项目测试过程产生的有机废气经收集后与生产过程产生的废气一并经 “二级活性炭吸附”处理后引至 57m 高排气筒 G1 排放。

## 4）恶臭

项目生产过程中会产生轻微的恶臭，主要污染因子为臭气浓度。由于臭气的发生比例与操作温度、原料性能等诸多因素有关，较难进行准确定量计算，本次评价不做定量分析。恶臭随有机废气一起收集经“滤芯除尘器+二级活性炭吸附”装置处理后通过排气筒 G1 排放。恶臭产生量较少，预计处理后臭气浓度可达到《恶臭污染物排放标准》（GB14554-93）中的相关排放限值。

## 废气收集效率分析：

项目分散机、实验室分散机、打印机和压烫机上方设置集气罩收集废气，集气罩外围安装软帘形成局部围蔽，加强收集效率。根据《佛山市涂料油墨行业建设项目环评文件编制技术参考指南（试行）》中废气收集集气效率参考值，包围性集气设备中敞开面控制风速不小于 0.5 m/s，集气效率取 60%（根据实际运行情况，收集集气效率应当预留（10%以上）余量），本项目拟在分散机上方安装“集气罩+帘幕”收集设施，控制风速为 0.6m/s，则废气收集效率按 50%计；烘箱烘烤废气采取管道直连废气排口收集。根据《佛山市涂料油墨行业建设项目环评文件编制技术参考指南（试行）》中废气收集集气效率参考值，设备废气排口直连集气效率为 95%（根据实际运行情况，收集集气效率应当预留（10%以上）余量），则废气收集效率为 85%。

## 1.2废气收集治理设施可行性分析

项目使用的废气治理设施及工艺见表 4-1，为《排污许可证申请与核发技术规范 涂料、油墨、颜料及类似产品制造业》（HJ 1116-2020）“表 A3 排污单位废气治理可行技术参照表—涂料制造”中的可行性技术（袋式除尘、吸附），故本项目废气治理设施可行。

活性炭是一种由含碳材料制成的外观呈黑色，内部孔隙结构发达、比表面积大、吸附能力强的一类微晶质碳素材料。活性炭材料中有大量肉眼看不见的微孔，1 g 活性炭材料中微孔的总内表面积可高达 700-2300 m2。正是这些微孔使得活性炭能“捕捉”各种有毒有害气体和杂质。由于气相分子和吸附剂表面分子之间的吸引力，使气相分子吸附在吸附剂表面。吸附剂表面面积愈大、单位质量吸附剂所能吸附的物质愈多。建议项目采用蜂窝状、碘值不低于 800mg/g 的活性碳，比表面积 900～1500 m2 /g，具有非常良好的吸附特性，其吸附量比活性炭颗粒一般大20-100倍，吸附容量为 15 wt%。当吸附载体吸附饱和时，可考虑更换。采用活性炭进行有机尾气的净化，其去除效率会因活性炭吸附废气的饱和程度而不同，净化效率为 50%\~80%（本报告取 51%），为确保活性炭吸附效率，需要对活性炭定期更换。

## 2.2生产废水

## ①设备清洗废水

项目在生产间歇期，要对分散缸进行清洗，会产生清洗废水。

水性离型涂料不需进行调色，分散缸清洗废水中本身含有生产所需原材料，故水性离型涂料分散缸清洗废水可回用于生产中。根据《排放源统计调查产排污核算方法和系数手册》（生态环境部公告 2021 年第 24 号）中“2641 涂料制造业-水性工业涂料”，工业废水量产污系数为0.18t/t·产品。本项目年产水性离型涂料 250t，则清洗水量为 45t/a，每次清洗后暂存在分散缸中，待下一批次生产时作为生产用水。

水性吸墨涂料不需进行调色，分散缸清洗废水中本身含有生产所需原材料，故水性吸墨涂料分散缸清洗废水可回用于生产中。根据《排放源统计调查产排污核算方法和系数手册》（生态环境部公告 2021 年第 24 号）中“2641 涂料制造业-水性工业涂料”，工业废水量产污系数为0.18t/t·产品。本项目年产水性吸墨涂料 350t，则清洗水量为 63t/a，每次清洗后暂存在分散缸中，待下一批次生产时作为生产用水。由表 2-4（a）可知，水性吸墨涂料自来水用量为 32.461t/a，小于清洗水量 63t/a，则剩余的清洗废水暂存于废水收集桶定期交由佛山市顺德区绿点废水回收处理有限公司处理。

综上，设备清洗废水产生量为108t/a，其中77.461t 清洗废水回用于生产，30.539t 清洗废水交由佛山市顺德区绿点废水回收处理有限公司处理。

## ②实验室清洗废水

实验室研发过程中需要清洗设备、器皿，实验室清洗用水量约 5m3 /a，废水产生系数按 0.9计，故清洗废水产生量是 4.5m3 /a。实验室清洗废水经收集桶收集后定期交由佛山市顺德区绿点废水回收处理有限公司处理。

## ③车间地面清洁废水

项目定期使用自来水和拖把对车间的地面进行清洗，拖把清洗的过程会产生一定量的地面清洁废水，项目年拖地 10 次，每次拖地用水量约为 0.25m3，则拖地用水量约为 2.5m3/a。依据实际运行情况，拖把带走的水量较多，造成的损失也较大，废水产生系数 0.8，则全年地面清洗水废水量约为 2m3 /a。车间地面清洁废水经收集桶收集后定期交由佛山市顺德区绿点废水回收处理有限公司处理。

综上，项目实验室清洗废水和地面清洗水废水经收集桶收集后交由佛山市顺德区绿点废水回收处理有限公司处理。

## 2.3废水污染防治措施

## ◇生活污水

项目不设饭堂和员工宿舍。本项目外排废水主要是工作人员的生活污水，主要为洗手废水、冲便废水。项目废水最大排放量为 $8 1 \mathrm { m } ^ { 3 } / \mathrm { a }$ ，废水主要污染物为 CODCr、BOD5、NH3-N、SS 等。生活污水经三级化粪池处理后通过市政管网进入杏坛污水处理厂处理，尾水排入顺德支流，对周围水环境影响不大。

## ◇生产废水

生产废水主要包括设备清洗废水、实验室清洗废水和车间地面清洁废水。废水产生量为37.039m3 /a，废水主要污染物为 $\mathrm { C O D } _ { \mathrm { C r } }$ 、 $\mathrm { B O D } _ { 5 } .$ 、SS 等，经收集后存放于收集桶中，定期交由佛山市顺德区绿点废水回收处理有限公司，对周围水环境影响不大。

## 2.4废水治理设施可行性分析

## ①依托杏坛污水处理厂的可行性分析

杏坛生活污水处理厂一期服务范围为杏坛镇区，包括齐杏、雁园、马齐、杏坛、吕地、罗水六个居委会的全部用地和桑麻、西北、龙潭三个村的部分用地；二期扩建完成后污水收集范围为以下几大区域的生活污水及经过预处理的工业废水：①顺德浦项钢板有限公司片区；②美的工业园片区；③大型村居片区，包括高赞村、上地村、昌教村、光辉村、西登村和河北路以北河涌收纳的村庄；④杏坛工业园二期片区；⑤大型楼盘片区，包括金海岸、佳兆业、中博兆业、银座、海俊达上苑和敬老院东侧地块等。本项目位于杏坛生活污水处理厂的服务范围，且已接通市政管网。

根据《顺德区杏坛镇污水处理厂二期扩建工程项目环境影响报告表》（佛山市顺德环境科学研究所有限公司，2013 年 12 月），杏坛生活污水处理厂一期工程日处理规模 2 万吨/日，二期工程日处理规模为 4 万吨/日，合计 6 万吨/日，尚有余量。

杏坛生活污水处理厂采用“改良 A2 /O 处理工艺”，废水首先进入粗格栅去除大尺寸的漂浮物和悬浮物，然后通过进水泵提升至细格栅沉砂池，细格栅用于进一步去除污水中较小颗粒的悬浮、漂浮物，然后废水进入 A2 /O 处理池工艺:沉砂池出水自流到厌氧池，在厌氧池内，大部分的有机物通过厌氧水解酸化,同时二沉池回流污泥 PAO 释放磷酸根。在缺氧池内，回流污泥将大量硝化液带到此处，反硝化菌将进行脱氮反应，然后污水流入好氧池。在好氧状态下，污水中的有机物和氨氮被细菌氧化生成 $\mathrm { C O } ^ { 2 }$ 、 $_ \mathrm { H _ { 2 } O }$ 和硝酸盐，从而达到去除污水中绝大部分有机物和氨氮的目的。传统 $\mathbf { A } ^ { 2 } \mathbf { O }$ 工艺的缺点是回流污泥中过多的硝酸盐破坏厌氧环境，影响厌氧放磷效果，为此产生了 UCT 工艺。与传统 $\mathbf { A } ^ { 2 } \mathbf { O }$ 工艺比较，UCT 工艺不同之处在于污泥先回流至缺氧池，再将缺氧池部分混合液回流至厌氧池，从而减少了回流污泥中硝酸盐对厌氧放磷的影响。但 UCT 工艺增加了一次回流，即多一次提升，相应的运行费用将增加。废水经 $\mathsf { A } ^ { 2 } / \mathsf { O }$ 处理池处理后，进入沉淀池。经沉淀池主要完成混合液分离和污泥的部分浓缩，使出水悬浮物浓度达到所要求的排放标准和回流污泥达到一定的浓度。最后废水经紫外消毒处理达标后，通过管道排入顺德支流。

项目生活污水经预处理达到广东省地方标准《水污染物排放限值》（DB44/26-2001）第二时段三级标准后再排至杏坛生活污水处理厂处理，满足污水厂的纳管要求，不会对污水厂造成冲击负荷，也不会影响其正常运行，因此本项目生活污水依托杏坛生活污水处理厂处理是可行的。

## 3.2声环境影响分析及达标分析

本项目噪声源为主要来自于组分散机、粘度计、实验室分散机、烘箱、电子天平等设备运行过程中产生的机械噪声，经基础减震、隔声降噪设施治理后的排放源强为 50\~70dB(A)。按照《环境影响评价技术导则—声环境》（HJ2.4-2021）要求，采用多声源叠加综合预测模式对项目产生噪声的发散衰减进行模拟预测。

（1）点声源的几何发散衰减计算公式：

$$
L _ { p } ( r ) { = } L _ { p } ( r _ { 0 } ) { - } 2 0 1 \mathrm { g } \Bigg ( \frac { r } { r _ { 0 } } \Bigg ) { - } { \varDelta } L
$$

式中： $L _ { p } ( r ) .$ 距声源 r 米处的噪声预测值，dB（A）；

$L _ { p } ( r _ { 0 } ) .$ 参考位置 r0处的声级，dB（A）；

$r -$ —预测点位置与点声源之间的距离，m；

$r _ { 0 ^ { - } }$ 参考位置处与点声源之间的距离；

ΔL——预测点至参考点之间的各种附加衰减修正量。

## （2）多点声源理论总等效声级贡献值 $. [ L _ { e q g } ]$ 的估算方法：

多个设备同时运行时在预测点产生的总等声级贡献值 $( L _ { e q g } )$ 的计算公式为：

$$
L _ { e q g } { = } 1 0 1 \mathrm { g } ( \frac { 1 } { T } \sum _ { i } t _ { i } 1 0 ^ { 0 . 1 L _ { A i } } )
$$

式中： $L _ { e q g }$ 建设项目声源在预测点的等效声级贡献值， $\mathrm { d B } ( \boldsymbol { \mathrm { A } } )$

$L _ { A i }$ i 声源在预测点产生的 A 声级， $\mathrm { d B } ( \boldsymbol { \mathrm { A } } )$

$T -$ 预测计算的时间段，s；

$t _ { i } \cdot$ i 声源在 T 时段内的运行时间，s。

## 5、地下水、土壤

## 5.1 影响途径

## （1）大气沉降

本项目对土壤可能造成污染的途径主要为大气沉降，本项目排放的大气污染物主要是颗粒物、VOCs、非甲烷总烃和臭气浓度，不属于《重金属及有毒害化学物质污染防治“十三五”规划》、《两高司法解释的有毒有害物质》（法释（2016）29号）、《有毒有害大气污染物名录（2018 年）》的公告（生环部公告 2019 年：第 4 号）、《土壤环境质量建设用地士壤污染风险管控标准（试行）》（GB36600-2018）、《土壤环境质量农用地土壤污染风险管控标准（试行）》（GB15618-2018）文件标准所述的土壤污染物质，故不存在大气沉降的污染途径。

## （2）液态物质泄漏

## ①废水渗漏分析和影响

一般情况下，废水渗漏主要考虑水池容纳构筑物（如废水处理设施、化粪池等）底部破损渗漏和排水管渗漏两个方面。

建设单位应认真做好排水管道外观监测和通水试验，检查排水管设计，根据管径尺寸、设定固定垂直、水平支架，避免管道偏心、变形而渗水；地下埋管应设置砖墩支撑，回填土时应两侧同时回填避免管道侧向变形，回填土前必须先做通水试验。只要采用优良品质的管道，在实际生产过程中及时做好排查工作，不会存在排水管道泄漏污染土壤、地下水的情况。

## ②固体废物泄漏

项目危险废物暂存间的废机油泄漏存在泄漏风险。项目危险废物暂存间做好防风、防雨、防渗漏等措施，危险废物废机油的产生量较少，运营期间做好巡查工作，不会存在废机油等泄漏污染土壤、地下水的情况。

## ③化学品泄漏

项目化学品存放区、危险废物暂存间进行重点防渗处理，化学品存放区、危险废物材料。建议危废暂存仓采取粘土铺底，再在上层铺设 10-15cm 的水泥进行硬化，四周设围堰。

经上述土壤及地下水环境影响途径分析，项目运行期间对地下水和土壤无污染影响途径，不再布设跟踪监测点。

## 5.5土壤和地下水防治措施及结论

项目针对土壤和地下水污染防治主要采取以下措施：

项目应认真做好设备的保养，定期进行维护、保修工作，确保不发生事故性废气、废水排放；项目按分区要求做好做好硬底防渗措施。只要各个环节得到良好控制，可以将本项目对土壤和地下水的影响降至最低，项目对周边土壤和地下水的影响较小。

综上，本项目通过采取以上措施，可有效防止对土壤和地下水环境造成不良影响，土壤和地下水污染防治措施可行。

## 6.3 环境风险分析及防治措施

1）化学品存放区泄漏、爆炸风险防治措施

项目设置了化学品存放区储存润湿剂、固化剂、水性聚硅氧烷乳液、水性合成树脂乳液等原辅材来哦，为防止泄漏、火灾爆炸产生的风险，建设单位应采取如下措施:

A、原料入库时，严格检验物品质量、数量、包装情况、有无泄漏。入库后采取适当的养护措施，在贮存期内，定期检查，发现其品质变化、包装破损、渗漏等，及时进行处理。

B、装卸和使用原料时，操作人员要轻拿轻放。

C、对仓库工作人员进行培训，熟悉储存物品的分类、性质、保管业务知识和安全知识。

D、配置沙土箱和适当的空容器、工具，以便发生泄漏时收集溢出的物料。

E、在仓库、车间等设置漫坡和围堰，防止液态化学品泄露溢出。

2）厂房火灾爆炸风险防治措施

为防止厂房火灾爆炸产生的风险，建设单位应采取如下措施：

A、规范原辅材料的存储，储存于阴凉处，远离热源、火源；储存及使用生产区应为禁烟区。

B、车间、原料仓库采用混凝土硬化防渗处理。

C、厂房保持通风良好，规划平面布局并设置消防通道。

D、定期检测生产设备、照明等电路，做好电气安全措施，设置防静电措施。

E、建设单位应按照消防部门的相关要求设置灭火器、消防栓等，消防措施须经相关部门验收合格，并定期检查消防器材的性能及使用期限。

3）危险废物泄漏风险防治措施

A、危废暂存间按照《危险废物贮存污染控制标准》（GB18597-2023）、《危险废物收集、贮存、运输技术规范》（HJ2025-2012）相应的规范进行设置。危废暂存间设置围堰、地面采用混凝土硬化，并做防渗处理。

B、贮存危险废物时使用符合标准的容器盛装危险废物，装载危险废物的容器及材质要满足相应的强度要求。

4）应急预案备案措施

根据《关于发布<突发环境事件应急预案备案行业名录（指导性意见）>的通知》（粤环〔2018〕44 号）、《佛山市企业事业单位突发环境事件应急预案备案管理实施办法》（佛环[2019]140 号）和《佛山市生态环境局关于印发危险废物产生单位突发环境事件应

急预案备案的指导意见（试行）的通知》（佛环[2020]54 号）中的相关要求，企业需编制（修订）企业环境应急预案备案，健全应急组织，落实应急器材，并对预案进行演练。

## 9、其他环境管理要求

①建立环境保护管理组织和机构，指定专人或兼职环保管理人员，落实各级环保责任。

②制定各环保设施操作规程，定期维修制度，使各项环保设施特别是危险废物收集储存设备，使其处于良好的运行状态，如环保设施出现故障，应立即停产检修，严禁非正常排放。

③对产污工序的工人和班组长进行上岗前的环保知识法规教育及操作规程的培训，使各项环保设施的操作规范化，保证环保设施的正常运转。

④落实环境监测工作，重点是各污染源的监测，并注意做好记录，不弄虚作假。

⑤建立相关记录台账：a、危险废物收集交接记录，转运交接记录；b、突发环境事件记录；c、废气监测记录，以供主管单位核查污染物排放量控制情况；d、原料购买、管理使用台账。

⑥建立污染事故报告制度。当污染事故发生时，必须在事故发生二十四小时内，向区环境主管部门作出事故发生的时间、地点、类型和排放污染物的数量、经济损失等情况的初步报告，事故查清后，向区环境主管部门面报告事故的原因，采取的措施，处理结果，并附有关证明。若发生污染事故，则有责任排除危害，同时对直接受到损害的单位或个人赔偿损失。

## 关于《顺德西部生态产业新区杏坛北片区控制性详细规划》的批后公告

## 一、规划背景

为了更好的指导顺德西部生态产业新区杏坛北片区的发展，使规划管理更科学合理，佛山市顺德区发展规划和统计局组织编制了《顺德西部生态产业新区杏坛北片区控制性详细规划》。

## 二、规划范围

本次规划范围北至南国路、南至规划路、西至二环路、东至顺德支流，规划范围总面积约4.94

## 三、规划目标、定位和原则

## 1、发展目标

打造“具有顺德水乡特色的高新技术开发区，高端的企业服务基地”。

## 2、功能定位

（1）杏坛镇东门户城市形象展示区：通过对杏龙路两侧的“三旧”改造，改善和提升杏坛镇东

门户的城市形象，并成为高新技术开发区的商业服务中心。

（2）现代产业转型基地：以传统产业改造升级为重点的现代产业基地。

## 3、规划原则

（1）以已有规划为支撑—整合已有的规划成果

（2）以条件为基础——尊重和利用片区的现状资源与条件

（3）以目标为导向—控规编制与顺德区管理模式相结合

（4）以策略为保障——制定面向可实施的规划策略

## 四、土地利用规划

## 1、结构规划

本规划编制区的规划结构为“一心、两轴、多片区”。

一心：是指工业区的公共服务中心，也是作为高新技术产业新区的产业配套服务区。

两轴：是指二环路和杏龙路产业发展轴。二环路在杏坛城区的过境路段，起到带动城区自东南向西北拓展的作用。杏龙路是城区中部的城市主干道，是杏坛镇联系大良和勒流的东西向干道，起到疏解城区内部交通和引导城区空间拓展的作用，是联系杏坛老城片区、公共服务中心的重要联系轴。

## 2、用地布局

（1）参照《顺德西部生态产业园规划》等上层次规划对该片区的规划要求，通过合理利用道路绿带、河涌旁绿地和外围的区域绿地构筑良好的生态环境。

（2）合理组织用地功能分区，并与分期建设的步骤相结合，注重发挥现有设施的使用潜力：协调、统筹片区建设滚动开发、环境保护以及可持续发展的关系和要求。

（3）注重与周边片区的建设协调统一，包括用地功能布局、道路交通联系以及景观环境建设等方面，使其成为生态产业园的一部分。

（4）提供合理、优化的用地布局和便于操作的土地细划方案，创造有特色的产业和生活空间，突出片区特色和展现顺德的产业活力与新形象。
