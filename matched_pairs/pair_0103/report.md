## 1、选址用地相符性

项目位于广东省佛山市顺德区陈村镇广隆工业区环镇东路 2号加工三车间之四，根据佛山市顺德区 SD-D-03-03编制单元（陈村镇广隆集约工业园区）控制性详细规划（详见附图13）可知，项目所在地为工业用地，因此本项目的选址符合佛山市顺德区总体规划的要求，符合所在地块的土地利用性质。且本项目办理了合法的租赁手续，因此建设项目的选址与土地利用规划基本相符。

## 2、与《广东省人民政府关于调整佛山市部分饮用水水源保护区的批复》（粤府函〔2018〕426 号）相符性分析

根据《广东省人民政府关于调整佛山市部分饮用水水源保护区的批复》（粤府函〔2018〕426 号），项目不属于饮用水水源保护区内。

## 其他符合性分析

根据《中华人民共和国水污染防治法》第八十一条：禁止在饮用水水源准保护区内新建、扩建对水体污染严重的建设项目，或者改建建设项目增加排污量的。本项目不在水源保护区范围内且没有生产废水排放，不会对周围环境造成影响，因此与《广东省人民政府关于调整佛山市部分饮用水水源保护区的批复》（粤府函〔2018〕426号）相符。

## 3、与产业政策符合性分析

根据国家发展改革委商务部关于印发《市场准入负面清单（2022 年版）》的通知（发改体改规﹝2022﹞397 号），项目不属于上述目录所列的鼓励类、限制类、禁止（淘汰）类严控类项目，也不属于《市场准入负面清单（2022年版）》所列的禁止准入及需许可准入事项。根据《促进产业结构调整暂行规定》（国发〔2005〕40号）第十三条，项目符合国家有关法律、法规和政策规定，项目属于允许类。根据《产业结构调整指导目录（2024年本）》，项目属于允许类。因此，本项目的建设符合国家和地方的相关产业政策。

本项目所属行业为汽车零部件及配件制造业。不属于《环境保护综合名录（2021年版）》“高污染、高环境风险”、“高环境风险”产品名录内的产品，符合产业政策要求。

## （1）与广东省“三线一单”相符性分析

根据《广东省人民政府关于印发广东省“三线一单”生态环境分区管控方案的通知》（粤府〔2020〕71号）发布的广东省环境管控单元图，详见附图 12，项目所在广东省佛山市顺德区陈村镇广隆工业区环镇东路 2 号加工三车间之四属于重点管控单元区域。

## ① 生态保护红线

项目位于广东省佛山市顺德区陈村镇广隆工业区环镇东路 2号加工三车间之四，周边无自然保护区：根据《广东省人民政府关于调整佛山市部分饮用水水源保护区的批复（粤府函[2018]426号）》可知，项目不在水源保护区范围内，根据《广东省主体功能区划》（粤府[2012]120 号）可知，项目所在区域不处于生态红线内，故本项目符合生态红线要求。

## ② 环境质量底线

本项目纳污水体陈村水道的水质达到了 III类标准要求，水质良好，满足《地表水环境质量标准》（GB3838-2002）之 III 类水功能要求；附近声环境质量以及大气环境均能满足相应的标准要求；本项目加强设备管理，噪声对周围环境影响很小。本项目有机废气收集经“二级活性炭吸附”处理后高空排放；抛丸粉尘经设备内部收集配套布袋除尘设备处理后高空排放；喷粉粉尘经配套的双层滤芯处理后在车间无组织排放；对周边环境影响很小。生活污水经三级化粪池处理后排入陈村污水处理厂，尾水排至陈村水道，对周围环境影响很小。本项目符合环境质量底线要求。

## ③资源利用上限

本项目营运过程中消耗一定量的电能、水资源，项目资源消

耗量相对区域资源利用总量较少，符合资源利用上限的要求。

理化性质：

PP 塑料粒：中文名：聚丙烯，英文名：Polypropylene。是由丙烯聚合而制得的一种热塑性树脂，无毒、无味，密度小，强度、刚度、硬度耐热性均优于低压聚乙烯，可在 100℃左右使用，PP 分解温度可达 $3 0 0 ^ { \circ } \mathrm { C }$ 以上。具有良好的介电性能和高频绝缘性且不受湿度影响，但低温时变脆，不耐磨、易老化。适于制作一般机械零件、耐腐蚀零件和绝缘零件。常见的酸、碱等有机溶剂对它几乎不起作用，可用于食具。

树脂粉末：具有一定粒径分布的松散粉末颗粒，主要成分为树脂和固化剂62%、颜填料 36%、添加剂 2.0%，密度1.2\~1.8g/ml，微溶于醇、酮、甲苯等非极性有机溶剂，有良好的附着力，耐化学腐蚀性，耐热性及优异的电绝缘性。同时其制品具有收缩率小、吸水性低等特性，可直接进行喷涂处理，环保高效。

机油：密度约为 $0 . 9 1 \times 1 0 3 \mathrm { k g / m } ^ { 3 } ,$ ，闪点约为 180℃，能对机械设备到润滑减磨、辅助冷却降温、密封防漏、防锈防蚀、减震缓冲等作用。机油由基础油和添加剂两部分组成。基础油是机油的主要成分，决定着机油的基本性质，添加剂则可弥补和改善基础油性能方面的不足，赋予某些新的性能，是机油的重要组成部分。

氩气：氩气是一种无色、无味的单原子气体，相对原子质量为 39.948。一般由空气液化后，用分馏法制取氩气。氩气的密度是空气的 1.4倍，是氦气的 10倍。氩气是一种惰性气体，在常温下与其他物质均不起化学反应，在高温下也不溶于液态金属中，在焊接有色金属时更能显示其优越性。可用于灯泡充气和对不锈钢、镁、铝等的电弧焊接，即“氩弧焊”。

二氧化碳：二氧化碳，一种碳氧化合物，化学式为 CO2，化学式量为 44.0095，常温常压下是一种无色无味或无色无臭而其水溶液略有酸味的气体，也是一种常见的温室气体，还是空气的组分之一（占大气总体积的 0.03%-0.04%）。熔点为-56.6℃（527kPa），沸点为-78.5℃，密度比空气密度大（标准条件下），可溶于水。在焊接方面二氧化碳气还可作为保护气体，使焊接过程飞溅降低到最小的程度。

## 5、公用、配套工程

## （1）给水：

项目给水均由市政给水管网供应。用水主要为生产用水及员工生活用水。

## ① 生活用水

项目员工30人，厂区不提供食宿，根据《广东省用水定额第 3部分：生活》（DB44/T 1461.3-2021），项目参照国家行政机构中办公楼，无食堂和浴室的生活用水定额（先进值），即为10立方米（人/ .年）计，则项目员工生活用水为300m3/a。

## ② 生产用水

项目生产过程中需要使用自来水对注塑机进行间接冷却，冷却水经过冷却塔冷却后循环利用，定期排出部分水量，并适当加入新鲜水补充因蒸发和损失的水分。项目使用的冷却塔循环水量为 $1 0 \mathrm { m } ^ { 3 } / \mathrm { h }$ ，参考《工业循环冷却水处理设计规范》（GB50050-2017），新鲜水补充量约占循环水量的 2.4%。项目年工作时长 2400h，总循环水量为 24000m3/a，新鲜补充水量为 576 m3/a。

计算得出，项目总新鲜水用量为876m3/a。

## （2）排水

## ①生活污水

项目运营期生活污水排放系数为 0.9，则生活污水排放量为 270t/a。

生活污水经三级化粪池处理达到《水污染物排放限值》（DB44/26-2001）中的第二时段三级标准后，通过市政管网排入陈村污水处理厂处理，尾水排入陈村水道。

## ②冷却水

项目冷却用水循环使用，定期排出部分水量，项目使用的冷却塔循环水量为10m3/h，参考《工业循环冷却水处理设计规范》（GB50050-2017），排放水量约占循环水量的0.4%，年工作时长 2400h，总循环水量为 24000m3/a，则定期排水量为96m3/a。作为清净下水定期排入雨水管网。

![](images/2f6633439a5969bee534717f250b9d32d51653acba8edb6caa542cd5414bee98.jpg)

工艺流程说明：

混料：项目将外购的PP塑料粒与破碎后的塑料进行混合，且混料过程为加盖密闭搅拌。此过程无粉尘产生，会产生噪声。

注塑：将混合均匀后的原辅材料注塑成型。注塑温度根据材料性质控制在200℃-220℃范围，然后控制注射的压力和速度将塑料注入模具，产品成型需用自来水通过管道循环进行间接冷却。项目生产中塑料粒子的熔融温度不会导致这些塑料粒子的分解，一般情况下不会分解产生单体气体。注塑过程会产生噪声、非甲烷总烃和臭气浓度。

破碎：次品及边角料全部经过破碎机破碎并与塑料粒新料混合后重新回用于注塑工序，不外排，此过程会产生噪声、塑料粉尘。

开料：对外购的铝合金板按尺寸要求进行切割和开料，该过程会产生金属粉尘、噪声和金属边角料。

机加工：利用冲床、折弯机对铝合金板进行机加工使其成型。该过程会产生金属粉尘、噪声和金属边角料。

抛丸：利用高速砂流的冲击作用清理和粗化工件表面，使工件的表面获得一定的清洁度和不同的粗糙度，改善其机械性能，同时提高了和涂层之间的附着力，便于后续喷粉工序的进行，该过程会产生金属粉尘，噪声。

喷粉固化：喷粉是利用静电是树脂粉末吸附在工件上，当工件表面的涂料达到一定厚度时，由于产生静电排斥作用，便不继续吸附，从而使整个工件获得一定厚度的粉末涂层，然后经过热使粉末熔融固化，即在工件表面形成坚硬的涂膜。喷粉过程会产生颗粒物，通过喷粉线自带的滤芯除尘系统收集处理回用于生产；固化过程采用天然气加热，固化过程会产生非甲烷总烃、SO2、NOx、烟尘、臭气浓度等。

组装：把喷粉后的五金配件和骑车侧踏板塑料配件组装在一起。

人工打包：人工简单包装后，便得到最后的成品。

## 3、空气环境质量现状

本项目位于广东省佛山市顺德区陈村镇广隆工业区环镇东路2号加工三车间之四，根据佛山市人民政府办公室《关于调整顺德区空气质量功能区划的复函》（佛府办函[2014]494号）及《佛山市顺德区生态环境保护“十四五”规划（2021-2025）》，顺德区全境为大气环境二类区，因此本项目所在区域属二类环境空气质量功能区，执行《环境空气质量标准》（GB3095-2012）二级标准及其2018年修改单的要求。

根据《环境影响评价技术导则-大气环境》（HJ2.2-2018）第6.4.1.1条规定，城市环境空气质量达标情况评价指标为 $\mathrm { S O _ { 2 } \cdot \ N O _ { 2 } \cdot \ P M _ { 1 0 } \cdot \ P M _ { 2 . 5 } }$ 、CO 和 $\mathrm { O } _ { 3 }$ ，六项污染物全部达标即为城市环境空气质量达标。

## B.喷粉粉尘（无组织）

工件通过自动输送线送至静电喷粉柜进行表面喷涂，项目设 2 个喷粉柜，喷粉过程会产生一定量的粉尘，污染因子为颗粒物。项目喷涂采用静电粉末喷涂工艺，其工艺原理为采取高电压使粉末带负电，借助静电引力附着在工件上。

参考《排放源统计调查产排污核算方法和系数手册》（环境部公告2021 年第24号）-机械行业系数手册内14 涂装中“粉末涂料-喷塑”工艺对应的颗粒物产物系数 300kg/t 原料，项目年用树脂粉末 28t/a，则喷粉粉尘产生量为 8.4t/a，喷粉工序年工作时长 2400h，则喷粉粉尘产生速率为 3.5kg/h。喷粉工序在相对密闭的喷粉室内进行，产生的粉尘经整室负压收集后通过配套“双层滤芯除尘系统”收集，收集后的粉末回用于生产，喷粉柜的喷粉粉尘采用负压密闭收集，收集效率可达 95%，滤芯除尘效率为 99%，喷粉工序位于独立的喷粉房内，未被收集和处理的粉尘量为 0.4998t/a，其中大部分（90%）沉降于喷粉房地面，少量粉尘（10%）通过喷粉房的门窗在车间无组织排放，无组织最终排放量为0.0500t/a（0.0208kg/h）。

## C.机加工金属粉尘（无组织）

项目会对金属件进行切割和冲压等机加工，过程中会产生金属粉尘，污染因子为颗粒物。参考《排放源统计调查产排污核算方法和系数手册》（环境部公告 2021 年第24号）-机械行业系数手册内04 下料中切割机切割工艺颗粒物产污系数 5.30kg/t•原料。本项目需切割和机加工的工件约占金属年用量 70%，则切割及机加工量为 350t/a，则机加工金属粉尘产生量为 1.855t/a；产生的金属颗粒物比重较大，易于沉降，90%粉尘可在操作区域附近沉降，金属颗粒物沉降量约为 1.6695t/a，只有 10%部分以无组织的形式扩散到大气中形成粉尘，则机加工工序金属颗粒物排放量约为 0.1855t/a，年工作时间约2400h，排放速率约 0.0773kg/h，排放情况表 4-8。

## D.抛丸金属粉尘（G1 排气筒）

项目喷粉前需要对板材配件进行抛丸，抛丸过程会产生金属粉尘，污染因子为颗粒物。参考《排放源统计调查产排污核算方法和系数手册》（环境部公告 2021 年第 24 号）-机械行业系数手册内 06 预处理中抛丸、喷砂、打磨、滚筒工艺颗粒物产污系数 2.19kg/t•原料。本项目板材年用量为 400t/a，则该工序金属颗粒物产生量为 0.876t/a，抛丸工序年工作时间为2400h，则产生速率为 0.365kg/h。抛丸工序在密闭的抛丸室进行，抛丸粉尘经设备内部直接收集，通过设备内部配套的布袋除尘设施处理后引至 15m 排气筒 G1 排放，有组织及无组织排放情况表 4-8。

项目焊接工序使用无铅焊丝会产生焊接烟尘，主要污染物为焊接烟尘，污染因子以颗粒物表征。焊接烟尘产生量参考《排放源统计调查产排污核算方法和系数手册》（环境部公告 2021 年第 24 号）-机械行业系数手册内 09 焊接表中实芯焊丝-氩弧焊、二氧化碳保护焊工艺的颗粒物产污系数：“9.19kg/t-原料”及手工电弧焊工艺的颗粒物产污系数：“20.2kg/t-原料”进行计算。项目焊接材料（无铅焊丝）使用量为 1t，则焊接烟尘产生量约为0.0202t/a，产生量少，以无组织形式排放，焊接工序年工作时间约 2400h，则排放速率约为 0.0084kg/h。

## 除尘设施：

项目拟设布袋除尘设施对抛丸工序产生的颗粒物进行处理；拟采用双层滤芯除尘设施对喷粉工序产生的颗粒物进行处理；

除尘工作原理如下，含尘气流通过负压穿过滤料或进入布袋中，在通过滤料的孔隙时，粉尘被捕集于滤料上，透过滤料的清洁气体由排出口排出。沉积在滤料上的粉尘，可在机械振动的作用下从滤料表面脱落，落入灰斗中。布袋除尘器捕获粉尘微粒可达 0.1 微米，具有很高的净化效率。它比电除尘器结构简单、投资省、运行稳定，可以回收高电阻率粉尘；

根据《袋式除尘工程通用技术规范》（HJ 2020-2012），布袋除尘设备和滤料除尘设施的处理效率为 99%,定期对布袋和滤芯进行清理，因此，在保证能耗和的布袋/滤芯完整性的条件下，项目选用布袋除尘设施和双层滤芯除尘设施能够满足处理工艺的要求。

项目所使用的“两级活性炭吸附”、“布袋除尘系统”、“滤芯除尘系统”等废气治理设施均为《排污许可证申请与核发技术规范 汽车制造业》（HJ971-2018）表 17 推荐的可行技术，故本项目废气治理设施可行。

## ①冷却水

项目需要使用冷却水进行间接冷却，冷却水经冷却塔冷却后循环使用，定期排出部分水量，并适当加入新鲜水补充因蒸发和损失的水分。项目使用的冷却塔循环水量为 $1 0 \mathrm { m } ^ { 3 } / \mathrm { h }$ 参考《工业循环冷却水处理设计规范》（GB50050-2017），循环冷却水系统蒸发水量约占循环水量的 2.0%，排放水量约占循环水量的 0.4%，则新鲜水补充量约占循环水量的2.4%。项目日均工作时长 8小时，年工作300天，总循环水量为 $2 4 0 0 0 \mathrm { m } ^ { 3 } / \mathrm { a }$ ，新鲜补充水量为 $5 7 6 \mathrm { m } ^ { 3 } / \mathrm { a }$ ，补充的均为自来水，不添加任何助剂。定期排水量为 $9 6 \mathrm { m } ^ { 3 } / \mathrm { a }$ ，本项目为间接冷却，循环冷却水中污染物成分较为简单且浓度不高，主要为管道中带入的悬浮物，作为清净下水定期排入雨水管网。

根据《环境影响评价技术导则地表水环境》（HJ2.3-2018）中的规定：“没有相关行业排放标准要求的通过工程分析合理确定，应统计含热量大的冷却水的排放量，可不统计间接冷却水、循环水以及其他含污染物极少的清净下水的排放量”。因此项目间接循环冷却水作为清净下水定期排入雨水管网，不计入项目污水排放量。

## （3）噪声污染防治措施及可行性分析

为了进一步减少本项目产生的噪声对周围环境造成的影响，对此建议建设单位：

①优先选用低噪声型号的设备，采取隔声、基础减振等处理措施；

②合理布局生产设备，生产设备噪声源合理布置在生产车间内，对产生噪声较大的设备尽量布置于远离居民区的一侧，同时企业加强生产区域门窗的隔声性能。

③定期对生产设备进行维修保养，确保各部件正常运转；

④空压机设备应重点：

A.尽量将空压机放置在独立空间，做好四面的隔音措施；

B.在其进出风口装消声器，使风机产生噪声大部分为消声器所消减；

C.设置减振器或减振垫以隔绝设备的振动，以减弱设备振动对结构的影响；

D.落实日常的维护保养；

E.一步加强环境管理，严禁夜间 22:00\~次日 06:00 时，进行高噪声设备的生产作业。

以上噪声治理措施容易实施，技术成熟可靠，投资费用较少，在经济上是可行的，对

项目所在区域的声环境影响很小。

项目在生产过程中需要使用机油对机械设备进行维护，此过程中会产生废机油。根据建设单位提供资料可知，年使用机油 0.1t，一般情况下，废机油的产污系数按 50%算，因此废机油产生量约为 0.05t/a，根据《国家危险废物名录》（2021 年版）可知，废机油属于危险废物，类别为HW08，废物代码900-249-08，全部收集后，定期交有相应资质的危废单位回收处理。

## ②废机油桶

本项目使用的机油为桶装，净含量 25kg/桶。根据上文可知，项目使用机油 0.1t/a，故废机油桶的产生量共 4 个。空桶质量为 1.5kg/个，则项目年产生废机油桶 0.006t/a，根据《国家危险废物名录》（2021 年版）可知，废机油桶属危险废物，废物类别为 HW08，废物代码900-249-08，全部收集后，定期交有相应资质的危废单位回收处理。

## ③含油废抹布和手套

项目需用到抹布擦拭机械设备上的机油，此过程会产生含油废弃抹布，员工工作穿戴的手套也会因粘有油污和破损被遗弃。根据建设单位提供资料可知，项目含油抹布和手套的产生量约为 0.002t/a，全部收集后，定期交有相应资质的危废单位回收处理。根据《国家危险废物名录》（2021 年版）可知，含油废抹布和手套属危险废物，废物类别为 HW49，废物代码900-041-49，全部收集后，定期交有相应资质的危废单位回收处理。

④废活性炭

项目使用“二级活性炭吸附”对废气进行吸附处理，对照《国家危险废物名录》（2021年版），废活性炭属于危险废物，编号为 HW49 其他废物，代码为 900-039-49，全部收集后，定期交有相应资质的危废单位回收处理。

项目采用颗粒状活性炭，根据《广东省工业源挥发性有机物减排量核算方法（2023年修订版）》表3.3-3废气治理效率参考值，吸附比例建议取 10%。根据前文工程分析，项目需处理有机废气量为 0.1858t，理论需要1.858t 活性炭，本项目颗粒状活性炭风量＜0.5m/s，达到吸附处理要求。项目两级活性炭吸附箱内活性炭装载量为 2.08t，吸附塔内的活性炭每季度更换1次，每年更换4次，则项目活性炭年更换量为 8.32t，大于理论所需活性炭量。则废活性炭产生量=活性炭填装量+有机废气吸附量=8.5058t/a。

## 5、地下水、土壤

## （1）影响途径

## ①大气沉降

大气沉降是指大气中的污染物通过一定的途径被沉降至地面或水体的过程，分为干沉降和湿沉降，是土壤污染的重要途径之一。

本项目主要工序为注塑、喷粉、固化、机加工、焊接、抛丸等，本项目大气污染因子主要是臭气浓度、非甲烷总烃、颗粒物、 ${ \mathrm { S O } } _ { 2 } .$ 、NOx 等，可以在大气中被稀释和降解，项目已作硬底化处理，因此不考虑大气沉降的影响。

## ②物质泄漏

原料泄漏：项目原料仓库的机油存在泄漏风险。物料建议使用托盘存放，储存在专用物料区，控制储存量，车间地面进行防渗处理，设置防渗墙裙，现场配置泄漏吸附收集等应急器材，防止泄漏范围扩大，原料仓库作硬底化处理；天然气管道设置可燃气体探测装置和紧急关闭阀门。

危险废物泄漏：项目废机油存在泄漏风险。项目废机油的储罐应做好防风、防雨、防渗漏等措施，废油产生量较少，运营期间做好巡查工作，不会存在废机油泄漏污染土壤、地下水的情况。

建设单位应严格按照消防及安监部门的要求，做好防范措施，制定完善的管理制度及相应的应急处理措施，设立以建设单位为环境风险责任主体的突发环境事故应急组织机构，以便采取更有效的措施来监测灾情及防止污染事故的进一步扩散。在采取有效措施的情况下，本项目风险事故发生概率很低，本项目环境风险在可接受的范围内。
