## 6、水平衡分析

## （1）生活用水及排水

项目总人数为16人，均不在厂内食宿，年工作时间为300天。根据《用水定额 第3部分：生活》（DB44/T1461.3-2021）中办公楼（无食堂和浴室）的生活用水定额（先进值），员工办公生活用水定额取10m3 /（人·a），则项目生活用水量为160m3 /a，排放系数取 0.9，则污水产生量为 $1 4 4 \mathrm { m } ^ { 3 } / \mathrm { a } \ \mathrm { ~ ( 0 . 4 8 \mathrm { m } ^ { 3 } / \mathrm { d } ) }$ 生活污水经三级化粪池预处理后引至容桂第二污水处理厂处理。

本项目从事铝制品的表面处理，具体工艺流程如下：

图 2-2 铝制品表面处理工艺流程及产污环节示意图

铝制品表面处理工序流程说明：

除油及水洗：工件放入除油槽以去除表面油污，除油剂在槽液中浓度约为6%。浸没时间约 5 分钟，工作温度约50℃。每三个月对除油槽进行清理，整槽更换一次槽液，产生除油废水。

除油后工件需使用自来水进行水洗，以去除工件表面残留除油剂，水洗槽水洗废水以固定流量（6L/min）溢流外排，产生水洗废水。

碱洗和水洗：工件除油及水洗后进行碱洗工序，碱洗槽中加入氢氧化钠及亚硝酸钠，其中槽液氢氧化钠浓度约为 9.8%、亚硝酸钠 5%左右，槽液温度为常温，工件浸没在碱洗槽液内时间约为半分钟。碱洗槽液每三个月整槽更换一次，有碱洗废水、碱雾及槽渣产生。

碱洗后工件需使用自来水进行水洗，在水中浸没约 60秒钟去除表面碱液。水洗槽水洗废水以固定流量（6L/min）溢流外排，产生水洗废水。

酸洗和水洗：工件碱洗及水洗后进行酸洗工序，酸洗是工件浸入溶液中的酸洗处理，使工件表面平整光滑。酸洗槽中加入硫酸、磷酸，槽液中浓度约为硫酸15%、磷酸50%，槽液温度为常温。酸洗槽定期补充损耗的药剂，槽液半年整槽更换一次，有阳极氧化废水、硫酸雾、噪声产生。

酸洗后工件进入水洗槽进行水洗，然后进入水洗槽在水中浸没 60秒左右以去除表面酸洗酸液；水洗使用自来水，水洗槽水洗废水以固定流量（6L/min）溢流外排，产生水洗废水。

阳极氧化和水洗：阳极氧化主要通过电解使工件表面产生防腐蚀氧化膜。其原理是以工件为阳极置于电解液中，利用电解作用使其表面形成氧化薄膜。

氧化槽液由 98%硫酸与水按比率配兑而成，槽液硫酸浓度约为16%，槽液温度20℃，对应的时间范围为 15分钟。氧化槽内槽液定期补充氧化药剂（硫酸），氧化槽每年更换底部20%槽液，有阳极氧化废水、硫酸雾、噪声产生。

阳极氧化后，工件进入水洗槽进行水洗，水洗槽水洗废水以固定流量（6L/min）溢流外排，产生水洗废水。

封闭和水洗：未封闭的阳极氧化膜，由于大量微孔孔内的面积，使暴露在环境中的工件有效面积增加至几十倍到上百倍，为此相应的腐蚀速度也大为增加。因此从提高耐腐蚀性和耐污染性考虑，必须进行封闭处理。项目使用封闭剂对氧化膜进行封闭处理，以增加氧化膜的防腐蚀性能以及减弱对杂质或油污的吸附能力，便于保持其光洁的表面质量，同时可以使染色产品的氧化膜保持持久的鲜艳的色泽。封闭分为常温及中温封闭，工作时槽液温度分别为常温或$7 0 \mathrm { { } ^ { \circ } C }$ 左右，封闭时间一般为 10 分钟左右，槽液中醋酸镍浓度约为10\~25g/L。槽液每年整槽更换一次，产生封闭废水和废槽渣。

封闭后需进行水洗，在水中浸没约60s 以去除表面封闭剂。水洗槽水洗废水以固定流量（6L/min）溢流外排，产生水洗废水。

烘干：将封闭及水洗处理后的工件送入烘干炉中烘烤干燥，烘干炉使用电能。该过程产生少量噪声。

检验：对烘干结束后的产品进行检验，该过程产生少量不合格品。

包装：对检验结束的合格品手工进行包装。

成品：包装好即得成品，储存至成品区待售。

参考《污染源强核算技术指南 电镀》（HJ984-2018）附录 B 的表 B.1 单位镀槽液面面积单位时间废气污染物产污系数，在质量浓度大于 $1 0 0 \mathrm { g / L }$ 的硫酸中浸蚀、抛光的硫酸雾产生量为 $2 5 . 2 \mathrm { g } / ( \mathrm { m } ^ { 2 } { \cdot } \mathrm { h } )$ ，则本项目的硫酸雾产污系数取值 $2 5 . 2 \mathrm { g } / ( \mathrm { m } ^ { 2 } { \cdot } \mathrm { h } )$

## ②依托容桂第二污水处理厂可行性分析

本项目属于容桂第二污水处理厂的服务范围内，容桂第二污水处理厂处理规模为3万m3 /d，本项目生活污水的排放量为 $1 4 4 \mathrm { m } ^ { 3 } / \mathrm { a }$ （0.48m3 /d），占容桂第二污水处理厂处理能力的0.0016%，容桂第二污水处理厂尚有足够的容量容纳本项目产生的生活污水，因此项目生活污水经处理后排入市政管网引至容桂第二污水处理厂集中处理，不会对容桂第二污水处理厂造成较大的冲击。

## ①生产废水源强核算

本项目生产废水包括除油、碱洗、酸洗、阳极氧化；除油、碱洗、酸洗、阳极氧化后的水洗、喷淋塔更换；封闭及水洗废水。其中除油、碱洗、酸洗、阳极氧化后的水洗废水和喷淋塔更换废水作为化学前处理清洗废水，主要污染因子为 $\mathsf { p H } , \mathsf { C O D } _ { \mathsf { C r } } ,$ SS、氨氮、石油类、总氮、总磷，先经厂区预处理设施（中和+混凝沉淀）预处理后，排至园区废水处理站的化学前处理清洗废水预处理系统（混凝沉淀+气浮）处理，出水汇入综合废水处理系统（厌氧+缺氧+接触氧化+沉淀）处理；除油、碱洗、酸洗、阳极氧化废水作为浓废水，主要污染因子为 pH、 $\mathrm { C O D } _ { \mathrm { C r } }$ 、SS、氨氮、石油类、总氮、总磷，直接排至园区废水处理站的浓废水预处理系统（芬顿氧化+混凝沉淀+气浮）处理，出水汇入综合废水处理系统处理；封闭及水洗废水作为含镍废水，主要污染因子为 pH、 $\mathrm { C O D } _ { \mathrm { C r } }$ 、SS、氨氮、总镍，先经厂区预处理系统（中和+混凝沉淀）预处理后，排至园区废水处理站含镍废水预处理系统（混凝沉淀+过滤+离子交换）处理，出水汇入综合废水处理系统（厌氧+缺氧+接触氧化+沉淀）处理。最终生产废水经处理达标后，部分（约 70%）通过园区废水处理站总排放口（水-02）排至眉蕉河，部分（约

## ②依托华腾金属工业楼集中废水处理站可行性分析

本项目化学前处理清洗废水、浓废水、含镍废水分质收集，其中化学前处理清洗废水、含镍废水先经各自的自建的废水预处理设施（主体工艺均为中和+混凝沉淀）处理，三股废水分别进入园区配置的废水收集管道，再经各自废水预处理单元处理后汇入综合废水处理系统，采用“厌氧+缺氧+接触氧化+沉淀”处理工艺处理达标后部分排入眉蕉河。

顺德区容桂金属表面处理产业园废水处理站废水采用分质处理，分为 5种废水：化学前处理清洗废水、磷化废槽液、含镍废水、浓废水、有机废水，各股废水先各自进行预处理，然后再一并经过综合废水处理设施处理。化学前处理清洗废水经“混凝沉淀+气浮”工艺进行预处理后排入综合废水处理设施的中间水池；磷化废水槽液采用“二级反应沉淀”预处理后与含镍废水一起经“混凝沉淀+过滤+离子交换”处理后排入综合废水处理设施的中间水池；浓废水和有机废水采用“芬顿氧化+混凝沉淀+气浮”预处理后排入综合废水处理设施的中间水池；综合废水采用“厌氧+缺氧+接触氧化+沉淀”处理后，部分进行深度处理后回用，部分达标排入眉蕉河。废水处理站总规模为 2540t/d，产生的污泥采用压滤机脱水处理后作为危险废物交给有资质单位处理。园区处理站处理工艺如下：

## 工艺流程说明：

综合废水为5股经各自预处理后混合的废水，综合废水经过生化系统处理达标。生化系统采用厌氧-缺氧-接触氧化，是典型的脱氮除磷工艺，在进行去除 BOD5、CODCr、SS的同时可生物脱氮除磷。

①在中间池混合后的污水用泵泵至厌氧池。厌氧生活过程一般包括四个阶段，即水解阶段、酸化阶段、酸性衰退阶段以及甲烷化阶段等，主要通过控制厌氧池的水力停留时间和选育的细菌种属以达到上述目的。厌氧池内通过反应器的填料及微生物将进水的颗粒物质和胶体物质截留和吸附，截留下来的物质吸附在组合填料上，同时在产酸菌的协同作用下将大分子物质，难于生物降解物质，氧化为易于生物降解低分子物质，为后序好氧生化处理创造好条件。厌氧生物滤料填料选用组合填料，该填料比表面积大，有一定的吸附能力，微生物能够在其上形成空间结构的生物膜，其活性高，生物量浓度比通常填料提高十倍。

②然后进入缺氧池。污水中的有机氮、蛋白氮在好氧条件下，由硝化菌变成硝酸盐氮，通过内回流的方式回到前端缺氧池。在缺氧池内反硝化细菌将内回流带入的硝酸盐通过生物反硝化作用,转化成氮气逸入大气中，从而达到脱氮的目的。

③然后进入接触氧化池，废水中绝大部分的有机污染物在此得到彻底分解。生物接触氧化法是生物膜法处理工艺中的一种，在生化池内充填生物填料作为生物膜的载体，池底曝气对污水进行充氧，并使池体内污水处于流动状态，以保证污水与污水中的填料充分接触，避免池中存在污水与填料接触不均的缺陷。生物膜吸附废水中的有机物，在有氧的条件下，有机物由微生物氧化分解，废水得到净化。生物膜生长至一定厚度后，填料壁的微生物会因缺氧而进行厌氧代谢，产生的气体及曝气形成的冲刷作用会造成生物膜的脱落，并促进新生物膜的生长，此时，脱落的生物膜将随出水流出池外。

生物接触氧化池内的生物膜由菌胶团、丝状菌、真菌、原生动物和后生动物组成。在活性污泥法中，丝状菌常常是影响正常生物净化作用的因素；而在生物接触氧化池中，丝状菌在填料空隙间呈立体结构，大大增加了生物相与废水的接触表面，同时因为丝状菌对多数有机物具有较强的氧化能力，对水质负荷变化有较大的适应性，所以是提高净化能力的有力因素。

厌氧条件下，聚磷菌释放磷，在好氧条件下，聚磷菌吸收液体中的磷，形成磷酸盐，贮存在细胞内，然后通过排放剩余污泥，将磷从系统中排除。

好氧池的充氧系统由曝气器和罗茨风机组成，曝气是水处理整体工程中最为重要的系统，其它设施基本上都是围绕曝气系统而建，所以曝气的好坏会直接影响出水效果。一般使用的曝气方式有射流曝气、表面曝气机、微孔曝气器和旋混式曝气器等。通过综合考虑溶氧效果，投资和运行成本，以及日后的维护操作，本设计方案选用旋流曝气器。旋流曝气器是一种新型曝气装置，该产品具有耐腐蚀、氧利用率高、气孔不易堵塞，污水不倒灌，环向受力，受力均匀，使用寿命长和安装维修方便，系统价格低廉价等主要特点。旋流曝气器，通过旋流、阻挡、碰撞等作用，使具有相当大的上浮动力的气泡得到了充分的破碎，从而实现曝气器的大孔排气细泡运行效果，完全摆脱了“微小孔隙方可以产生细泡”的概念。采用大孔排气方式经动力扩散作用形成细泡，使旋混曝气器具有排气阻力损耗小，布气均匀，不易堵塞，效率高，免维修免更换的优点，而且还具有系统止回、排气孔隙自动高速的技术特点。

④然后进入二沉池，沉淀分离生物处理时由于微生物的新陈代谢而老化脱落的生物膜(即生化污泥)，沉淀分离出来的生化污泥部分回流至厌氧池，部分则排至污泥池进行脱水处理。

⑤二沉池出水一部分达标排放至眉蕉河，一部分水进行深度处理后回用于生产中。

废水处理设施是将废水中的金属离子、磷酸盐、SS、CODCr、BOD5、氨氮、石油类等污染物质，转化成污泥。污泥含水率高、有机物含量较高，不稳定，且易腐化，还含有致病菌和寄生虫卵。因此，必须对污泥进行处理和处置，避免造成二次污染。污泥处理系统主要包括：污泥池、污泥浓缩池。混凝沉淀池产生的污泥定期排入污泥池，通过泵打入污泥浓缩池浓缩处理，所产生的泥饼含重金属污染物，属危险废物，应交有资质的单位外运处置，滤液则回流至调节池再次处理，以防止产生二次污染。

以上处理工艺在表面处理工业生产应用已较成熟，参考《顺德区容桂金属表面处理产业园（华腾金属工业楼）公辅工程建设项目环境影响报告书》（佛环03环审[2020]第0076 号）项目集中废水处理站各处理站各处理单元处理效果预测表的各处理设施的处理效率，预计本项目所有含镍废水的总镍在园区废水处理站预处理排放口排放浓度、所有生产废水污染物浓度在园区废水处理站排放口的排放浓度可达到《电镀水污染物排放标准》（DB44/1597-2015）表2 规定的珠三角水污染物排放限值。

华腾金属工业楼集中废水处理站的总处理规模为2540t/d。本项目生产废水排放量为 5384.768m3 /a（17.95m3 /d），占比为 0.7%，华腾金属工业楼集中废水处理站尚有足够的容量容纳本项目的生产废水。本项目生产废水依托华腾金属工业楼集中废水处理站处理，不会对园区废水治理设施造成冲击负荷，也不会影响其正常运行，满足依托的环境可行性要求。

综上所述，本项目生产废水依托园区废水处理站的废水处理设施处理是可行的。

## 3、水环境影响评价结论

项目不设员工饭堂和宿舍，生活污水主要污染因子为 CODCr、BOD5、NH3-N、SS等，经三级化粪池预处理达到广东省地方标准《水污染物排放限值》（DB44/26-2001）第二时段三级标准引至容桂第二污水处理厂处理，满足污水厂的纳污要求，不会对污水厂造成冲击负荷，经处理后的尾水达到《城镇污水处理厂污染物排放标准》（GB18918-2002）一级A标准及广东省地方标准《水污染物排放限值》（DB44/26-2001）第二时段一级标准的较严值，尾水排入鸡鸦水道。生产废水分质收集，其中化学前处理清洗废水、含镍废水分别经自建的废水预处理设施处理，三股废水均达到园区废水处理站的纳管标准，进入园区废水处理站各自的废水预处理单元处理，处理后汇入综合废水处理系统处理，处理后的含镍废水的总镍在园区废水处理站预处理排放口排放浓度、所有生产废水污染物浓度在园区废水处理站排放口的排放浓度达到《电镀水污染物排放标准》（DB44/1597-2015）表 2 规定的珠三角水污染物排放限值后，部分（约70%）通过华腾金属工业楼集中废水处理站总排放口（水-02）排入眉蕉河，部分（约30%）经深度处理后回用。综上，采取有效的污染治理措施后，项目废水排放最终对地表水体造成的环境影响不大，其地表水环境影响是可接受的。

## 1、噪声影响及达标分析

## 预测模型与预测方法

为了解项目噪声对厂界噪声的影响，本次评价采用预测模式对其影响进行预测。

（1）项目生产设备主要位于生产车间，将项目生产车间视为一个等效噪声源，各设备于等效噪声源的噪声贡献值可通过以下公式计算：

$$
L e q g = 1 0 \log ( \frac { 1 } { T } { \sum _ { i } } t _ { i } 1 0 ^ { 0 . 1 L { A } _ { i } } )
$$

式中： $\mathrm { L _ { e q g } } { \mathrm { - } }$ 建设项目声源在等效噪声点的等效声级贡献量，dB(A)；

$\mathrm { L } _ { \mathrm { A i } ^ { - } }$ i 声源在预测点产生的 A声级，dB(A)；

T— 预测计算的时间段，s；

ti— i 声源在T时段内的运行时间，s。

（2）预测点的预测等效声级（Leq）计算公式：

$$
L \mathbf { e } \mathbf { q } = 1 0 \log ( 1 0 ^ { 0 . 1 L \mathbf { e q g } } + 1 0 ^ { 0 . 1 L \mathbf { e q b } } )
$$

式中： $\mathrm { L _ { e q } } ^ { }$ —点声源在预测点产生的声压级；

$\operatorname { L } _ { \mathrm { e q g } }$ —建设项目声源在预测点的等效声级贡献值，dB（A）；

$\operatorname { L } _ { \mathrm { e q b } ^ { - } }$ —预测点的背景值，dB（A）；

## （3）户外声传播衰减计算

户外声传播衰减包括几何发散（Adiv）、大气吸收（Aatm）、地面效应（Agr）、屏障屏蔽（Abar）、其他多方面效应（Amisc）引起的衰减。距声源点r处的A 声级按下式计算：

$$
L _ { \mathrm { p } } \mathrm { ( \bf ~ r ) } = L \mathrm { p } \mathrm { ( \bf ~ r 0 ) } - ( A \mathrm { d i v } + \mathrm { A a t m } + \mathrm { A g r } + \mathrm { A b a r } + \mathrm { A m i s c } )
$$

$\mathrm { r } _ { 0 ^ { - } }$ —参考位置距声源的距离，m；

各声源由于厂区内外其它建筑物的屏障衰减、空气吸收引起的衰减以及由于云雾、温度梯度、风及地面其它效应等引起的衰减量难确定其取值范围，且其引起的衰减量不大，保守起见，本评价预测计算中只考虑厂区内各声源至受声点（预测点）的距离衰减及车间墙体隔音量。

## ③废水预处理污泥

本项目生产废水中的化学前处理清洗废水、含镍废水分质分别通过厂区内的废水预处理设施处理（主体工艺均含有中和+混凝沉淀），预处理过程中会产生废水处理污泥，根据《国家危险废物名录（2021年版）》，本项目产生的废水处理污泥参照含油废水处理中隔油、气浮、沉淀等处理过程中产生的浮油、浮渣和污泥，其危险废物类别为HW08废矿物油与含矿物油废物，代码为900-210-08。项目厂区废水预处理量合计为5347.328t/a，参考《集中式污染治理设施产排污系数手册》（环境保护部华南环境科学研究所，2010年修订）中“表4工业废水集中处理设施的物化与生化污泥综合产生系数表”其他工业含水污泥产生系数为6吨/万吨废水处理量计，则污泥产生量约为3.208t/a（含水率为80%）。污泥经压滤设备压滤成干污滤饼，压滤后污泥含水率为50%，则压滤后的废水处理污泥量为1.2832t/a（含水率为50%）。

## 4、固体废物管理要求

## （1）生活垃圾、一般工业固体废物

根据《中华人民共和国固体废物污染环境防治法》要求，建设单位应做好以下防治措施：

①建设单位和个人应当依法在指定的地点分类投放生活垃圾。禁止随意倾倒、抛撒、堆放或者焚烧生活垃圾。

②建设单位应当建立健全工业固体废物产生、收集、贮存、运输、利用、处置全过程的污染环境防治责任制度，在室内建设一个占地面积≥5m2的一般工业固废暂存间，建立工业固体废物管理台账，如实记录产生工业固体废物的种类、数量、流向、贮存、利用、处置等信息，实现工业固体废物可追溯、可查询，并采取防治工业固体废物污染环境的措施。

③禁止向生活垃圾收集设施中投放工业固体废物。

④建设单位委托他人运输、利用、处置工业固体废物的，应当对受托方的主体资格和技术能力进行核实，依法签订书面合同，在合同中约定污染防治要求。

⑤建设单位应当向所在地生态环境主管部门提供工业固体废物的种类、数量、流向、贮存、利用、处置等有关资料，以及减少工业固体废物产生、促进综合利用的具体措施，并执行排污许可管理制度的相关规定。

## （2）危险废物

项目拟于车间东侧建设一个占地面积10m2的危险废物暂存间，针对危险废物提出环境管理要求如下：

①设置独立的危险废物暂存间并有专人负责管理，危险废物暂存间应做到防风、防雨、防渗漏，门口处设置围堰，内部地面和墙裙做耐腐蚀硬化处理。

②危险废物应采取分类收集，按类别放入相应的容器内，禁止生活垃圾、一般固体废物与危险废物混放，不相容的危险废物分开存放并设有隔离间隔断。

③在收集、运输、贮存危险废物的设施、场所设置规范的警示标志、标识、标牌。

④制定危险废物管理计划，清晰描述危险废物的产生环节、种类、危害特性、产生量、利用处置方式等。

⑤按要求如实申报登记危险废物的种类、产生量、贮存、处置等有关情况。

⑥建设单位必须严格执行危险废物转移计划报批和依法运行危险废物转移联单，并通过信息系统登记转移计划和电子转移联单。企业还需健全产生单位内部管理制度，包括落实危险废物产生信息公开制度，建立员工培训和固体废物管理员制度，完善危险废物相关档案管理制度；建立和完善突发危险废物环境应急预案，并报当地环保部门备案。

⑦建设单位须根据管理台账和近年生产计划，制订危险废物管理计划，并报当地环保部门备案。台账应如实记载产生危险废物的种类、数量、利用、贮存、处置、流向等信息，以此作为向当地环保部门申报危险废物管理计划的编制依据。

## 5、固体废物环境影响分析结论

综上所述，项目固体废物经上述“减量化、资源化、无害化”处置后，可将固废对周围环境产生的影响减少到最低限度，不会对周围环境产生明显的影响。

## 五、地下水、土壤

本项目属于污染影响型，影响时段为运营期。本项目的生活污水经三级化粪池预处理后通过市政污水管网引至容桂第二污水处理厂处理；生产废水经自建的废水预处理设施处理后，依托华腾金属工业楼集中废水处理站处理达标后部分通过华腾金属工业楼集中废水处理站总排放口（水-02）排至眉蕉河；危险废物分类暂存于危废暂存间内，危废暂存间按照《危险废物贮存污染控制标准》（GB 18597-2023）要求落实好“防雨、防渗、防泄漏”等措施，定期交由有处理资质的单位接收处置，租用的厂房和周边环境地面已做好水泥面硬化防渗措施，对地下水环境和土壤环境不存在污染途径。

综上所述，本项目不存在地下水、土壤污染途径，也不涉及土壤环境影响评价因子，因此，本项目不开展地下水、土壤环境影响评价。

本项目对周边生态环境无明显影响。

## （2）生产废水泄漏事故风险防范措施

①安排专人管理厂区内的表面处理槽体、厂区废水预处理设施，定期巡视及保养，一旦发现生产废水外漏，应关闭相应的阀门并采取应急封堵措施，及时截流并转移泄漏的生产废水，防止泄漏的生产废水通过雨水管等排出厂外。

②表面处理槽体、厂区废水预处理设施附近的地面应采取防渗防泄漏措施，并且定期对生产废水排至华腾金属工业楼集中废水处理站的输送管道进行检测和维护，降低因输送管道损坏造成生产废水泄漏的概率；一旦发生管道损坏，生产车间应立即停止生产，待废水输送管道抢修完毕后恢复生产。

## （3）环保治理设施故障风险防范措施

①定期对厂区的废水预处理设施和废气预处理设施进行检测和维修，降低因环保设备故障造成生产废气/废水事故排放的概率。

②一旦发生环保设备故障，生产车间应立即停止生产，待故障点抢修完毕后恢复生产。

## （4）火灾/爆炸事故引起的伴生/次生污染排放风险防范措施

①严格企业内部安全生产管理体系、加强质量管理体系的监督、对操作工人进行生产前的安全培训，制定严格的生产操作流程，任何违规和违章操作即刻进行处理，加强各种辅助化学品的安全管理工作；

②加强防火安全管理，对进出厂区的人员进行登记和管理；原料和危险废物要分类储存，项目厂区要做好防火措施，远离一切火源，禁止堆放其他易燃物品和杂物，配置相应的应急设施，定期对应急设施进行检查；③采取防静电防爆措施，每年对防雷接地装置以及电气设备的接地保护线进行检测，保证防火防爆安全装置完好，使静电和雷电能够及时得到地释放，生产区域设置火灾报警仪；

④保证灭火降温装置（消防系统）完好，起到防火的效果；

⑤依托华腾金属工业楼设置的雨水总排口应急闸门和应急事故池，防止发生事故时事故废水或消防废水通过雨水管网流入附近地表水体。
