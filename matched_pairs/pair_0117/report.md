## 2、工艺流程说明：

1）手机保护套生产工艺流程说明：项目将外购回来的A胶、B胶人工按比例倒入混胶机内混胶，混胶得到的胶水放入真空机/高压仓内进行抽真空/加压来消除气泡，消泡后得到环氧树脂 AB 胶。由于消泡后得到的环氧树脂 AB胶与空气长期接触容易导致硬化，故将使用放置于保温箱中维持其液态状态。

根据客户定制要求，项目将外购的植物标本放在手机保护套表面后通过人工使用混胶得到的环氧树脂AB 胶/人工混合后的环氧树脂AB胶进行粘合，或者使用激光雕刻机在外购的手机保护套表面刻绘图案（主要以激光作为加工媒介，加工温度为 200℃左右，加工材料表面在激光雕刻照射下瞬间的熔化和气化的物理变形，能使激光雕刻达到加工的目的）；然后人工在手工装配台上对粘合或激光雕刻后的手机保护套进行封胶过程，主要是在手机保护套的表面均匀洒上金属粉后再均匀的涂抹上环氧树脂 AB 胶并放置金属配件。最后，封胶后的手机保护套在一般情况下通过自然晾干得到成品，但在时间紧或加急生产等其他特殊情况时需使用烤箱（电人工混合，固化温度在60-80℃）对封胶后的手机保护套进行固化，最后使用包装材料进行包装得到成品。

注：项目人工混合主要是将硬化的环氧树脂AB 胶置于搅拌杯内倒入少量的热水（由烧水炉对自来水进行人工混合得到，温度为100℃）进行浸泡软化且加入水性颜料后人工搅拌使其混合，由于加入的热水量少，该部分经过蒸发或进入胶水中，故无废水产生。

2）木工艺品工艺流程说明：根据客户的需求，项目使用锯台、介机对外购的木材进行开料后再使用锯台进一步切割得到所需的尺寸后使用刨床进行压刨加工，接着使用雕刻机对其进行雕刻，再使用手动抛光机、砂轮机进行打磨使得工件表面光滑后使用钻孔机进行钻孔得到半成品。

项目将外购回来的A胶、B胶经人工按比例倒入混胶机内进行混胶得到胶水，混胶得到的胶水放入真空机/高压仓内进行抽真空/加压来消除气泡，消泡后得到环氧树脂AB 胶。由于消泡后得到的环氧树脂 AB胶与空气长期接触容易导致硬化，故需放置于保温箱中维持其液态状态。

接着，人工将半成品放在手工装配台并洒上金葱粉和装配金属配件后再将消泡后得到的环氧树脂 AB 胶浇注至半成品表面，然后通过自然晾干得到成品，或在时间紧或加急生产等其他特殊情况时需使用烤箱进行固化，最后使用包装材料进行包装得到成品。

3）首饰生产工艺流程说明：项目环氧树脂AB 胶的生产工艺流程和木工艺品的环氧树脂AB 胶一样，具体流程说明详见上面表述。项目人工将外购植物标本、金葱粉、金属配件放置在手工装配台配套的模具内后浇注消泡后得到的环氧树脂AB 胶，然后通过自然晾干得到成品，或在时间紧或加急生产等其他特殊情况时需使用烤箱进行固化，最后使用包装材料进行包装得到成品。

## 2）非甲烷总烃

项目激光雕刻加工温度为200℃左右，手机保护套的成分主要为TPU塑料粒、PC 塑料粒、ABS 塑料粒等物料，尚未达到其热分解温度，但使用激光雕刻机在手机保护套表面刻绘图案时塑胶在激光照射下瞬间的熔化会产生少量的有机废气，其污染因子为非甲烷总烃。根据相似人工混合熔融原理，参考激光雕刻工艺产污系数，参考《排放源统计调查产排污核算方法和系数手册（公告 2021 年第24 号）》2929 塑料零件及其他塑料制品制造行业系数表中激光雕刻过程挥发性有机物的产污系数为 2.7kg/t 产品。根据建设单位提供的资料，项目单个手机保护套的重量为 18g，则 156 万个手机保护套的重量为 28.08t，则激光雕刻过程的非甲烷总烃产生量为0.076t/a。项目激光雕刻过程年工作300天，每天工作8小时，则非甲烷总烃产生速率为0.031kg/h。

根据建设单位提供的资料，项目生产过程产生的VOCs 和非甲烷总烃采取整室收集后引至“活性炭吸附装置”处理，处理后通过 22m 高的 1#排气筒引至高空排放。

## a、风量设计依据

项目混胶机、高压仓、保温箱、真空机、烤箱、烧水炉、激光雕刻机、手工装配台等产污设备分别设置在密闭空间内，晾干车间、混胶车间、装配车间均为密闭且微负压状态，项目通过整室收集的方式对晾干车间、混胶车间、装配车间的有机废气进行收集。根据《废气处理工程技术手册》（王纯、张殿印主编，化学工业出版社，2013 版）中“第十七章净化系统的设计”可知，工厂的一般作业室换气次数为 6 次/h，项目晾干车间、混胶车间、装配车间的设计换气次数取10次/h，设计处理风量 L=nV（换气次数×通风车间体积，m3 /h）。根据建设单位提供的资料，项目晾干车间、混胶车间、装配车间的尺寸均为 8×11×2.7m，则晾干车间、混胶车间、装配车间的总送风量 7128m3 /h；参考《吸附法工业有机废气治理工程技术规范（HJ 2026-2013）》可知，吸附法设计风量应该取120%且考虑到收集管道和截口的损失，额定风机风量应稍大于所需新风量，本报告设计风量按照所需风量的 120%进行设计，故项目风机总风量取 8600m3 /h。项目将产生有机废气的工序均设置在密闭车间内，仅留有供物料和人员进出的门，加强环境管理，进一步提高员工环保意识，使得门口处于常关闭状态。根据《广东省工业源挥发性有机物减排量核算方法》（2023 年修订版）的表3.3-2 废气收集集气效率参考值可知，全密闭设备/空间中单层密闭负压的收集效率为 90%；则项目废气收集效率按90%计。

## 1.4废气环境影响分析小结

根据上述分析可知，项目生产过程的VOCs、非甲烷总烃有组织排放达到《固定污染源挥发性有机物综合排放标准》（DB44/2367-2022）表1挥发性有机物排放限值，臭气浓度有组织排放达到《恶臭污染物排放标准》（GB14554-93）表2恶臭污染物排放标准值的要求。因此，项目生产过程产生的VOCs、非甲烷总烃、臭气浓度经整室收集后引至“活性炭吸附装置”处理后通过 22m 高的 1#排气筒引至高空排放是可行的。

根据佛山市生态环境局顺德分局关于发布《2023 年度佛山市顺德区生态环境状况公报》的通知（佛环顺涵[2024]44 号）可知，2023 年顺德区空气污染物中臭氧（O3）超标；根据《环境影响评价技术导则-大气环境》（HJ2.2-2018）的规定，判定本项目所在的顺德区为不达标区。

项目无组织排放的颗粒物、VOCs、非甲烷总烃、臭气浓度通过加强车间通风换气，颗粒物无组织排放可达到广东省地方标准《大气污染物排放限值》（DB44/27-2001）第二时段无组织排放监控浓度限值，厂区内有机废气无组织排放满足《固定污染源挥发性有机物综合排放标准》（DB44/2367-2022）表3厂区内 VOCs 无组织排放限值，臭气浓度无组织排放可达到《恶臭污染物排放标准》（GB14554-93）表 1 二级新扩改建厂界标准限值。总体而言，项目生产过程产生的污染物对周围敏感点的大气环境影响较小。

## 3.2噪声影响及达标分析

根据《环境影响评价技术导则—声环境》（HJ2.4-2021），在用倍频带声压级计算噪声传播衰减有困难时，可用 A声级计算噪声影响分析如下：

①将项目生产车间视为一个噪声源，设备全部开动时的噪声源强计算公式如下：

$$
\mathrm { L r } = 1 0 \mathrm { l g } \sum _ { \mathrm { i } = 1 } ^ { \mathrm { n } } \mathrm { l } 0 ^ { \mathrm { 0 . 1 L i } }
$$

式中：Lr—噪声源叠加A声级，dB（A）；

Li—每台设备最大A声级，dB（A）；

n—设备总台数。

## 4.1固体废物产生情况

## （1）员工生活垃圾

根据《社会区域类环境影响评价》（中国环境科学出版社），我国目前城市人均生活垃圾为 0.8\~1.5kg/人·d，办公垃圾为 0.5\~1.0kg/人·d，项目员工均不在厂内住宿。因此本项目中生活垃圾主要为员工的办工、生活垃圾。每人每天生活垃圾产生量按0.5kg计算，本项目共有员工20人，年工作300天，则员工生活垃圾产生量约为3t/a；收集后交由环卫部门定期清运处理。

## （2）一般工业固废

本项目产生的一般工业固废主要为开料、切割、压刨、雕刻、打磨、钻孔过

程产生的边角料和沉降的粉尘，包装过程产生的废包装材料等。

边角料、沉降的粉尘：根据上述分析，项目开料、切割、压刨、雕刻、打磨、钻孔过程会产生少量的边角料和沉降的粉尘；根据建设单位提供的资料和上述分析可知，项目边角料的产生量为 0.5t/a、沉降的粉尘量为0.162t/a。根据《固体废物分类与代码目录》（生态环境部 2024 年第 4 号）可知，边角料和沉降的粉尘均为 SW17 可再生类废物，代码为 900-009-S17；收集后交由专业回收公司回收处理。

废包装材料：根据上述分析可知，项目使用包装材料进行包装时会产生少量的废包装材料（主要为废纸箱和废胶袋），根据建设单位提供的资料，项目废包装材料的产生量为0.1t/a。根据《固体废物分类与代码目录》（生态环境部 2024年第 4 号）可知，边角料和沉降的粉尘均为 SW17 可再生类废物，代码为900-005-S17 和 900-003-S17；收集后交由专业回收公司回收处理。

## （3）危险废物

## 1）废活性炭

项目生产过程产生的 VOCs、非甲烷总烃经整室收集后引至“活性炭吸附装置”处理，处理废气后的活性炭需要定期更换，更换会产生废活性炭。根据《国家危险废物名录》（2021 年版）中相关规定，废活性炭属于危险废物，类别为HW49 类其他废物，代码为 900-039-49，根据上述分析可知，项目废活性炭产生量为 2.685t/a，收集后定期交由具有危废处置资质的公司处理。

## 2）废原料包装桶

项目废原料包装桶主要来源于人工混合、混胶过程产生的废 A 胶桶、废 B胶桶，根据《国家危险废物名录》（2021 年版）中相关规定，废原料包装桶属于危险废物，类别为HW49类其他废物，代码为900-041-49。根据建设单位提供的资料，项目 A 胶、B 胶、水性颜料的使用量分别为 9.27t/a、3.09t/a、0.21t/a，每桶重量均为25kg，单个空桶重量为0.5kg，则废A胶桶、废B 胶桶、废水性颜料桶的产生量分别为 0.19t/a、0.06t/a、0.0042t/a，则废原料包装桶产生量为 0.2542t/a；分类收集后定期交由具有危废处置资质的公司处理。

## 5、地下水、土壤

## 5.1污染途径

（1）大气沉降影响途径：本项目属于C2039 软木制品及其他木制品制造和C2439 其他工艺美术及礼仪用品制造，均不属于《农用地土壤污染状况详查点位布设技术规定》（环办土壤函[2017]1021 号）附件1 土壤污染重点行业分类及企业筛选原则，项目不在土壤污染重点行业范围内。故不涉及大气沉降影响途径。项目大气污染因子主要是颗粒物、VOCs、非甲烷总烃、臭气浓度等，均为非持久性污染物，可以在大气中被稀释和降解；其大气污染物均不涉及《农用地土壤污染状况详查点位布设技术规定》附件 3 中“附表3-1 农用地土壤和农产品样品必测项目”中无机及有机污染物，因此不考虑大气沉降的影响。

（2）地面漫流影响途径：项目生活污水经三级化粪池处理后排入均安污水厂，不涉及地面漫流影响途径。

（3）垂直入渗影响途径：项目使用的厂房均硬底化，一般固废仓和危废仓均做好防风挡雨、防渗漏等措施，因此可防止泄漏物料下渗到土壤和地下水；故不涉及垂直入渗影响途径。

本项目不涉及大气沉降、地面漫流和垂直渗入影响途径，且项目所在建筑均已水泥硬底化和防渗处理。即使发生泄漏事故，泄漏的废水均可以控制在建筑范围内，因此项目不存在土壤、地下水环境污染途径。

## （3）风险防范措施

为预防和减少突发环境事件的发生，控制、减轻和消除突发环境事件引起的危害，规范突发环境事件应急管理工作，保障公众生命、环境和财产的安全。针对上述风险，建设单位应该采取以下防范措施：

1）存放原料的仓库应以混凝土硬化地面作为基础，并做好防渗措施；危废暂存间应设置围堰，做好防渗措施；

2）安排专人定期对原料进行排查；

3）车间内准备足够的沙包，以应对突发的泄漏；

4）加强员工的岗前培训，强化安全意识，指定操作规程；

5）定期对生产设备进行检修维护以及废气处理设施进行检修维护；

6）为加强建设项目的环境管理，建设单位应编制突发环境事件应急预案，根据关于发布《突发环境事件应急预案备行业名录（指导性意见）》的通知（粤环【2018】44 号）及佛山市生态环境局顺德分局关于转发《佛山市生态环境局关于危险废物产生单位突发环境事件应急预案备案的指导意见（试行）》的通知，本项目不属于《突发环境事件应急预案备行业名录（指导性意见）》的通知（粤环【2018】44号）中需要备案的行业，属于《佛山市生态环境局关于危险废物产生单位突发环境事件应急预案备案的指导意见（试行）》的通知中的简化备案程序，应向佛山市生态环境局顺德分局均安监督管理所备案。

正常生产情况下，建设单位按照本环评要求加强管理和设备的维护，并设立完善的预防措施和预警系统，并配备必要的设备设施，制定严格的安全操作规程和维修维护措施，本项目的环境风险在可接受范围内。一旦发生事故，因为防护措施得力并反应迅速，可把事故造成的影响降到最小。所以本项目在环境风险方面来说是可行的。
