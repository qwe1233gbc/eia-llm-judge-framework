## ①与“一核一带一区”区域管控要求的相符性

## 1）区域布局管控要求

本项目主要从事生物质燃料的加工生产，不属于区域布局管控要求中的禁止新建、扩建水泥、平板玻璃、化学制浆、生皮制革以及国家规划外的钢铁、原油加工等项目。本项目使用的原辅材料不属于新建生产和使用高挥发性有机物原辅材料的项目，符合区域布局管控要求。

## 2）能源资源利用要求

项目所属生物质致密成型燃料加工，不属于高能耗行业。项目生产设备使用电能，生产用水由市政供水，不直接取用江河湖库水量，不会对项目所在地生态流量造成影响，符合能源利用要求。

## 3）污染物排放管控要求

项目产生的粉尘废气均经净化后排放，产生粉尘的生产设备均设置有包围型集气罩，粉尘废气经收集后进入气旋塔水喷淋除尘设施处理，而后通过15米高的排气筒DA001排放；同时，通过在车间邻近设备的位置设置集气管道，集气管道的抽风口对逸散于车间内的粉尘废气有进一步的收集作用，少量在车间内逸散的粉尘经收集后进入一套脉冲布袋除尘设施，处理后通过15米高的排气筒DA002排放。此外，未被集气系统收集的粉尘在车间内通过雾化喷淋装置降尘后以无组织形式排放。通过废气收集和处理措施，能有效减少项目颗粒物的无组织排放。

项目生活污水预处理达标后排至龙江生活污水处理厂处理，项目总量指标由佛山市生态环境局顺德分局分配，符合污染物排放管控要求。

## 4）环境风险防控要求

项目不属于石化、化工重点园区环境风险防控区域。本项目产生的危险废物拟定期委托有资质的处置公司进行收集处理，并通过信息系统登记转移计划和电子转移联单，符合危险废物全过程跟踪管理的防控要求。

## ②环境管控单元总体管控要求

顺德区将以环境管控单元为基础，实施生态环境分区管控，精细化管理、保护生态环境。根据《佛山市顺德区“三线一单”生态环境分区管控方案》（顺府发（2021）11号）佛山市顺德区环境管控单元图，本项目所在区域属于重点管控单元，编号：ZH44060620006，详见附图11。根据项目生产产品、原材料、工艺等分析，本项目不属于单元"区域布局管控"中土壤/禁止类、产业/限制类、水/限制类等。

# 二、建设项目工程分析

## 1、项目由来

佛山市顺德朗格森生物能源科技有限公司（下面简称“企业”），原申报于佛山市顺德区龙江镇龙江社区居民委员会大坝工业园C03-2之二地块一楼C区从事生物质致密成型燃料加工，预计产能为成型生物质燃料4万吨/年。

企业在生产设备进场时因为发现更有利于发展的新生产厂房，所以中止进场作业、放弃租用现有厂房并拟租用佛山市顺德区龙江镇龙江社区北华路高滘路段5号之一3号首层（中心地理位置坐标为北纬22度53分05.63秒，东经113度05分25.45秒）用于生产。重新选址后，公司仍主要从事生物质致密成型燃料加工，生产设备及产能按原申报（即佛环0308环审[2022]第001号）不变，重新选址后产能仍为成型生物质燃料4万吨/年。

根据《中华人民共和国环境影响评价法》第二十四条“建设项目的环境影响评价文件经批准后，建设项目的性质、规模、地点、采用的生产工艺或者防治污染、防止生态破坏的措施发生重大变动的，建设单位应当重新报批建设项目的环境影响评价文件”，本项目在建设过程中建设地点发生重大变化，因此需要重新报批环评文件。

根据《中华人民共和国环境保护法》、《中华人民共和国环境影响评价法》及国务院令第682号《国务院关于修改（建设项目环境保护管理条例》的决定》等有关法律法规的规定，本项目须执行环境影响审批制度。根据环境保护部2020年第16号令《建设项目环境影响评价分类管理名录》（2021年版），本项目属于“二十二、石油、煤炭及其他燃料加工业25”中的“生物质燃料加工254”，本项目为生物质致密成型燃料加工，需要编制建设项目环境影响报告表。受佛山市顺德朗格森生物能源科技有限公司委托，广州国寰环保科技发展有限公司承担该项目的环境影响评价工作，并形成建设项目环境影响报告表。

## 5、给水与排水

## （1）给水：

重新报批前后项目用水由市政给水管网供应。重新报批前用水主要为员工生活用水、除尘喷雾用水，重新报批后为员工生活用水、气旋塔喷淋除尘用水。

## ①生活用水

重新报批前后本项目从业人数均为20人，年工作日300天，项目厂区内不设置宿舍和食堂，参照广东省《用水定额第三部分：生活》（DB44/T1461.3-2021）表A.1中国家机构办公楼无食堂和浴室中的先进值，生活用水10m³/年·人计，则员工生活用水为200m/a。

## ②气旋塔喷淋除尘用水

项目粉尘废气采用气旋塔水喷淋除尘+脉冲布袋除尘处理，根据工程分析，项目喷淋除尘用水量为2112m³/a。

## ③喷雾用水

本项目在生产车间设置有雾化机对车间内未被集气系统收集的粉尘进行雾化喷淋降尘，共设置4台雾化除尘机，每台喷雾流量为5L/min，项目每天工作8小时，年工作300天，则喷雾用水量为2880m³/a。

## （2）排水：

项目排水主要为员工生活污水。生活污水主要包括员工洗手和冲厕产生的污水，生活用水量200m3/a，生活污水按生活用水量的90%计，则生活污水排放量为180m³/a。

喷淋塔内的喷淋水经清渣处理后循环使用，定期更换的废水委托有处理能力的单位回收处理。其中喷淋塔的容积为1m/套，2台设备同样规格，计划14天更换一次喷淋水，年更换合共约24次，则喷淋废水年更换总量为48立方米/年。

雾化降尘所用的形式为雾化喷洒，且单位时间流量较少，喷雾用水将全部在大气中蒸发，无雾化废水产生。

根据《关于调整顺德区环境空气质量功能区划的复函》（佛府办函（2014）494号），项目所在地属二类功能区，执行《环境空气质量标准》（GB3095-2012）及2018年修改单中的二级标准。

根据佛山市生态环境局顺德分局关于发布《2023年度佛山市顺德区生态环境状况公报》的通知（佛顺环函（2024）44号），2023年全区空气质量综合指数为3.14，比2022年下降4.0%，在全市五区中排名第二。

2023年全区二氧化硫 $( \mathrm { S O } _ { 2 } )$ 年平均浓度为6微克/立方米，与上年相比上升20.0%，二氧化氮 $\left( \mathrm { N O } _ { 2 } \right)$ 年平均浓度为28微克/立方米，与上年相比下降3.4%，可吸入颗粒物 $( \mathrm { P M } _ { 1 0 } )$ 年平均浓度为35微克/立方米，与上年相比上升9.4%，细颗粒物 $( \mathrm { P M } _ { 2 . 5 } )$ 年平均浓度为20微克/立方米，与上年相比上升5.3%，臭氧年评价浓度为164微克/立方米，与上年相比下降13.7%，一氧化碳（CO）年评价浓度为1.毫克克/立方米，与上年相比下降9.1%。

## 2、地表水

项目生活污水经三级化粪处理后排入龙江污水处理厂处理，尾水排入龙江大涌。

本项目所在地属于龙江污水处理厂的纳污范围，运营期间，本项目生活污水经三级化粪池处理后通过市政管网排入龙江污水处理厂处理，尾水排至龙江大涌。根据佛山市生态环境保护委员会办公室关于印发《佛山市“十四五"水环境质量排名办法的》的通知（佛环委办[2021]12号），龙江大涌为V类水质目标，水环境质量执行《地表水环境质量标准》（GB3838-2002）中的V类水质标准。

为评价龙江大涌水质情况，项目引用广东增源检测技术有限公司枯水期对龙江大涌的地表水监测数据，检测报告编号为GZH22012713301。采样时间为2022年2月16日\~2月18日，在龙江大涌布设W1、W2、W3共3个监测断面，水环境现状调查断面详情见表3-2，监测结果见表3-3。

## 4、固体废物污染控制标准

固体废物管理应遵照《中华人民共和国固体废物污染环境防治法》、《广东省固体废物污染环境防治条例》执行，一般固体废物鉴别执行《固体废物分类与代码目录》（公告2024年第4号），一般工业固体废物在厂内采用库房或包装工具贮存，贮存过程应满足相应防渗漏、防雨淋、防扬尘等环境保护要求。

危险废物执行《国家危险废物名录》（2021年版）、《危险废物贮存污染控制标准》（GB18597-2023）、《危险废物识别标志设置技术规范》（HJ1276-2022）、《危险废物收集贮存运输技术规范》（HJ2025-2012），危险废物暂存于危险废物暂存间，暂存间应满足防渗漏、防雨淋、防扬尘等要求。

气旋喷淋塔内部主要由旋流桶、填料除雾层、喷淋层、水循环系统、水池等部分组成，多用于针对黏性类粉尘、油性粉尘工业废气预处理、纤维类粉尘等废气净化设备。气旋喷淋塔主要分成旋流层、喷淋层、除雾层。旋风层通过并联旋风筒来增加处理的气量，可以有效减少占地与设备高度，设备工作时，粉尘经过旋风层，大部分粉尘得到有效处理，残余粉尘前往层喷淋层，一般为粒径较小的粉尘；喷淋层设有填料增加吸收面积，残余粉尘在这里被有效吸收，后经过除雾，排出干净气体。两层设计，充分利用了填料塔与旋风板塔的优点，又避开了各自缺点。解决了旋流塔细小颗粒处理不理想，填料塔容易堵塞的问题，二者结合，可以适用于各种除尘除雾场景。气旋喷淋塔具有优点包括粉尘可以集中打捞、无需频繁更换水，结构紧凑、占地面积小，同时处理效果也较佳。

脉冲布袋除尘器由灰斗、上箱体、中箱体和下箱体这四部分组成。当一个箱体区域被清洗后，其他箱体区域仍然正常工作，确保了设备的连续正常运行。含尘气体由进风口进入除尘设备下箱体被滤袋阻隔，经过滤袋过滤后的净化气体由风机吸入直接排出。随着运行时间增加，滤袋上的粉尘越来越多，粉尘层增多，过滤效果提高，阻力也随之增大，但处理风量逐渐减少。清灰时由脉冲控制仪顺序触发各控制阀开启脉冲阀，压缩空气在经脉冲阀至喷吹管各孔喷出进入滤袋，滤袋瞬间膨胀，使滤袋表面大部分粉尘掉落，极少部分粉尘在滤袋表面继续帮助过滤，掉落的粉尘落进灰斗内经排灰阀排出。循环往复，粉尘被周期性清理，实现除尘设备的除尘净化或者粉尘收集作用。脉冲布袋除尘设备具有的优势包括清灰效率高、清灰效果好，处理气体量大、除尘效果好，方便实现自动化控制、后期操作维护方便。

## （2）噪声影响及达标分析

根据项目噪声污染源的特征，按照《环境影响评价技术导则声环境》（HJ2.4-2021）要求，采用多声源叠加综合预测模式对项目产生噪声的发散衰减进行模拟预测。

①点声源在预测点的噪声强度采用几何发散衰减计算式：

$$
L _ { p } { = } L _ { p 0 } { - } 2 0 1 \mathrm { g } \left( \frac { r } { r _ { 0 } } \right) { - } \varDelta L
$$

式中： $L _ { p ^ { - } }$ 距声源r米处的噪声预测值，dB（A）；

$L _ { p \sigma }$ 参考位置 $\mathtt { r _ { 0 } }$ 处的声级，dB（A）；

-预测点位置与点声源之间的距离，m；

$r _ { \mathcal { O } }$ 参考位置处与点声源之间的距离；

4L——预测点至参考点之间的各种附加衰减修正量

②多点声源理论总等效声压级[Leq（总）]的估算方法：

多个设备同时运行时在预测点产生的总等声级贡献值 $( L _ { e g g } )$ 的计算公式为：

$$
L _ { e q g } { = } 1 0 1 \mathrm { g } ( \frac { 1 } { T } \sum _ { i } t _ { i } 1 0 ^ { 0 . 1 \mathcal { L } _ { A i } } )
$$

式中： $L _ { e q g }$ 建设项目声源在预测点的等效声级贡献值， $\mathrm { { d B } ( A ) ; }$

$\textit { L } _ { A i }$ -i声源在预测点产生的 $A$ 声级， $\mathrm { { d B } ( A ) ; }$

$T -$ 预测计算的时间段，s；

$t _ { i ^ { - } }$ -i声源在T时段内的运行时间，s。

③预测点等效声级计算方法：

在预测某处的噪声值时，应先预测计算建设项目声源在该处产生的等效声级贡献值，然后叠加该处的声背景值，最后得到该点的预测等效声级 $( L _ { e q } )$ ，具体计算公式如下：

$$
L _ { e q } = 1 0 1 \mathrm { g } ( 1 0 ^ { 0 . 1 L _ { e q g } } + 1 0 ^ { 0 . 1 L _ { e q b } } )
$$

式中： $L _ { e q g }$ 建设项目声源在预测点的等效声级贡献值，dB(A）；

$L _ { e g b ^ { - } }$ 预测点的背景值， $\mathrm { { d B ( A ) } } ,$ □

## （3）噪声影响及达标分析

项目噪声源主要来自生产设备运行噪声，噪声排放强度约65\~90·dB(A))，生产设备运行噪声经距离衰减后以及车间墙体的隔声作用，通过预测计算，噪声在厂界的贡献值满足《工业企业厂界环境噪声排放标准》（GB12348-2008）2类标准要求，在西面声环境敏感点距离20米的龙江社区高滘居民区处叠加现状后声环境仍可达到《声环境质量标准》（GB3096-2008）2类标准要求。项目所在地属于工业区边沿，距离最近的敏感点龙江社区高滘居民住宅约20m，企业主要生产车间及其设备布置在厂区北面，其中主要噪声源破碎及粉碎工序布置在厂区东面，西面则是制粒、打包为主的低噪声作业，车间布局较合理。建议企业使用低噪音设备，同时做好厂房的隔声降噪工作，设备做好防震处理，充分利用距离衰减和屏障效应等措施降低噪声。由于车间是实体墙体，生产过程亦封窗闭门作业，噪声随距离衰减和墙体隔声作用下，预计设备噪声对附近敏感点影响明显较小。

此外，由于项目距离周边民居较近，建议项目严格控制生产作业时间，生产旺季可考虑同样执行8小时工作制，午间及夜间休息时间不进行生产活动。

②废气处理设施风机外安装隔声罩，下方加装减振垫，配置消音箱，隔声量可达25dB(A)。

以上噪声治理措施容易实施，技术成熟可靠，投资费用较少，在经济上是可行的。

## 5、地下水、土壤

## （1）大气沉降

大气沉降是指大气中的污染物通过一定的途径被沉降至地面或水体的过程，分为干沉降和湿沉降，是土壤污染的重要途径之一。本项目属于石油、煤炭及其他燃料加工业，行业类别为C2542生物质致密成型燃料加工，根据《农用地土壤污染状况详查点位布设技术规定》附件1土壤污染重点行业分类及企业筛选原则，本项目不在土壤污染重点行业范围内。本项目大气污染因子主要是颗粒物等，均为非持久性污染物，可以在大气中被稀释和降解。项目产生的大气污染物不涉及《农用地土壤污染状况详查点位布设技术规定》附件3中"附表3-1农用地土壤和农产品样品必测项目"中无机及有机污染物，因此不考虑大气沉降的影响。

## （2）液态物质泄漏

项目危废仓的废机油等存在泄漏风险。项目危废仓做好防风、防雨、防渗漏、围堰等措施，运营期间做好巡查工作，不会存在废机油等泄漏污染土壤、地下水的情况。

根据分析，项目对可能产生地下水、土壤影响的各项途径均进行有效预防，生产运营期间，在做好各项防渗措施，并加强维护和厂区环境管理的基础上，可有效控制厂区内的液态危险废物等污染物下渗现象，不会出现污染地下水、土壤的情况。

## （4）评价小结

项目环境风险物质主要为机油和废机油，主要危险单元为危废仓和仓库，经核算Q值为0.00004，环境风险潜势为Ⅰ，判定为开展简单分析。通过简单风险分析，项目主要风险类型为机油等液态原材料泄漏；废机油等液态危险废物泄漏；车间内易燃物质遇明火发生火灾或爆炸等。通过简单分析，项目在落实相应风险防范和控制措施的情况下，项目总体环境风险可控。
