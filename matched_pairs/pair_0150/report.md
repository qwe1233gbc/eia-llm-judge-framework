## 一、工艺流程简述（图示）：

（1）机加工生产工艺流程

![](images/02256280134d54518b4babd187f3d95ddc4f1256409e23a15932f69c7fbb6e55.jpg)

## 机加工生产工艺流程说明：

机加工：极少部分来料抽油烟机外壳坯件由于局部外观边缘的不平整或偶有缺漏打孔，需利用钻床、铣床进行机加工处理，此工序会产生噪声和机加工粉尘。

（2）正式生产工艺流程

![](images/e557bda3fbea429ddf9d71f80071cc9cf863e69a764a821e8018d9ec3e8c7c0e.jpg)  
图 2-4 正式生产工艺流程图

## 生产工艺流程说明：

上挂：利用人工操作将来料抽油烟机外壳和经机加工处理的抽油烟机外壳挂在挂具上，期间无大气污染物产生，会产生噪声；

喷淋除油：工件经过脱脂槽进行喷淋除油，脱脂槽上方设有喷淋头。脱脂槽工作温度为常温，除油剂质量浓度为 20%，作业方式为喷淋，单次作业时间为1min，期间产生除油废水和噪声。

喷淋水洗 1、2：工件从一种溶液进入另一种溶液前都要用自来水进行清洗，以除去工件表面滞留的前一种溶液，目的是为了防止对后一种溶液的污染，避免造成后一种溶液的成分及 pH 等发生变化，避免在工件上生成难以去除的物质。工件在喷淋除油、喷淋陶化处理后均需用自来水进行1次喷淋清洗，水洗槽上方设有喷淋头。水洗槽工作温度为常温，作业方式为喷淋，单次作业时间为1min，期间产生水洗废水和噪声。

喷淋陶化：使用陶化剂对工件进行陶化处理，致使工件表面生成一层均匀的陶化膜，以起保护工件的作用，提高后续的喷粉效果，陶化槽工作温度为常温，陶化槽上方设有喷淋头，陶化剂质量浓度为 20%，作业方式为喷淋，单次作业时间为1min，期间产生陶化废水和噪声。

烘干：将喷淋水洗2处理后的工件放入烘干炉中，将工件表面沾有的水分烘干，使其表面完全干燥，烘干炉使用液化石油气作为燃料，烘干时间为 10min，烘干温度为70℃，期间产生燃烧废气和噪声。

喷粉：利用喷粉柜内的粉体喷枪通过静电压力将粉末涂料喷涂在工件上，作业方式为手工喷粉，使工件表面形成一层具有一定厚度的均匀的粉末涂层，期间产生喷粉粉尘和噪声。

固化：将喷粉处理后的工件放入固化炉中，固化炉使用液化石油气进行燃烧加热，使工件表面的粉末涂层发生熔融、流平、固化（作业温度为180\~200℃），形成一层坚硬的涂膜，固化时间为10min，期间产生有机废气、燃烧废气、恶臭气体和噪声。

冷却下件：待固化后的工件完全冷却后进行人工检验，检验合格后可下挂作为成品入库待出货。

## 2、废水污染防治措施可行性分析

本项目生产废水经处理工艺为“pH调节+混凝沉淀+絮凝沉淀“的废水处理设施进行预处理达标后，通过市政污水管网排入容桂第二污水处理厂处理，尾水排至鸡鸦水道。根据前文计算，前处理废水和喷淋塔废水产生量为1087.4m3/a（3.62m3 /d），企业自建的废水处理设施的处理能力为4m3 /d，能满足处理要求。

参考《排污许可证申请与核发技术规范 电镀工业》（HJ855-2017）“表9电镀废水治理可行技术”，本项目采用的“pH调节+混凝沉淀+絮凝沉淀“属于可行技术。

## 废水处理设施工艺说明：

pH调节池：生产废水流入调节池，废水的水质、水量及水温在调节池中得到缓冲、均匀，废水继而进入沉淀池中。

混凝沉淀、絮凝沉淀：随后再加入PAC、PAM，形成胶体等颗粒物结成粗大的絮体，即“矾花”，通过泵输送进入压滤机进行过滤，去除废水中的SS、BOD5、石油类等污染物。废水经自建的生产废水处理设施处理后，通过市政污水管网排入容桂第二污水处理厂处理，尾水排至鸡鸦水道。废水处理过程中产生的污泥同意收集后进入污泥池，污泥浓缩池内的污泥再经过隔膜泵输送至板框压滤机进行脱水减容，之后装袋暂存到危废暂存间暂存，定期交由有危险废物处理资质的单位处理，滤液则回流至原有调节池。

## 1、生活垃圾

本项目劳动定员为15人，均不在厂内食宿。根据《社会区域类环境影响评价》（中国环境出版社）中固体废物污染源推荐数据，办公生活垃圾产生量按每人每天 0.5kg 计，项目年工作 300 天，则生活垃圾产生量 7.5kg/d、2.25t/a，在厂内统一收集后交由环卫部门集中清运处理。

## 2、一般工业固体废物

①一般废包装材料：本项目来料抽油烟机外壳坯件采用包装纸包装，粉末涂料采用塑料包装袋包装，根据企业提供的资料，本项目一般废包装材料产生量为0.9t/a，经收集后交由相应回收单位回收利用。

②喷粉沉降粉尘：本项目喷粉工序产生的粉尘经配套的滤芯回收系统收集后回用于生产中，未附着部分沉降于车间内，根据表4-4，沉降粉尘量为4.725t/a，经收集后回收后可外售给回收单位。

## 3、危险废物

项目危险废物包括废机油、含油废抹布、废机油桶、废化学品包装物和废活性炭。

①废机油：项目生产运营过程中，生产设备由于长时间使用需要机油定期维护，废机油属于《国家危险废物名录》（2021年版）中的HW08废矿物油与含矿物油废物，代码为900-214-08。机油损耗量为50%，机油使用量为0.1t/a，则废机油产生量为0.05t/a。

②含油废抹布：项目设备维护过程中需要更换补充机油，维护过程中会产生溢出废油，需要用抹布擦拭掉，期间会产生含油废抹布，属于《国家危险废物名录》（2021年版）中的 HW49其他废物，代码为900-041-49。本项目年使用的抹布用量为 200 张，每张抹布重量约为50g/张，则含油废抹布产生量为0.01t/a。

③废机油桶：项目所使用的机油的包装规格为10kg/桶，本项目机油的使用量共为0.1t/a，则会产生废机油桶10个，包装规格为10kg的油桶的重量按0.8kg/个，则废机油桶产生量为0.008t/a。废机油桶属于《国家危险废物名录》（2021年版）中的HW08废矿物油与含矿物油废物，代码为900-249-08。

按 8 个抽屉：8×抽屉长×宽×填装厚度 $= 8 \times 0 . 6 \mathrm { m } \times 0 . 5 \mathrm { m } \times 0 . 3 \mathrm { m } = 0 . 7 2 \mathrm { m } ^ { 3 }$ 颗 粒 碳 密 度 按 $4 0 0 \mathrm { k g } / \mathrm { m } ^ { 3 }$ 计 算 ， 则 一 个 活 性 炭 箱 装 炭 重 量 为 ：$0 . 7 2 \mathrm { m } ^ { 3 } { \times } 4 0 0 \mathrm { k g } / \mathrm { m } ^ { 3 } \mathrm { = } 2 8 8 \mathrm { k g }$

$$

$$

S— 动态吸附量，%；（一般取值15%）

C——活性炭削减的VOCs 浓度， ${ \mathrm { m g / m } } ^ { 3 } ;$ ；（本项目活性炭吸附装置削减的VOCs 浓度为 3.96mg/m3）

## 5、固体废物环境管理要求

## （1）生活垃圾、一般工业固体废物

根据《中华人民共和国固体废物污染环境防治法》要求，建设单位应做好以下防治措施：

①建设单位和个人应当依法在指定的地点分类投放生活垃圾。禁止随意倾倒、抛撒、堆放或者焚烧生活垃圾。

②建设单位应当建立健全工业固体废物产生、收集、贮存、运输、利用、处置全过程的污染环境防治责任制度，在室内建设一个占地面积≥10m2的一般工业固废暂存间，建立工业固体废物管理台账，如实记录产生工业固体废物的种类、数量、流向、贮存、利用、处置等信息，实现工业固体废物可追溯、可查询，并采取防治工业固体废物污染环境的措施。

③禁止向生活垃圾收集设施中投放工业固体废物。

④建设单位委托他人运输、利用、处置工业固体废物的，应当对受托方的主体资格和技术能力进行核实，依法签订书面合同，在合同中约定污染防治要求。

⑤建设单位应当向所在地生态环境主管部门提供工业固体废物的种类、数量、流向、贮存、利用、处置等有关资料，以及减少工业固体废物产生、促进综合利用的具体措施，并执行排污许可管理制度的相关规定。

## 6、固体废物环境影响分析结论

综上所述，项目固体废物经上述“减量化、资源化、无害化”处置后，可将固废对周围环境产生的影响减少到最低限度，不会对周围环境产生明显的影响。

## 五、地下水、土壤

本项目属于污染影响型，影响时段为运营期。本项目的生活污水经三级化粪池预处理后、生产废水经自建废水处理设施预处理达标后通过市政污水管网引至容桂第二污水处理厂进一步处理；危险废物分类暂存于危废暂存间内，危废暂存间按照《危险废物贮存污染控制标准》（GB18597-2023）要求落实好“防雨、防渗、防泄漏”等措施，定期交由有处理资质的单位接收处置，租用的厂房和周边环境地面已做好水泥面硬化防渗措施，对地下水环境和土壤环境不存在污染途径，因此项目不需对地下水、土壤进行追踪监测。

本项目不存在地下水、土壤污染途径，也不涉及土壤环境影响评价因子，因此，本项目不开展地下水、土壤环境影响评价。

本项目对周边生态环境无明显影响。

## （1）危废物质泄漏风险防范措施

①危险物质（液化石油气、机油）储存需远离火种和热源，避免阳光直射， 同时在厂区公告栏、液化石油气储存房、仓库和危废暂存间内张贴危险物质 （液化石油气、机油）的危险特性表。

②液化石油气储存房、仓库和危废暂存间内设置“危险”、“禁止烟火”等警示标志，定期检查危险物质（液化石油气、机油）的包装是否损坏或泄漏，及时通知相关人员进行维修。

③设置危险物质（液化石油气、机油）的进出台账及管理制度，做好处理危险物质泄漏的应急物资等储备。

④建议在液化石油气储存房内安装气体防泄漏装置，防止气体泄漏遇明火引起火灾爆炸事故。

## （2）环保治理设施故障风险防范措施

①定期对自建的废水处理设施和废气治理设施进行检测和维修，降低因环保设备故障造成生产废气/废水事故排放的概率。

## 环境风险防范措施

②一旦发生环保设备故障，生产车间应立即停止生产，待故障点抢修完毕后恢复生产。

## （3）生产废水泄漏风险防范措施

①安排专人管理厂区内的前处理处理槽体和回收槽，定期巡视及保养，一旦发现生产废水外漏，应关闭相应的阀门并采取应急封堵措施，及时截流并转移泄漏的生产废水，防止泄漏的生产废水通过雨水管等排出厂外。

②前处理槽体、回收槽体附近的地面应采取防渗防泄漏措施，并且定期对生产废水排至废水处理站和厂外的输送管道进行检测和维护，降低因输送管道损坏造成生产废水泄漏的概率；一旦发生管道损坏，生产车间应立即停止生产，待废水输送管道抢修完毕后恢复生产。

## （4）火灾/爆炸事故引起的伴生/次生污染排放风险防范措施

## 六、结论

<table><tr><td>本项目与周边环境功能区划相符，符合相关产业政策，选址合理可行。本项目 所在区域水、气、声环境质量现状良好，营运期采取的废水、废气、噪声及固废污 染防治措施及各种生态环境保护措施技术可靠、经济可行，项目产生的污染物通过 生产工艺替代或污染防治措施得到有效削减，达到排放标准要求，不会对周围环境 质量造成明显影响。因此建设单位应切实落实本评价提出的各项有关环保措施，保 证污染治理工程与主体工程执行&quot;三同时&quot;制度，并确保各种治理设施正常运转的前 提下，确保污染物达标排放、固体废弃物安全处置，项目在正常运营状况下不会对 周边环境产生大的污染影响。 从环保角度分析，项目的建设是合理可行的。</td></tr></table>
