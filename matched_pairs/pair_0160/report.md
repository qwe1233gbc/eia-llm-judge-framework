◇性能稳定由于部分电子电器设备长期在户外使用，受天气因素、空气湿度变化等影响，印刷的图案需具有耐晒、耐摩擦、抗老化和不易吸潮的性能。水性油墨主要以水为溶剂，遇到高温或雨水天气的情况，可能导致印刷图案发生脱墨现象。

◇色泽一致电子线上印字内容一般为商标、型号、电压、芯数和长度标识等信息，方便后续检验和组装操作，印字内容要保持颜色相同，印迹清晰，没有褪色现象。

◇印刷均匀印刷内容分布要均匀，不会出现明显的图案、文字和标志重叠。

◇防粘脏性油墨不会对线圈绝缘层产生污染，不影响印刷质量。

## ③现阶段低挥发性原辅材料的应用

塑料印刷水性油墨应用范围不广，成熟度一般，目前水性原辅材料在塑料印刷大范围应用存在一定的困难。根据《东莞家具制造业和印刷行业低挥发性有机物原辅材料替代指引》中相关调研情况，正常情况下油性油墨生产速率可达200m/min，而水性油墨生产速率较低，一般约为90m/min，对生产效率影响较大，且使用水性油墨印后的图案附着力不强，耐晒、耐摩擦度不高，对产品质量影响较大，市场接受程度低。综上所述，本项目使用的油性油墨、稀释剂不属于低挥发性有机物原料，根据产品的品质管控要求和水性油墨在塑料薄膜印刷的应用技术现状等因素，暂无可替代的物质，待行业内有成熟的低 VOCs 原辅材料或环保型生产工艺，应实行替代，从源头上减少VOCs 的产生量，在使用油性油墨期间，企业应加强有机废气的收集、处理，从末端保证有机废气达标排放。

## （2）废气

## 原环评数据：

根据建设单位提供资料，迁改扩建前项目所有设备均使用电能，无燃料废气产生。项目营运期间产生的废气主要为非甲烷总烃、恶臭、VOCs。

## （1）非甲烷总烃

根据《空气污染物排放和控制手册》（美国国家环保局）中推荐的公式塑料加工废气排放系数，PVC挤出时，非甲烷总烃产生系数取8.5kg/t 原料。

项目挤出使用 PVC 塑料粒 45t/a，每天工作 8 小时，年工作 300 天，PVC 塑料粒使用量为 18.75kg/h，非甲烷总烃产生速率为 0.16kg/h，产生量为 0.383t/a。

## （2）VOCs

根据原环评环评资料，项目水性油墨的主要成分为 1-甲基-2-吡咯烷酮（3\~6%），水性聚氨酯（44\~47%），颜料（15%），水（30%）和有机硅添加剂（5%），按1-甲基-2-吡咯烷酮全部挥发核算，水性油墨的VOCs 挥发系数为6%。项目共使用水性油墨 0.1t/a，水性油墨的最大使用速率为 0.05kg/h，则VOCs 的产生量为 0.006t/a。

## （3）臭气浓度

迁改扩建前项目挤出过程中塑料热熔和印字过程会产生轻微的恶臭，其污染因子为臭气浓度。由于臭气的发生比例与操作温度、原料性能等诸多因素有关，较难进行准确定量计算，本次评价不做定量分析。项目挤出和印字工程产生的臭气浓度与有机废气一并收集后经“UV 光解”处理后通过21 米排气筒引至楼顶高空

排放，不会对周边环境造成恶臭污染。

挤出和印字废气采用采用上吸伞型罩进行收集，收集后经“UV 光解”处理后经21米排气筒高空排放。根据《集气罩设计手册》，集气罩收集效率为80%\~95%，项目取 90%。根据《广东省家具制造行业挥发性有机化合物废气治理技术指南》，UV 光解的处理效率可达到 50\~95%，因项目的产生量比较小，预计UV 光解对有机废气的净化效率会偏低，本报告取 50%。

## 1.1、源强核算说明

## （1）挤出产生的非甲烷总烃

项目电线挤出工序产污系数参考《排放源统计调查产排污核算方法和系数手册》中表 2922 塑料板、管、型材制造行业系数表的配料-混合-挤出工艺产生的挥发性有机物产污系数为1.50kg/t-产品。项目挤出工序原料使用量为 380t/a，则挤出过程中非甲烷总烃产生量为 0.57t/a。年工作日300天，每天有效工作时间为8小时，工作时间为 2400h/a。建设单位拟在挤出工位设置包围型集气罩（通过软质垂帘四周围挡，偶有部分敞开）收集后经一套“活性炭吸附”废气处理设备处理后引至47米高G1 排气筒高空排放，其余无组织排放。

## （2）印字有机废气

印刷过程使用油墨和稀释剂，印刷过程中会产生一定量的有机废气，主要污染因子为 NMHC、VOCs。

项目使用的油墨 VOCs 含量为 36.3g/L，密度为 0.9215g/cm3，油墨使用量为0.3t/a，则油墨 VOCs 产生量为 0.012t。根据稀释剂的成分其挥发系数为 100%，稀释剂使用量为 0.3t，则印刷过程中稀释剂 VOCs 产生量为 0.3t/a，综上，印字过程中 VOCs 产生量为 0.312t/a。项目印字每天工作 8 小时，年工作 300天，废气产生速率 0.13kg/h。

建设单位拟在印字工位上设置包围型集气罩（通过软质垂帘四周围挡，偶有部分敞开）有机废气收集后经一套“活性炭吸附”废气处理设备处理后引至47米高G1 排气筒高空排放，其余无组织排放。

## （3）臭气浓度

迁改扩建后项目挤出、印字工序会产生少量异味，该异味污染因子以臭气浓度为表征。项目产生的臭气浓度通过“活性炭吸附装置”处理后引至G1 排气筒高空排放，其余未被收集的以无组织的形式排放，预计臭气浓度有组织和无组织排放均可达到《恶臭污染物排放标准》（GB14554-1993）中表1恶臭污染物厂界标准值的二级新扩改建标准以及表2恶臭污染物排放标准值。

## （4）破碎粉尘

迁改扩建后项目在检测过程中会产生不合格品，对不合格产品进行拆分，将绝缘层和铜线分开，绝缘层收集后使用破碎机破碎后重新利用，破碎过程中会产生一定量的粉尘，主要污染因子是颗粒物。项目破碎过程在独立区域进行，破碎过程中旁边有挡板和运作工程设有盖子，粉尘被挡下，破碎粉尘产生量及浓度较低。参考生态环境部《关于发布<排放源统计调查产排污核算方法和系数手册>的公告》（公告 2021 第 24 号）—“42 废弃资源综合利用行业系数手册”中4220非金属废料和碎屑加工处理行业-废 PS/ABS-“干法破碎”颗粒物产污系数425g/t-原料，迁改扩建后项目塑料粒子加工量为380t/a，根据企业提供资料，其次品产生量约为原料量的3%，不合格品产生量约为11.4t/a，破碎后回用于生产中，项目设有1台破碎机，每次破碎时间为2h，则破碎过程颗粒物产生量为 0.0048t/a，产生速率为 0.008kg/h，破碎粉尘经车间机械通风后以无组织形式排放至大气环境。

## （2）直接冷却水

迁改扩建后项目设有1 台冷却塔，用于直接冷却挤出后的线材。冷却塔循环水量为 $2 \mathrm { m } ^ { 3 } / \mathrm { h }$ ，需适当地加入新鲜水补充因蒸发而损失的水分。根据《工业循环冷却水处理设计规范》（GB/T50050-2017）开式系统的补充水量公式为：

$$
Q m = Q e + Q b + Q w ( \vec { \tt x } \{ 1 . 1 \} )
$$

$$
\scriptstyle Q m = { \frac { Q e \bullet N } { N - 1 } } ( { \vec { \mathrm { x } } } \backslash 1 . 2 )
$$

$$
Q e = k \bullet \Delta t \bullet Q r \quad ( \overrightarrow { \sf x } \{ 1 . 3 \} )
$$

$$
Q b = \frac { Q e } { N - 1 } - Q w ( \vec { \tt x } \{ 1 . 4 \} 
$$

式中：Qm— 补充水量 $\mathrm { ( m ^ { 3 } / h ) }$

Qb— 排污水量 $\mathrm { ( m ^ { 3 } / h ) }$

Qw——风吹损失水量 $\mathrm { ( m ^ { 3 } / h ) }$ ，冷却塔风吹损失量占进冷却塔循环数量的百分数取0.3%；

N——浓缩倍数，开式冷却塔浓水倍数一般为2\~3，本次评价取 $\Nu { = } 3$

Qe— 蒸发水量 $\mathrm { ( m ^ { 3 } / h ) }$

Qr— 循环冷却水量 $\mathrm { ( m ^ { 3 } / h ) }$

Δt——循环冷却水进、出冷却塔温差（℃），项目设计循环冷却水进塔温度为 $4 0 \mathrm { { ^ \circ C } }$ ，出塔温度为 $2 0 \mathrm { { ^ \circ C } }$ ，则 $\Delta \mathrm { t } { = } 2 0$

k— 蒸发损失系数 $( 1 / \mathrm { { } ^ { \circ } C } )$ ，进塔大气温度取 $4 0 \mathrm { { ^ \circ C } }$ ，则 k=0.0016。

## 2.2、项目外排废水依托伦教污水处理厂处理达标的可行性分析

生活污水经三级化粪池预处理后经市政污水管网引入伦教污水处理厂处理，三级化粪池将生活污水分格沉淀并对沉淀到池底的固化物（粪便、污泥等）进行一定程度的厌氧分解，上层的水化物体进入市政污水管网。

伦教污水处理厂位于佛山市顺德区伦教街道三洲居委会碧桂路东侧（西海大桥附近），用地面积为7.07公顷，伦教污水处理厂分三期建设，总规划规模为10万 t/d，首期建设规模为 3 万 t/d，已于2009 年8 月 7 日通过环保验收，纳污范围南至龙洲路，东至广珠公路，北至世纪大道，西至世龙大道；二期建设规模4 万t/d，已于2018年 9月29 日通过环保验收，纳污范围包括羊大河以北区域，主要分布于熹涌、霞石和三洲等村居，三期规模3 万t/d，属于远期规划。伦教污水处理厂已建成规模为7万t/d，首期工程采用微曝氧化沟工艺，二期工程采用Unitank工艺，现状出水水质执行《城镇污水处理厂污染物排放标准》（GB18918-2002）一级 A 标准及广东省地方标准《水污染物排放限值》（DB44/26-2001）第二时段一级标准的较严值，经处理达标后的尾水排入李家沙水道。

本项目位于伦教污水处理厂的服务范围，且已接通市政管网。本项目生活污水经三级化粪池预处理后可达到广东省地方标准《水污染物排放限值》（DB44/26-2001）第二时段三级标准，满足伦教污水处理厂的进水水质要求，项目废水排放量约为 3t/d（年工作 300 天），约占伦教污水处理厂处理规模（7万t/d）的 0.0004%，不会对伦教污水处理厂造成冲击，因此本项目生活污水纳入伦教污水处理厂处理是可行的。

## ①车间内噪声源靠近围护结构处的噪声贡献值预测

计算某一室内声源靠近围护结构处产生的A声压级Lp1：

$$
L _ { _ { p 1 } } = L _ { _ { w } } + 1 0 \log ( \frac { Q } { 4 \pi r ^ { 2 } } + \frac { 4 } { R } )
$$

式中：

Q－指向性因数：通常对无指向性声源，当声源放在房间中心时，Q=1；当放在一面墙的中心时，Q=2；当放在两面墙夹角时，Q=4；当放在三面墙夹角处时，Q=8。

R－房间常数： $\scriptstyle \mathrm { R = S a } / ( 1 - \mathbf { a } )$ ，S 为房间内表面面积， $\mathbf { m } ^ { 2 } \mathbf { ; }$ ；a为平均吸声系数。

r－声源到靠近围护结构某点处的距离，m。

Lw 为设备的A声功率级。

计算出所有室内声源在围护结构处产生的叠加A声压级：

$$
L _ { P 1 } ( T ) = 1 0 \log ( \sum _ { j = 1 } ^ { N } 1 0 ^ { 0 . 1 L _ { R _ { j } } } )
$$

式中：

$\mathrm { { L } _ { p l } ( T ) }$ --靠近围护结构处室内N 个声源叠加A声压级， $\mathrm { d B } ( \mathrm { A } )$

$\mathrm { L _ { p l j } } \mathrm { - }$ 室内 j 声源的A声压级， $\mathrm { d B } ( \mathrm { A } )$

## 7）法律法规规定的其他义务。

移出人应当按照国家有关要求开展危险废物鉴别。禁止将危险废物以副产品等名义提供或者委托给无危险废物经营许可证的单位或者其他生产经营者从事收集、贮存、利用、处置活动。

## ③处置

建设单位拟将危险废物交有危废处置资质单位处理。根据《广东省危险废物产生单位危险废物规范化管理工作实施方案》，企业须根据管理台账和近年生产计划制订危险废物管理计划，并报当地环保部门备案。台帐应如实记载产生危险废物的种类、数量、利用、贮存、处置、流向等信息，以此作为向当地环保部门申报危险废物管理计划的编制依据。危险废物分类收集后置于贮存设施内，贮存时限一般不得超过一年，并设专人管理。盛装危险废物的容器和包装物以及产生、收集、贮存、运输、处置危险废物的场所必须依法设置相应标识、警示标志和标签，标签上应注明贮存的废物类别、危害性以及开始贮存时间等内容。企业必须严格执行危险废物转移计划报批、依法运行危险废物转移联单，并通过信息系统登记转移计划和电子转移联单。企业还需健全产生单位内部管理制度，包括落实危险废物产生信息公开制度、建立员工培训和固体废物管理员制度、完善危险废物相关档案管理制度、建立和完善突发危险废物环境应急预案并报当地环保部门备案。根据《中华人民共和国固体废物污染环境防治法》（2020 年 4 月 29 日修订），产生危险废物的单位，应当按照国家有关规定制定危险废物管理计划；建立危险废物管理台账，如实记录有关信息，并通过国家危险废物信息管理系统向所在地生态环境主管部门申报危险废物的种类、产生量、流向、贮存、处置等有关资料。

综上所述，危险废物按要求妥善处理后，不会对周围环境大气、地表水、土壤以及环境敏感保护目标产生影响。

## 2、排污口及环保图形标识规范设置

各污染排放口应按规范实施，遵守《国家环境保护总局办公厅关于印发排放口标志牌技术规格的通知》（环办〔2003〕第 95号）相关规定。明确采样口位置，设立环保图形标志、废气污染治理设施进出口均设置采样孔及采样平台；废水处理设施出口应设置采样点；一般工业固体废物暂存区及危废仓设置环保图形标志；设置噪声相关环保图形标志。

## 3、排污许可证制度执行要求

根据《固定污染源排污许可分类管理名录》（2019 版），项目行业类别为“三十三、电气机械和器材制造业，87 电线、电缆、光缆及电工器材制造 383-其他”，应实行排污许可登记管理；项目在通过审批后应进行排污许可登记管理手续，填写基本信息、污染物排放去向、执行的污染物排放标准以及采取的污染防治措施等信息。

## 4、竣工验收

项目竣工后，建设单位应按环保部规定的标准和程序验收环保设施，自行委托有资质的环境监测单位进行验收监测，编写自主验收监测报告，并向社会公开，验收合格后方可投产使用，同时项目环保措施落实情况受环保主管部门监督检查。

## 5、管理文件

记录废气运行设施台账、危废及一般工业固废台账；制定环境管理制度，提高员工环保意识，加强日常维护，落实污染物达标排放监督与考核。
