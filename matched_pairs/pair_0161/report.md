## 7、水平衡分析

## （1）冷却塔及直接冷却用水及排水

项目拉粒、注塑（测试）工序共设置 1 台冷却塔，冷却塔提供冷却水对拉粒机挤出的尼龙塑料粒成品进行直接冷却，以及对注塑机中的模具进行间接冷却。冷却用水循环使用，定期补充因蒸发而损失的水分，并适当排放一定量的水以维持循环系统盐分的平衡。

冷却塔的循环冷却水由于高温会导致蒸发，参考《工业循环冷却水处理设计规范》（GB50050-2017），蒸发水量计算公式如下：

$$
{ \mathrm { Q c } } { = } { \bf k } ^ { * } ~ { \Delta t } ^ { * } { \mathrm { Q r } }
$$

式中： Qc—蒸发水量(m3/h) 。

K—蒸发损失系数(1/℃ )，需根据进塔大气温度取值。

∆t—循环冷却水进塔温度差(℃)，项目进塔温度差约15℃。

Qr—循环冷却水量(m3/h) 。

项目冷却塔参照开式系统，进塔大气温度平均约 $3 0 \mathrm { { } ^ { \circ } C }$ ，根据《工业循环冷却水处理设计规范》（GB/T50050-2017）表5.0.6，冷却塔的蒸发损耗系数取值0.0015。项目冷却塔使用时间为 8h/d，年工作日300 天，根据建设单位提供资料，冷却塔循环水量为 5m3 /h，则总循环水量为 12000m3 /a，则冷却塔蒸发水量为270m3 /a（蒸发系数为 0.0015\*15=2.25%）。

每台拉粒机均配套 1 个直接循环水池，3 台拉粒机冷却水槽尺寸分别为5m×0.4m×0.3m、4m×0.35m×0.2m、4m×0.35m×0.2m，循环水池的有效容积为池体容积的 90%，即 3 个循环水池有效容积分别约为 0.54m3、0.252m3、0.252m3。

根据建设单位提供资料，直接冷却水需定期更换。每月更换一次（年更换12 次），更换产生的直接冷却废水量为 12.528m3 /a，项目设置废水暂存储罐，用于储存更换的直接冷却废水。根据建设单位提供的资料，拉粒工序的冷却过程对水质要求不高，且冷却时尼龙塑料粒成品已经过初步的自然冷却，冷却过程无需添加药剂，溶于水中的物料极少，水质较清洁，冷却完毕的冷却水经拉粒机自带的循环水池自然沉淀后，再通过冷却塔循环进入下一次冷却，本项目定期更换循环水池内的冷却水，更换的直接冷却水经静置后委托佛山市科源达环保污水处理有限公司回收处理，不外排。

同时相对较高温的拉粒半成品导致直接冷却水槽内的冷却水的蒸发，循环水槽的日损耗量约为有效容积的 15%，则损耗水量为46.98m3 /a。冷却水槽新鲜水补充量为 59.508m3 /a。则冷却塔总新鲜水补充量为 329.508m3/a。

补充说明：本项目拉粒机与注塑机共用 1 台冷却塔，仅定期更换拉粒机的直接冷却水槽产生直接冷却废水。

## （2）真空泵（及配套微型冷却塔）用排水

项目每台拉粒机配套 1 台水环真空泵（合计 3 台水环真空泵）进行抽气减压，目的是去除挤出材料中的气泡和水分，提高产品质量和稳定性，并防止挤出材料在拉粒机中的分解或降解。水环真空泵需使用（配套微型冷却塔提供的）冷却自来水，并适当地加入新鲜水补充因蒸发而损失的水分，真空泵的自来水循环使用。由于真空泵对拉粒机抽气减压过程抽出的气体带有较少量塑料挤出废气，因此真空泵内的自来水会有一定程度的污染，因此需定期更换该部分自来水，更换产生的废水暂存于废水密封暂存罐中，定期委托佛山市科源达环保污水处理有限公司外运处理。根据建设单位提供资料，真空泵用水 2 个月更换一次，每台真空泵单次更换量为 0.15m3，合计更换量为2.7m3/a。

水环真空泵储水量为 0.15m3。真空泵年工作时间为2400h，由于真空泵工作过程自来水水温上升，会有少量蒸发，根据同类型项目生产经验，每台真空泵蒸发水量约为 0.03m3 /h，则年蒸发水量为 216m3/a。

每台真空泵配套有 1 台微型冷却塔（共计 3 台），微型冷却塔为真空泵提供循环冷却水以确保真空泵正常运行。

微型冷却塔的循环冷却水由于高温会导致蒸发，参考《工业循环冷却水处理设计规范》（GB50050-2017），蒸发水量计算公式如下：

$$
{ \mathrm { Q c } } { = } { \bf k } ^ { * } ~ { \Delta t } ^ { * } { \mathrm { Q r } }
$$

式中： Qc—蒸发水量(m3/h) 。

K—蒸发损失系数(1/℃ )，需根据进塔大气温度取值。

∆t—循环冷却水进塔温度差(℃)，项目进塔温度差约15℃。

Qr—循环冷却水量(m3/h) 。

项目冷却塔参照开式系统，进塔大气温度平均约 30℃，根据《工业循环冷却水处理设计规范》（GB/T50050-2017）表5.0.6，冷却塔的蒸发损耗系数取值0.0015。项目微型冷却塔使用时间为 8h/d，年工作日300 天，根据建设单位提供

资料，冷却塔循环水量为 0.5m3 /h，则3台微型冷却塔总循环水量为3600m3/a，则冷却塔蒸发水量为 81m3 /a（蒸发系数为 0.0015\*15=2.25%）。

则真空泵新鲜水补充量约 299.7m3 /a（2.7+216+81=299.7）。

## 工艺流程说明：

投料：将PA塑料粒、玻璃纤维、滑石粉、阻燃剂、增韧剂、色母原料按比例（比例为 49.6%：24.9%：2.0%：10.0%：10.0%：3.5%）人工投入拌料机中，该过程会产生少量粉尘和噪声。

拌料：通过拌料机对以上原料搅拌均匀，由于粉料（滑石粉）投料量占比较小，且拌料机密闭作用，因此基本不产生粉尘。拌料完毕后将混合均匀的原料输送至拉粒机，此过程产生少量噪声。

拉粒：通过拉粒机将原料加热挤出（加热温度为 $2 5 0 ^ { \circ } \mathrm { C } )$ ，挤出后得到的熔融状条状半成品进入设备自带的直接冷却水槽中，通过冷却水对半成品进行直接自然冷却。拉粒机配套的水环式真空泵同时对挤出设备内进行抽气减压，目的是去除挤出材料中的气泡和水分，提高产品质量和稳定性，并防止挤出材料在拉粒机中的分解或降解。真空泵工作过程会经排放口定期排水（抽出的废气也会同时排出），该部分排水经收集后循环使用于真空泵，并定期更换。冷却水槽的直接冷却水也定期更换。直接冷却废水、真空泵废水更换后暂存于废水暂存储罐，定期委托有处理能力单位处理，不外排。此过程产生少量有机废气、恶臭气体、直接冷却废水、真空泵废水、噪声。

切粒：冷却后的尼龙塑料条进入切粒机，通过设备对条状尼龙半成品进行裁切，该过程产生少量粉尘和噪声。

包装：对切粒后的尼龙塑料粒成品用手持式缝包机进行包装，即得成品，入库待售。此过程产生少量噪声、一般废包装材料。

烘干（抽样检测）：项目抽取少量尼龙塑料粒产品进行注塑测试，根据建设单位提供资料，测试量约为 2kg/t·尼龙塑料粒产品量。先将样品投入烘干机以烘干尼龙塑料粒冷却带走的水分，工作温度为 120℃。此过程产生少量噪声。

注塑（抽样检测）：烘干后的尼龙塑料粒进入注塑机加热注塑，工作温度约为 200℃，通过间接冷却后得到塑料件，根据塑料件的性状判断样品的品质。此过程产生少量有机废气、恶臭气体和噪声。

破碎：生产过程拉粒产生的少量不合格品以及所有注塑（测试）产生的塑料件经破碎机破碎后返回拉粒生产使用。此过程产生少量粉尘、噪声。破碎后基本成块状，成块状的物料少量散落地面清扫后回用生产，破碎产生的较少量颗粒粉尘无组织排放。

补充说明：①项目测试过程的注塑工序使用的模具为外购，并委外维修，项目不自行生产或维修模具，不使用维修模具的相关设备及原料。②经企业核实，本项目拉粒机及注塑机的挤出机头基本不会发生堵塞情况，不需进行定期的专门清理。若生产过程拉粒机或注塑机的挤出机头发生堵塞情况，只需在加热条件下挤动数次拉粒机或注塑机的挤出机头即可清理堵塞物，不使用燃烧方式对机头堵塞情况进行清理。由于发生情况极少，处理该情况产生的废气纳入拉粒、注塑有机废气计算和收集治理中，不作单独分析。③本项目拉粒、注塑工作温度均远小于对应使用有机原料（PA、阻燃剂、增韧剂、尼龙塑料粒成品）的分解温度，有机原料基本不会分解，基本不产生分解废气。根据本项目阻燃剂的MSDS中“当温度达到 $3 1 0 \mathrm { { } ^ { \circ } C }$ 以上会产生磷的氧化物、磷化氢、碳的氧化物、氮的氧化物（NOx）”，本项目拉粒工作温度为 $2 5 0 \mathrm { { } ^ { \circ } C } .$ 、注塑工作温度为 $2 0 0 \mathrm { { } ^ { \circ } C }$ 低于 $3 1 0 \mathrm { { } ^ { \circ } C }$ ，不会产生磷的氧化物、磷化氢、碳的氧化物、氮的氧化物（NOx）气体。④本项目生产工序中切粒过程产生少量粉尘，污染因子以颗粒物表征。由于切粒的对象为尼龙塑料粒，非粉料，且切粒过程时长较短，因此切粒过程产生的粉尘极少，本项目仅定性分析。

## 1、废气污染物排放量核算

## （1）粉尘废气（颗粒物）

①投料、切粒粉尘（颗粒物）

本项目生产工序中切粒过程产生少量粉尘，污染因子以颗粒物表征。由于切粒的对象为尼龙塑料条，非粉料，且切粒过程时长较短，因此切粒过程产生的粉尘极少，本项目仅定性分析。

生产尼龙塑料粒成品的拉粒工序前的拌料工序需要先于拌料机投入 PA塑料粒、玻璃纤维、滑石粉、阻燃剂、增韧剂、色母，其中滑石粉为粉状原料，投加滑石粉过程中会因粉料外溢产生少量粉尘；投料粉尘污染因子以颗粒物表征（由于拌料机密闭作用，拌料过程基本不产生粉尘）。滑石粉的年投加量为12t，粉末原料通过人工称量，投放过程中会有少量粉尘产生（配料消耗表中非粉状固体物料不产生粉尘），参考《环境影响评价实用技术指南》（李爱贞等编著）：“四、无组织排放源强的确定（一）估算法：投料粉尘产生量按粉状原料用量0.1‰\~0.4‰计算”，由于项目所使用的粉末原料为细微状，不是使用全细微粉末，故粉尘产生量按粉状原料的 0.1‰计算，则项目投料粉尘产生量约为0.0012t/a。按每天合计投料工序1小时计，年排放时间300h/a，则粉尘产生速率为 0.0040kg/h，投料粉尘于生产车间无组织排放。项目投料粉尘源强情况见表4-7。

②破碎粉尘（颗粒物）

项目拉粒生产尼龙塑料粒产品过程会产生少量不合格品，产生的不合格品以及测试过程的注塑工艺生产的塑料件全部经破碎机破碎后回用于尼龙塑料粒产品生产。尼龙塑料粒产品不合格品、塑料件经破碎后成块状，成块状的物料少量散落地面清扫后回用，破碎产生较少量破碎粉尘，污染因子为颗粒物。根据建设单位提供资料，尼龙塑料粒产品不合格品数量约占尼龙塑料粒产品量的2%、测试工序注塑件产量为2kg/t·尼龙塑料粒产品量，本项目尼龙塑料粒产品量为600t/a，则不合格品量为12t/a、注塑（测试）塑料件产量为1.2t/a，合计需破碎的塑料量为13.2t/a。参照《排放源统计调查产排污核算方法和系数手册》（公告2021年第24号）中“4220非金属废料和碎屑加工处理行业系数手册”，废PE/PP-干法破碎产生的颗粒物产污系数为375克/吨-原料（其中尼龙塑料无相关系数，简化参照该系数），则本项目的塑料件破碎粉尘为0.0050t/a（保留4位小数）。平均每天破碎作业时间为1h，年工作300天，则破碎粉尘产生速率为0.0167kg/h。项目破碎工段产生较少量颗粒粉尘，于生产车间无组织排放。破碎粉尘源强情况见表4-7。

## （2）有机废气

①拉粒有机废气（非甲烷总烃DA001）

拉粒工序对混合后的原料（PA塑料粒、玻璃纤维、滑石粉、阻燃剂、增韧剂、色母）进行加热挤出，经过冷却、裁切后得到尼龙塑料粒成品，该过程会挥发产生少量有机废气。拉粒工作温度约 250℃。参考《排放源统计调查产排污核算方法和系数手册》（公告2021年第24号）中“292塑料制品行业系数手册”2929 塑料零件及其他塑料制品制造行业系数表，改性粒料造粒挥发性有机物产污系数为 4.6 千克/吨-产品。本项目尼龙塑料粒成品生产量约600t/a，则拉粒有机废气产生量为 2.760t/a，年工作时间2400h，则产生速率为1.150kg/h。

另外拉粒工序涉及抽真空废气的VOCs 排放量计入相应的拉粒工序。

由于企业严格控制拉粒工作温度（250℃），控制工段温度尽可能低于有机原料分解温度避免分解，实现最大的产品利用率，因此拉粒所使用的有机原料基本不会分解。PA塑料粒、阻燃剂、增韧剂的分解温度分别为300℃或350℃（PA 塑料粒）、300℃（阻燃剂中的 PA6 组分的分解温度）、300℃（增韧剂）远高于本项目拉粒工序的工作温度，PA 塑料粒、阻燃剂、增韧剂均不会分解，不会产生其他污染物，因此可不考虑使用 PA塑料粒、阻燃剂、增韧剂拉粒过程中可能由于分解产生的有机污染物因子。根据本项目阻燃剂的MSDS中“当温度达到310℃以上会产生磷的氧化物、磷化氢、碳的氧化物、氮的氧化物（NOx）”，本项目拉粒工作温度为 $2 5 0 \mathrm { { } ^ { \circ } C }$ ，低于 $3 1 0 \mathrm { { } ^ { \circ } C }$ ，不会产生磷的氧化物、磷化氢、碳的氧化物、氮的氧化物（NOx）气体。

②测试过程的注塑有机废气（非甲烷总烃，DA001）

测试过程的注塑工序对尼龙塑料粒产品进行加热熔融生产塑料件的过程会挥发产生少量有机废气。该注塑工序的工作温度为 $2 0 0 \mathrm { { } ^ { \circ } C }$ 。参考《排放源统计调查产排污核算方法和系数手册》（公告2021 年第24号）中“292塑料制品业系数手册”2929 塑料零件及其他塑料制品制造行业系数表，塑料零件的注塑工序的挥发性有机物产污系数为2.7 千克/吨-产品。项目测试工序注塑件产量为2kg/t·尼龙塑料粒产品量，则测试的塑料件产品量为 1.2t/a，则注塑工序的有机废气产生量为0.003t/a，注塑工序年工作时间按300h计，则注塑有机废气产生速率为 0.010kg/h。

由于企业严格控制注塑工作温度（200℃），控制工段温度尽可能低于有机原料分解温度避免分解，实现最大的产品利用率，因此注塑工序所使用的有机原料基本不会分解。尼龙塑料粒产品的分解温度为 320-380℃，远高于本项目注塑工序的工作温度，尼龙塑料粒基本不会分解，基本不会产生其他污染物，因此可不考虑注塑过程中可能由于分解产生的有机污染物因子。根据本项目阻燃剂的 MSDS 中“当温度达到 $3 1 0 \mathrm { { } ^ { \circ } C }$ 以上会产生磷的氧化物、磷化氢、碳的氧化物、氮的氧化物（NOx）”，本项目注塑工作温度为 $2 0 0 \mathrm { { } ^ { \circ } C } .$ ，低于310℃，不会产生磷的氧化物、磷化氢、碳的氧化物、氮的氧化物（NOx）气体。

补充说明：经企业核实，本项目拉粒机及注塑机的挤出机头基本不会发生堵塞情况，不需进行定期的专门清理。若生产过程拉粒机或注塑机的挤出机头发生堵塞情况，只需在加热条件下挤动数次拉粒机或注塑机的挤出机头即可清理堵塞物，不使用燃烧方式对机头堵塞情况进行清理。由于发生情况极少，处理该情况产生的废气纳入拉粒、注塑有机废气计算和收集治理中，不作单独分析。

## （5）废气治理设施可行性分析

项目拉粒（含真空泵废气）、注塑产生的有机废气、恶臭气体经集气罩（四周设置软帘）收集后通过活性炭吸附设施处理后引至50m 排气筒DA001 排放，参考《排污许可证申请与核发技术规范 橡胶和塑料制品工业》（HJ1122-2020），活性炭吸附设施属于有机废气处理的可行性技术。

活性炭吸附：当气体分子运动到固体表面时，由于气体分子与固体表面分子之间相互作用，使气体分子暂时停留在固体表面，形成气体分子在固体表面浓度增大，这种现象称为气体在固体表面上的吸附。被吸附物质称为吸附质，吸附吸附质的固体物质称为吸附剂。而活性炭吸附法是以活性炭作为吸附剂，把废气中有机物溶剂的蒸汽吸附到固相表面进行吸附浓缩，从而达到净化废气的方法。活性炭吸附器是一种干式废气处理设备，可以处理多种不同废气，如苯类、酚类、醇类、醚类、酊类等有机废气和臭味。废气在风机的动力作用下，经过收集装置及管道进入主体治理设备——吸附器。吸附器内填充高效活性炭。活性炭的吸附能力在于它具有巨大的比表面积（高达 600～1500m2/g），以及其精细的多孔表面构造。废气经过活性炭时，其中的一种或几种组分浓集在固体表面，从而与其他组分分开，气体得到净化处理。该方法几乎适用于所有的气相污染物，一般是中低浓度的气相污染物，具有去除效率高等优点。根据生态环境部关于印发《2020 年挥发性有机物治理攻坚方案的通知》，采用活性炭吸附技术的，应选择碘值不低于 800mg/g 的活性炭，并按设计要求足量添加、及时更换。

## （1）生活污水排入杏坛镇污水处理厂的可行性分析

## 1）杏坛镇污水处理厂概况

杏坛镇污水处理厂一期服务范围为杏坛镇区，包括齐杏、雁园、马齐、杏坛、吕地、罗水六个居委会的全部用地和桑麻、西北、龙潭三个村的部分用地；二期扩建完成后污水收集范围为以下几大区域的生活污水及经过预处理的工业废水：①顺德浦项钢板有限公司片区；②美的工业园片区；③大型村居片区，包括高赞村、上地村、昌教村、光辉村、西登村和河北路以北河涌收纳的村庄；④杏坛工业园二期片区；⑤大型楼盘片区，包括金海岸、佳兆业、中博兆业、银座、海俊达上苑和敬老院东侧地块等。本项目位于杏坛镇污水处理厂的服务范围，且已接通市政管网。污水处理工艺为“改良A2 /O处理工艺”，该工艺是近年来国际公认的处理生活污水及工业废水的先进工艺，污水能够稳定达标排放。杏坛镇污水处理厂一期工程日处理规模2万吨/日，二期工程日处理规模为4万吨/日，合计6万吨/日，尚有余量，能够满足本项目废水处理量的要求。

## 2）杏坛镇污水处理厂接纳本项目废水量的可行性分析

本项目属于杏坛镇污水处理厂的纳污范围，目前杏坛镇污水处理厂现有工程污水处理能力为6万吨/日，目前杏坛镇污水处理厂处理能力还未饱和，本项目产生的污水量极少，生活污水排放量为 0.24t/d，占杏坛镇污水处理厂日处理量的 0.0004%，远远低于杏坛镇污水处理厂现有的处理规模，不会对杏坛镇污水处理厂的处理规模造成影响。

## （2）直接冷却水、真空泵废水交由有处理能力单位收集处置可行性分析

根据前文分析，直接冷却水主要污染物为 pH、 $\mathrm { C O D } _ { \mathrm { C r } }$ 、SS、氨氮等，产生量为 12.528m3 /a；真空泵废水主要污染物为 pH、 $\mathrm { C O D } _ { \mathrm { C r } }$ 、SS、氨氮等，产生量为2.7m3 /（a 直接冷却水单次更换量为 $1 . 0 4 4 \mathrm { m } ^ { 3 }$ ，真空泵废水单次更换量为 $0 . 4 5 \mathrm { m } ^ { 3 }$ 单月最大外运量约为 1.494m3）。根据工程分析，日最大废水产生量为 $1 . 4 9 4 \mathrm { m } ^ { 3 }$ （单次最大更换量为 $1 . 4 9 4 \mathrm { m } ^ { 3 } .$ ）。因直接冷却废水、真空泵废水较少，建设废水治理设施不太实际，处理成本及日后运行费用较高，管理也较困难。

本项目直接冷却水、真空泵废水属于佛山市科源达环保污水处理有限公司可接纳处理的废水类别。企业应与废水处理单位签订废水处理合同，确保废水的定期处理，同时做好废水的储存和转运工作，并按照相关的规范要求，建议做好废水收集的规范化设施。项目拟设置 1 个容积 $2 \mathrm { m } ^ { 3 }$ 的废水密封暂存罐（材质要求耐酸碱耐腐蚀，储罐充满系数取0.95），并配套1个容积 $0 . 2 \mathrm { m } ^ { 3 }$ 的塑料密封桶作为备用，则厂内废水暂存设施最大废水暂存量为 $1 . 9 \mathrm { m } ^ { 3 }$ ，可达到废水暂存要求。初步计划每个月进行一次废水外运处置，单次最大废水外运量约为1.494m3。

佛山市科源达环保污水处理有限公司（以下简称“科源达”）属于佛山市生态环境局已发布的佛山市内具有废水处理能力的企业。根据佛山市生态环境局关于《佛山市临港国际产业社区工业水净化项目环境影响报告书》（批复文号：佛环函（南）[2020]994 号）可知，佛山市科源达环保污水处理有限公司位于广东省佛山市南海区九江镇九江大道领航东一路 3 号，工业废水设计处理总规模为 2900td（其中社区内工业废水 2300t/d，零星工业废水 600t/d），主要处理含磷废水、综合清洗废水、有机废水和医卫用、新材料、先进装备制造、大健康等四小类行业工业废水，其中综合清洗废水采用“一级pH 调节池+一级混凝池+一级絮凝池+一级沉淀池+二级 pH 调节池1+芬顿反应池+二级pH调节池2+二级混凝池+二级絮凝池+二级沉淀池→工业废水调节池”工艺处理；预处理后的综合清洗废水进入工业废水调节池，与临港产业社区内企业的工业废水混合，再进一步采用“一级物化处理+一段水解酸化+一段缺氧+一段好氧+一段脱氧+二段水解酸化+二段缺氧+二段好氧+二段脱氧+MBR+芬顿反应+二级物化处理+纤维球过滤”工艺进行处理，出水达标排放。本项目产生的直接冷却水、真空泵废水属于科源达可接收处理工业废水范围中的零星工业废水（直接冷却水、真空泵废水属于其中的综合清洗废水），科源达尚有足够处理余量（科源达零星工业废水的处理量为 600t/d，本项目的直接冷却水+真空泵废水产生量为 15.228t，约0.051t/d，占科源达的处理量 0.09%），本项目直接冷却水、真空泵废水产生量较少，委托处理不会对科源达的稳定运行造成冲击。

## 4、水环境影响分析结论

综上，本项目生活污水经三级化粪池预处理后排放浓度可以达到杏坛镇污水处理厂进水水质要求，通过市政污水管网排入杏坛镇污水处理厂处理，尾水最终排入顺德支流。生活污水排放满足相应的废水排放要求，依托杏坛镇污水处理厂具有环境可行性。直接冷却水、真空泵废水定期更换，更换后暂存于废水暂存储罐，定期委托有处理能力单位处理，不外排。本项目废水排放最终对地表水体造成的环境影响不大，其地表水环境影响是可接受的。

## 1、 噪声预测分析

预测模型与预测方法如下：

为了解项目噪声对厂界噪声的影响，本次评价采用预测模式对其影响进行预测。

（1）项目生产设备主要位于生产车间，将项目生产车间视为等效噪声源，各设备于等效噪声源的噪声贡献值可通过以下公式计算：

$$
L e q g = 1 0 \log ( \frac { 1 } { T } { \sum _ { i } } t _ { i } 1 0 ^ { 0 . 1 L . i _ { 1 } } )
$$

式中： $\mathrm { L _ { e q g ^ { - } } }$ 建设项目声源在等效噪声点的等效声级贡献量， $\mathrm { d B } ( \mathrm { A } )$

$\mathrm { L } _ { \mathrm { A i } }$ i 声源在预测点产生的A声级，dB(A)；

T— 预测计算的时间段，s；

ti— —i 声源在T时段内的运行时间，s。

（2）预测点的预测等效声级（Leq）计算公式：

$$
L \mathbf { e } \mathbf { q } = 1 0 \log ( 1 0 ^ { 0 . 1 L \mathbf { e q g } } + 1 0 ^ { 0 . 1 L \mathbf { e q b } } )
$$

式中： $\mathrm { L _ { e q } }$ —点声源在预测点产生的声压级；

$\operatorname { L } _ { \mathrm { e q g } }$ —建设项目声源在预测点的等效声级贡献值，dB(A)；

$\operatorname { L } _ { \mathrm { e q b } ^ { - } }$ —预测点的背景值，dB(A)；

## （3）户外声传播衰减计算

户外声传播衰减包括几何发散（Adiv）、大气吸收（Aatm）、地面效应 $( \mathrm { A g r } )$ 屏障屏蔽（Abar）、其他多方面效应（Amisc）引起的衰减。距声源点r 处的A声级按下式计算：

$$
L _ { \mathrm { p } } \mathrm { ( \bf ~ r ) } = L \mathrm { p } \mathrm { ( \bf ~ r _ { 0 } ) } \mathrm { ( } A \mathrm { d i v + } A \mathrm { a t m + } A \mathrm { g r + } A \mathrm { b a r + } A \mathrm { m i s c ) }
$$

各声源由于厂区内外其它建筑物的屏障衰减、空气吸收引起的衰减以及由于云雾、温度梯度、风及地面其它效应等引起的衰减量难确定其取值范围，且其引起的衰减量不大，保守起见，本评价预测计算中只考虑厂区内各声源至受声点（预测点）的距离衰减及车间墙体隔音量。

## 4、固体废物环境管理要求

（1）员工生活垃圾定期交由环卫部门清理；

（2）要求项目在室内建设一个占地面积≥9m2的一般工业固废暂存间。建设单位需在暂存场所上空设有防雨淋设施，地面采取防渗措施；根据生产需要合理设置贮存量，尽量减少厂区内物料贮存量；一般固废暂存间需要设置明显环境保护图形标志。

根据《中华人民共和国固体废物污染环境防治法》要求，建设单位应做好以下防治措施：

①建设单位应当建立健全工业固体废物产生、收集、贮存、运输、利用、处置全过程的污染环境防治责任制度，建立工业固体废物管理台账，如实记录产生工业固体废物的种类、数量、流向、贮存、利用、处置等信息，实现工业固体废物可追溯、可查询，并采取防治工业固体废物污染环境的措施。

②禁止向生活垃圾收集设施中投放工业固体废物。

③建设单位委托他人运输、利用、处置工业固体废物的，应当对委托方的主体资格和技术能力进行核实，依法签订书面合同，在合同中约定污染防治要求。

④建设单位应当向所在地生态环境主管部门提供工业固体废物的种类、数量、流向、贮存、利用、处置等有关资料，以及减少工业固体废物产生、促进综合利用的具体措施，并执行排污许可管理制度的相关规定。

（3）要求项目在室内建设一个占地面积≥9m2的危废暂存间。建设单位须根据废物特性设置符合《危险废物贮存污染控制标准》（GB 18597-2023）的要求的危险废物暂存场所，且在暂存场所上空设有防雨淋设施，地面采取防渗措施，危险废物收集后分别临时贮存于废物塑料桶内；根据生产需要合理设置贮存量，尽量减少厂区内的物料贮存量；严禁将危险废物混入生活垃圾；堆放危险废物的地方要有明显的标志，堆放点要防雨、防渗、防漏，按要求进行包装贮存。

针对危险废物提出环境管理要求如下：

①设置独立的危险废物暂存间并有专人负责管理，危险废物暂存间应做到防风、防雨、防渗漏，门口处设置围堰，内部地面和墙裙做耐腐蚀硬化处理。

②危险废物应采取分类收集，按类别放入相应的容器内，禁止生活垃圾、一般固体废物与危险废物混放，不相容的危险废物分开存放并设有隔离间隔断。

③在收集、运输、贮存危险废物的设施、场所设置规范的警示标志、标识、标牌。贮存点应及时清运贮存的危险废物，实时贮存量不应超过3吨。

④制定危险废物管理计划，清晰描述危险废物的产生环节、种类、危害特性、产生量、利用处置方式等。

⑤按要求如实申报登记危险废物的种类、产生量、贮存、处置等有关情况。

⑥建设单位必须严格执行危险废物转移计划报批和依法运行危险废物转移联单，并通过信息系统登记转移计划和电子转移联单。企业还需健全产生单位内部管理制度，包括落实危险废物产生信息公开制度，建立员工培训和固体废物管理员制度，完善危险废物相关档案管理制度；建立和完善突发危险废物环境应急预案，并报当地环保部门备案。

⑦建设单位须根据管理台账和近年生产计划，制订危险废物管理计划，并报当地环保部门备案。台账应如实记载产生危险废物的种类、数量、利用、贮存、处置、流向等信息，以此作为向当地环保部门申报危险废物管理计划的编制依据。

## 五、地下水和土壤

（1）污染源及污染物类型

本项目生活污水经三级化粪池预处理后引至杏坛镇污水处理厂处理；直接冷却水、真空泵废水定期委托有处理能力单位处理，不外排。本项目生产过程中产生的废气污染物污染因子为颗粒物、非甲烷总烃、臭气浓度。拉粒（含真空泵废气）、注塑产生的有机废气、恶臭气体经集气罩（四周设置软帘）收集后通过活性炭吸附设施处理后引至50m排气筒DA001排放。投料、切粒、破碎粉尘于生产车间无组织排放。项目对地下水和土壤环境可能造成影响的是危废暂存间内的危险废物泄漏、废水暂存储罐的生产废水泄漏以及大气污染物沉降。
