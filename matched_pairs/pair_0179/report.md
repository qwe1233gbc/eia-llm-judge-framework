## 二、建设项目工程分析

## 1.项目概况

顺德陈村黔粤兴五金厂建设项目原位于佛山市顺德区陈村镇弼教村委会环镇西路 7 号之一 1 区五仓，主要从事不锈钢磨砂，平板，分条，不含不锈钢酸洗、喷涂、退火压延工序，该项目已于2015年7月1日取得《顺德区环境运输和城市管理局关于顺德陈村黔粤兴五金厂建设项目环境影响报告表的批复》（顺管环审【2015】203 号），此时经营主体为顺德陈村黔粤兴五金厂，后续此项目经营主体于2014年1 月 22 日转型升级为佛山市顺德区黔粤兴五金有限公司（见附件 1），并由此经营主体于 2017 年 2 月 7 日完成通过竣工环境保护验收（环验【2017】A038 号）。现由于企业发展需要，拟搬迁至广东省佛山市顺德区陈村镇广隆工业区永兴鸡肠滘工业区一路10号，项目建成后预计年进行不锈钢卷湿式磨砂加工 48000吨，分条加工50000吨。目前，项目租赁的厂房为现有已建成厂房，现申请办理环保审批手续。

建设内容

根据《中华人民共和国环境影响评价法》（2018 年修订）及《建设项目环境保护管理条例（2017 年修订版）》（国务院令第682号）中的有关规定，建设项目必须执行环境影响评价制度。根据《建设项目环境影响评价分类管理名录 2021版》（中华人民共和国生态环境部令第 16 号，2021 年1 月1 日起实施），本项目属于“三十、金属制品业 33”，“67 金属表面处理及热处理加工-其他（年用非溶剂型低 VOCs 含量涂料 10 吨以下的除外）” ，按要求编写环境影响报告表。

不锈钢湿式磨砂：原项目设两条自动磨砂线，每条磨砂线均设粗磨和细磨两道工序。钢板每经过一道磨砂工序后，进入清洗工序，清洗完毕再进行第二次磨砂和清洗。磨砂线内设有砂带和砂轮，当不锈钢板平铺着以一定速度通过自动磨砂线时，通过砂带或砂轮的自身运转，摩擦不锈钢板表面，从而达到磨砂的效果。自动磨砂线采用湿式磨砂，磨砂时喷洒冷却水，一方面使钢材降温，不会由于磨砂摩擦产生热量而影响产品质量，另一方面有效抑制磨砂产生粉尘。同时，为达到防锈、润滑效果，冷却水中添加少量切削液。冷却水循环使用，定期补充由于蒸发损失的水分，一年更换一次。项目设两个三级沉淀池，用于盛装循环冷却水，尺寸分别为 $5 . 5 \mathrm { m } ^ { * } 1 . 2 \mathrm { m } ^ { * } 0 . 8 \mathrm { m }$ 和 1.2m\*3.6m\*1.2m。由于冷却水中含有切削液，故应交由有资质或有处理能力的单位处理。

磨砂完后，进行清洗工序。清洗采用清洗水。为加强清洗效果，清洗水通过电加热到 50-60℃。每道清洗工序配套 $0 . 8 \mathrm { m } ^ { * } 0 . 6 \mathrm { m } ^ { * } 0 . 6 \mathrm { m }$ 的清洗水箱，清洗水循环使用，定期补充由蒸发损失的水分，5 天更换一次，更换的清洗水回用于补充循环冷却水。

原项目使用的切削液为水溶性磨削液，其主要成分矿物油，润滑油性剂、润滑极压剂、表面活性剂、防锈剂、防霉杀菌剂、消泡剂。 pH 为 8.0-10，具有优异的清洗性能，能彻底清除加工件表面的灰尘和金属屑，保证工件良好的表面加工质量，同时具有良好的润滑性能和冷却性能可有效延长砂带使用寿命。

## ◇钢板切割产生的粉尘

## （1）废气污染物源强核算

## ①颗粒物

项目生产过程中钢板切割时会产生少量的金属粉尘，污染因子为颗粒物。参考原环评钢板切割时颗粒物产生情况，本项目金属粉尘产生量按钢板切割原材料用量的十万分之一计算。根据表2-7物料平衡，本项目不锈钢分条加工产品原材料使用量为50500.505t/a，可计算得颗粒物产生量为0.505t/a，参考《未纳入排污许可管理行业适用的排污系数、物料衡算方法（试行）》（原环境保护部公告2017年第81号）中“47 锯材加工业”的系数，车间不装除尘设施的情况下，重力沉降法的效率约为85%，本项目钢板切割过程产生的颗粒物由于自重较大，沉降效率比木粉尘的略高，本项目沉降效率取90%，沉降部分及时清理后作为一般工业固废处理，只有极少部分扩散到大气中形成粉尘，扩散量约为0.051t/a，本项目年工作时间2400h，故颗粒物产生速率为0.021kg/h，以无组织形式排放。

## （4）湿式磨砂冷却水治理设施可行性分析

本项目湿式磨砂冷却水主要污染物为磨砂过程中脱落的金属碎屑，污染因子为SS，经磨砂冷却水池的不锈钢筛网过滤后经沉淀水池沉淀后回用，过滤的主要目的是去除磨砂产生的不锈钢渣，沉淀主要是去除更小颗粒的不锈钢渣，因磨砂过程对用水水质要求不高，且拟每年更换底部磨砂废水，同时定期打捞水池内不锈钢渣，并定期补充损耗水量，保证水质，因此湿式磨砂废水经过滤、沉淀后的水质可回用到磨砂冷却水池中循环使用。

## （5）环境监测

本项目外排水仅为生活污水，生活污水经三级化粪池处理后最终排入陈村污水处理厂，尾水排入陈村水道，其废水的主要监测因子为 $\mathrm { C O D } _ { \mathrm { C r } }$ 、BOD5、SS、氨氮，没有生产废水外排。根据《排污许可证申请与核发技术规范指南 总则》（HJ942-2018）及《排污单位自行监测技术指南 总则》（HJ819-2017），单独排污公共水处理系统的生活污水无需开展自行监测。

## （6）地表水环境影响评价结论

项目外排废水为员工生活污水，生活污水排放量为 450t/a。生活污水经预处理达到广东省地方标准《水污染物排放限值》(DB44/26-2001) 第二时段三级标准后，排入陈村污水处理厂处理，尾水排入陈村水道。综合以上分析，项目由于排放污水量不大，且可达标排放，通过区域水污染防治计划和方案实施后，对纳污水体的水质影响很小。

本项目所在的水环境功能区属于达标区，水污染控制和水环境影响减缓措施有效，依托陈村污水处理厂集中处理具备可行性，不会到造成陈村水道水质下降，因此地表水环境影响可以接受。

## （3）防护设施

本项目产生的噪声做好防护设施后再经自然衰减后，可使项目厂界噪声达《工业企业厂界环境噪声排放标准》(GB12348-2008) 3类标准要求，对周围环境影响不大。建议拟建工程采取以下治理措施：

①在噪声源控制方面，优先选用低噪声设备，在技术协议中对厂家产品的噪声指标提出要求，使之满足噪声的有关标准。在设备选型上，尽量采用低噪声设备，设计上尽量使

气、水、风管道布置合理，使介质流动顺畅，减少噪声。另外，由于设备的特性和生产的需要，建议业主将所有转动机械部位加装减振固肋装置，减轻振动引起的噪声，以尽量减小这些设备的运行噪声对周边环境的影响。

②在传播途径控制方面，应尽量把噪声控制在生产车间内，可在生产车间安装隔声门窗。

③在总平面布置上，项目尽量将高噪声设备布置在生产车间远离厂区办公区，远离厂界，以减小运行噪声对厂界处噪声的贡献值，同时加强场区及厂界的绿化，形成降噪绿化带。

④加强设备维护，确保设备处于良好的运转状态，保持包装机转动传送带运转顺畅，杜绝因设备不正常运转时产生的高噪声现象。

⑤加强职工环保意识教育，提倡文明生产，防止人为噪声；强化行车管理制度，设置降噪标准，严禁鸣号，进入厂区应低速行驶，最大限度减少流动噪声源。

⑥项目生产安排在昼间进行生产，若特殊情况夜间必须生产应控制夜间生产时间，特别夜间应停止高噪声设备，减少机械的噪声影响，减少夜间交通运输活动。

## ②危险废物收集贮存措施

危险废物从产生、收集、贮运、转运、处置等各个环节都可能因管理不善而进入环境，因此在各个环节中，抛落、渗漏、丢弃等不完善问题都可能存在，为了使各种危险废物能更好的达到合法合理处置的目的，本评价按照《危险废物贮存污染控制标准》等国家相关法律，提出相应的治理措施，以进一步规范项目在收集、贮运、处置方式等操作过程。

## 5.2影响途径

## （1）大气沉降

大气沉降主要指由于生产活动产生气体排放间接造成土壤环境污染的影响途径。本项目主要的污染途径是大气沉降，主要的污染因子是颗粒物，不属于《土壤环境质量——建设用地土壤污染风险管控标准（试行）》（GB36600-2018）中的污染物。这些污染物能够改变土壤的组成和性质，对土壤的物理化学特性对土壤积盐、肥力和土壤发育有着明显的影响。本项目的大气污染物排放浓度和排放速率均没有超标，经扩散、降解等作用后，沉降到周边土壤环境的污染物较少。

## （2）垂直渗漏和地面径流

项目地面已做好硬底化，生活污水经三级化粪处理后排入陈村污水处理厂。磨砂冷却水池、清洗水池、沉淀水池、危废暂存间、仓库油类与化学品存放区已做好防腐防渗措施，生产车间已做好相应的密闭设施。因此不涉及地面径流和垂直渗漏的影响。

## 5.3防控措施

## （1）源头控制措施

源头控制主要包括：严格按照国家相关规范要求，对污水处理设施等采取相应措施，以防止和降低污染物的跑、冒、滴、漏，将污染物泄漏的环境风险事故降到最低程度；设备和管线尽量采用“可视化”原则，做到污染物“早发现、早处理”，以减少由于埋地泄漏而可能造成的地下水污染；堆放各种原辅材料、固体废物的堆放场地按照国家相关规范要求，采取防泄漏措施；严格固体废物管理，不接触外界降水，使其不产生淋滤液，严防污染物泄漏到地下水中。

项目物质不构成重大危险源。企业应编制突发环境事件应急预案，配备应急器材，定期组织应急演练。项目在落实相应风险防范和控制措施的情况下，总体环境风险可控。
