## （3）实验服清洗用水

本项目工作完毕后，穿过的实验工作服拟统一收集起来清洗，每天清洗一次，洗衣过程与家庭清洗衣物过程相同。根据《建筑给排水设计规范》（GB50015-2009)，洗衣用水量标准为 40-80L/公斤干衣。

本项目需穿实验工作服约20人，每件实验工作服约0.5kg，年工作250天，每天均需清洗一次，则需清洗的实验工作服约为 2500kg/a(计算公式：20 人×0.5kg/(人)×250次/a)=2500kg/a)。按照 80L/公斤干衣算，本项目实验服清洗用水量为200t/a（计算公式：2500kg/a×80L/kg/1000)=200t/a），按产污系数 0.9 计算，产生实验服清洗废水为 180m³/a（用水为自来水）。

## （4）实验室配制药剂及试验用水

根据建设单位提供的资料，需用移液管将一定量的样品、标准液等移液到容量瓶中用纯水进行稀释配制药剂，每次需要用 2L 纯水配制药剂，一年约配制250次，配制药剂需要纯水量为 500L/a（即0.5t/a）。实验室配制药剂需要用到的实验试剂总量约为0.15t/a。实验结束后，实验过程产生的废水及配制废药剂倒入废液收集桶内，作为危废交由有资质单位处理，处理量为 0.5+0.15=0.65t/a。

## （5）实验器皿清洗用水

根据建设单位提供资料，本项目的实验器皿清洗主要针对实验过程中使用的实验器皿。

本项目实验结束后对实验器皿进行分级清洗，清洗顺序如下：a、将测试废样品和废弃试剂倒入废液收集桶内：b、用自来水进行容器内壁的第一道清洗，清洗后，容器内外壁粘附的高浓度清洗废液倒入废液收集桶内，作为危废交由有资质单位处理；③用纯水进行第二道及第三道的实验器皿清洗后待用，实验器皿第二道清洗废水倒入废液收集桶内，作为危废交由有资质单位处理。实验器皿第三道清洗废水经楼层管道排入美和门诊部的污水处理设施处理。

根据建设单位提供资料，本项目用于配制药剂为 5 个100mL 的容量瓶和5个1mL移液管，用于实验过程的容器为 20 个 2000mL 烧杯，实验结果后，所有容器均要清洗，清洗的水量分别为 2000mL 烧杯容积的 1/10 倍、100mL 容量瓶容积的 1/4 倍、1mL 移液管容积的 1 倍，经计算，本项目实验结束后实验器皿单次清洗的用水量为 4130mL/次（计算公式：200mL（个）×20 个+25mL（个）×5 个+1mL（个）×5 个=4130mL/次。本项目一年实验约 250 次，每次实验器皿需要清洗三道，均使用纯水清洗。实验器皿三道清洗用水量为 3.1t/a（4130mL/次×250 次×3 道≈3.1t/a）。

实验器皿第一道和第二道清洗废水倒入废液收集桶内，作为危废交由有资质单位处理，处理量为 4130mL/次×250次×2道=2.065t/a，实验器皿第三道清洗废水经本楼层废水管道排入美和门诊部的污水处理设施处理，处理量为1.035t/a。

## （6）研发及检测人员洗手用水

项目试验人员每天研发及检测前后需洗手，按每人每天洗手10次，每次洗手约需25s 计算。参考《建筑给排水设计标准》（GB50015-2019），实验室化验水嘴（鹅颈）设计流量：0.2L/秒，项目人数共 20 人。则洗手用水用量为1t/d（250t/a），根据排放系数取 0.9，洗手废水排放量为0.9t/d（225t/a），污染物主要为 $\mathrm { C O D } _ { \mathrm { C r } }$ 、BOD5、SS、LAS、$\mathrm { N H } _ { 3 ^ { - } } \mathrm { N }$ 等，该废水依托美和门诊部的污水处理设施处理后排入市政管网。

本项目实验对水质要求较高，用水均为纯水，纯水由自来水通过纯水机制备，纯水制备工艺为"过滤+RO反渗透"，在制备纯水过程中会产生一定量的浓水；另外纯水机的过滤器材砂滤器、碳滤器、软化过滤器等需要定期反冲洗，反冲洗水量较少，计入浓水中。根据上文分析，项目器械清洗废水、设备更换废水均使用纯水，项目纯水年使用量约为21.1t/a，取纯水制备率为 70%，则制备纯水所需自来水约 30.14m3 /a，即产生浓水9.04m3 /a，浓水较为洁净，作为清净下水经本建筑的雨水管道排入市政雨水管网，不计入综合废水。

## 工艺流程简介：

## 一、细胞研发、制备：

## （1）组织接收

接收组织样本，并进行表面消毒处理后放到生物安全柜内进行分离提取，此过程会产生噪声。

## （2）分离提取

清洗组织样本，分离出目标细胞，并将目标细胞进行培养扩增或进行诱导分化后培养扩增；部分组织在分离后直接进行种子细胞的储存，此过程会产生试验废液、噪声。

## （3）种子细胞建库

细胞扩增到一定数量后进行收集，并加入冻存保护剂后将种子细胞进行冻存，此过程会产生噪声。

## （4）主细胞库建库

出库种子细胞进行复苏，进一步将种子细胞进行扩增培养后进行收集，加入冻存保护剂后将细胞进行冻存，为主细胞库细胞，此过程会产生噪声。

## （5）工作细胞库建库

出库主细胞库细胞进行复苏，进一步将主细胞库细胞进行扩增培养后进行收集，加入冻存保护剂后将细胞进行冻存，为工作细胞库细胞，此过程会产生噪声。

## （6）细胞制剂研发

根据临床需求，出库工作细胞库细胞进行复苏，进一步将工作细胞库细胞进行扩增培养后进行收集，为原液。将辅料与原液按一定顺序和体积比混匀，分装成细胞制品，应用于临床转化应用研究，此过程会产生有机废气、气溶胶、试验废液、实验器皿清洗废水、恒温水浴锅废水以及噪声。

## 二、细胞质量检测：

本项目将对细胞制品工作流程的关键点分别从微生物水平、细胞水平和分子水平进行质量控制，以保证研发质量。

## （1）微生物检测工作流程

①接种

先混匀样本，在无菌隔离器内分别取适量的样本加至微生物培养基中，此过程会产生试验废液、噪声。

## ②培养观察

将微生物培养基放置在生化培养箱中培养，每天观察结果，此过程会产生有机废气、气溶胶、试验废液以及噪声。

## ③高温灭菌废弃

培养结束后，收集微生物培养基，放入高压灭菌锅进行高压灭菌，灭菌后的样本按照医疗废物处理，此过程会产生废样本、试验废液、噪声。

## （2）分子检测工作流程

## ①检测样本前处理

根据检测项目，采用对应的方法对检测样本进行前处理，包括离心、染色、抗体孵育或核酸提取等前处理步骤，得到可上机检测的检测样本，此过程会产生试验废液、噪声。

## ②上机检测

混匀样本，对样本进行上机检测，此过程会产生试验废液、噪声。

## ③结果分析

仪器检测完成后，分析检测结果，计算出检测结果，并出具检测报告，此过程会产生试验废液、实验器皿清洗废水、恒温水浴锅废水和噪声。

## 1.1 废气污染源强分析

## ①有机废气

本项目的有机废气主要是在消毒过程中会使用乙醇（75%）以及冻存过程中会使用异丙醇挥发产生，挥发过程较短，且为不连续排放，以 NMHC 表征。本项目试剂存放在密闭的试剂瓶内，储存过程不挥发。异丙醇主要在种子细胞制备间使用，是细胞冻存盒里面需要添加的一种溶剂；乙醇在各区域的洁净区和实验区都会使用，主要是用来消毒的。项目乙醇（75%）年用量为 150L，密度为 0.79g/cm3，异丙醇年用量为 6L，密度为 0.785g/cm3，按照乙醇、异丙醇 100%挥发计算，则乙醇挥发产生有机废气的量约为 0.09t/a，异丙醇挥发产生有机废气的量约为0.0036t/a。

## ②气溶胶

本项目在细胞制备、培养过程中会产生气溶胶，气溶胶是由固体或液体小质点分散并悬浮在气体介质中形成的胶体分散体系，又称气体分散体系。本项目在细胞制备、培养过程中均可能产生气溶胶，产生量极少，本评价仅作定性分析。

本项目细胞制备、培养过程主要在生物安全柜内进行，生物安全柜与高效过滤器主要是由柜体内的高效滤网过滤进排气，并在柜体内产生向下气流的方式来避免感染性生物材料污染环境与感染实验操作人员以及实验操作材料间的交叉污染的箱型空气净化负压安全装置，生物安全柜及室内排风系统高效过滤器内配有高效过滤器，并进行定期更换，有效防止实验操作处理过程中某些含有危险性或未知性生物微粒发生气溶胶散逸，确保生物实验安全风险，不会对周边环境产生明显的不良影响。

## ③臭气浓度

实验过程中原辅材料会产生少量恶臭，主要污染因子为臭气浓度。恶臭与废气一同收集后经活性炭吸附处理后高空排放。项目恶臭产生量不大，经处理后可以达到《恶臭污染物排放标准》(GB14554-93) 表 1 和表2恶臭污染物排放限值，对周边环境和敏感点影响不大。

## 活性炭吸附装置：

本项目实验室排出的气体属于大风量、低浓度废气。综合比较分析，此类废气适宜采用吸附法在常温下进行处理。可作为净化异味及含经类化合物废气的吸附剂有活性炭、硅胶、分子筛等，其中应用最广泛、效果最好的为活性炭。因此，建设单位拟采用“活性炭吸附装置”。

活性炭吸附原理：在用多孔性固体物质处理流体混合物时，流体中的某一组分或某些组分可被吸引到固体表面并浓集其上，此现象称为吸附。活性炭是应用最早、用途较广的一种优良吸附剂。它是由各种含炭物质如煤、木材、石油焦、果核等炭化后，再用水蒸汽或化学药品进行活化处理，制成孔穴十分丰富的吸附剂，比表面积一般在 700～1500m2 /g 范围内，具有优异的吸附能力，故活性炭常常被用来吸附处理空气中的有机溶剂和恶臭物质。固体表面吸附了吸附质后，一部分被吸附的吸附质可从吸附表面脱离，此现象称为脱附。而当吸附剂进行一段时间的吸附后，由于表面吸附质的浓集，使其吸附能力明显下降而不能满足吸附净化的要求，此时可更换吸附剂，以恢复吸附剂的吸附能力。吸附器的压力降一般为 1000～1500Pa。

本项目细胞制剂研发、培养观察工序主要产生有机废气（以NMHC 表征）、气溶胶（颗粒物）和臭气浓度，废气经高效过滤器+活性炭吸附装置处理后，有机废气（以 NMHC 表征）有组织排放可以达到广东省地方标准《固定污染源挥发性有机物综合排放标准》（DB44/2367-2022）表1中TVOC 和非甲烷总烃的排放限值；气溶胶（颗粒物）可以达到广东省地方标准《大气污染物排放限值》（DB44/27-2001）中的颗粒物第二时段二级标准限值，臭气浓度可以达到《恶臭污染物排放标准》（GB14554-93） 中表2恶臭污染物排放标准值要求，对大气环境质量影响极小。

实验室内加强通风，场区内 VOCs 无组织排放能达到广东省《固定污染源挥发性有机物综合排放标准》（DB44/2367-2022）中排放限值无组织排放监控点浓度限值的要求；场界颗粒物能够达到广东省地方标准《大气污染物排放限值》（DB44/27-2001）颗粒物第二时段无组织排放监控浓度限值，场界臭气浓度能够达到《恶臭污染物排放标准》（GB14554-93） 中表1 中二级新改扩建限值。因此，项目的废气处理措施是可行的。

①尽量选择低噪声型设备，在高噪声设备上安装隔声罩、隔声垫，采用隔声、吸声、减震等措施；

②根据实验室实际情况和设备产生的噪声值，对实验室设备进行合理布局；

③加强设备管理，对实验设备定期检查维护，加强设备日常保养，及时淘汰后设备；加强员工操作的管理，合理安排实验时间，制定严格的装卸作业操作规程，避免不必要的撞击噪声；

④严格实验作业管理，合理安排实验时间，以尽量减小项目实验噪声对周边环境的影响。

采取上述治理措施后，经实验室墙壁及一定的距离削减作用，场界噪声可以达到《工业企业厂界环境噪声排放标准》（GB12348-2008）中的2类标准要求，可以将对最近敏感点的影响降到最低。

## （2）环境管理要求

①一般工业固体废物

对于一般工业固体废物的管理和贮存应做好以下工作：根据《一般工业固体废物贮存和填埋污染控制标准》（GB18599-2020）规定：采用库房、包装工具（罐、桶、包装袋等）贮存一般工业固体废物过程的污染控制，不适用本标准，其贮存过程应满足防渗漏、防雨淋、防扬尘等环境保护要求。

本项目本项目产生的废包装材料交由专业回收公司回收处理，产生量为0.5t/a，依托美和门诊部的一般固体废物间暂存，美和门诊部一般固体废物间占地面积20m2，贮存能力为16t，美和门诊部年产废包装材料约为 1t/a，美和门诊部的一般固体废物间有足够的储存余量接纳本项目产生的废包装材料，因此，本项目一般固体废物依托美和门诊部的一般固体废物间暂存是可行的。

## ②危险废物

危险废物从产生、收集、贮运、转运、处置等各个环节都可能因管理不善而进入环境，因此在各个环节中，抛落、渗漏、丢弃等不完善问题都可能存在，为了使各种危险废物能更好的达到合法合理处置的目的，本评价拟按照《危险废物贮存污染控制标准》（GB18597-2023）等国家相关法律，提出相应的治理措施，以进一步规范项目在收集、贮运、处置方式等操作过程。

## A、收集、贮存

根据上述分析，项目的危险废物主要为废活性炭、试验废液、等。因此，建设单位应根据废物特性设置符合《危险废物贮存污染控制标准》（GB18597-2023）要求的危险废物暂存场所，且在暂存场所上空设有防雨淋设施，地面采取防渗措施，危险废物收集后运输至美和门诊部的危险废物暂存间暂存。

美和门诊部危险废物暂存间占地面积30m2，贮存能力为24t，美和门诊部年产危险废物量约为 9t/a，本项目产生危险废物量约为 11.3t/a，美和门诊部危险废物暂存间有足够的储存余量接纳本项目产生的危险废物，因此，本项目危险废物依托美和门诊部的危险废物暂存间暂存是可行的。

## B、运输

对危险废物的运输要求安全可靠，要严格按照危险废物运输的管理规定进行危险废物运输，减少运输过程中的二次污染和可能造成的环境风险，运输车辆需有特殊标志。

## C、处置

建设单位拟将危险废物交由有危废处理资质的单位外运处理，根据《广东省危险废物产生单位危险废物规范管理工作实施方案》，企业须根据管理台账和今年生产计划，制订危险废物管理计划，并报当地环保部门备案。台账应如实记载产生危险废物的种类、数量、利用、贮存、处置、流向等信息，以此作为向当地环保部门申报危险废物管理计划的编制依据。

产生的危险废物实行分类收集后依托美和门诊部危险废物暂存间暂存，贮存时限一般不得超过一年，并设专人管理。盛装危险废物的容器和包装物以及产生、收集、贮存、运输、处置危险废物的场所，必须依法设置相应标识、警示标志和标签，标签上应注明贮存的废物类别、危害性以及开始贮存时间等内容。

企业必须严格执行危险废物转移计划报批和依法运行危险废物转移联单，并通过信息系统登记转移计划和电子转移联单。企业还需健全产生单位内部管理制度，包括落实危险废物产生信息公开制度，建立员工培训和固体废物管理员制度，完善危险废物相关档案管理制度；建立和完善突发危险废物环境应急预案，并报当地环保部门备案。

综上所述，本项目产生的固体废物按要求妥善处理后，对环境影响不明显。

正常工况下，由于本项目所在车间已进行混凝土地面硬化，本项目不会造成地下水及土壤污染。

## 6、生态

本项目用地范围内不含有生态环境保护目标，因此，本项目不会对周围生态环境造成不良影响。
