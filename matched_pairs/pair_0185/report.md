## 2、与产业政策相符性分析

本项目属于C2913橡胶零件制造，根据《产业结构调整指导目录（2024年本）》的规定，项目不属于目录所列的鼓励类、限制类、禁止（淘汰）类项目，属于允许类。根据《市场准入负面清单（2025年版）》（发改体改规〔2025〕466号），项目不属于其中的禁止准入类。

本项目所属类别及生产产品不属于广东省发展改革委关于印发《广东省“两高”项目管理目录（2022年版）》的通知（粤发改能源函〔2022〕1363号）的附件广东省“两高”项目管理目录中的行业类别或产品，符合相关规定。

5、本项目溶剂型胶粘剂不可替代分析

## （1）基材特性：

橡胶：表面能极低（疏水、惰性），难以润湿和黏附；高弹性模量（需要胶粘剂能匹配其形变）；耐高温。

铁配件:高表面能，但表面可能有油污、氧化物。热膨胀系数与硅胶差异大（需胶粘剂缓冲热应力）。

（2）溶剂型橡胶胶粘剂的核心优势：

优异的渗透性：溶剂具有低表面张力，能有效渗透进入橡胶（尤其是多孔、粗糙或含有微裂纹的表面）和金属表面的微观孔隙中。这种深度渗透能够清除微孔中的空气和水分，使胶粘剂与基材形成更紧密的“微观啮合”和更大的有效接触面积，从而产生强大的机械锚定作用。

优异的表面清洁与活化作用：溶剂可以溶解并带走橡胶表面的少量油脂、增塑剂、脱模剂残留以及金属表面的微量油污和氧化物。起到“在线清洁”的作用，为胶粘剂直接与纯净基材接触创造了条件。同时，部分溶剂能轻微溶胀橡胶表层，使其表面的分子链更活跃，提高了表面能，增强了化学键合的可能性。

优异的初粘性与定位能力：溶剂在涂刷后快速挥发，导致胶粘剂中的固体含量迅速增稠或形成黏膜。能够在较短时间内（如几分钟到十几分钟）产生足够的粘性，使橡胶件和铁件在压合前就能暂时固定位置，便于后续的装配和加压操作，这对于流水线作业和复杂形状部件尤为重要。

对多种橡胶的广谱适应性：通过调整溶剂的类型（如甲苯、二甲苯、酮类、酯类等）和胶粘剂的主体聚合物，可以匹配不同极性的橡胶。

固化速度快：粘合过程主要依赖溶剂挥发和物理干燥，无需复杂的加热或长时间等待化学固化。

形成的胶膜柔韧性好：溶剂型胶粘剂成膜后，其高分子链段通常能保持较好的运动能力。粘接层具有良好的柔韧性和动态疲劳性能，能够承受橡胶与金属之间因热胀冷缩、振动、弯曲等产生的应力，不易脆裂。

优异的耐候性与耐化学性：对水、湿气、油脂、多种清洁剂和弱酸碱有良好。

（3）潜在替代胶粘剂的局限性说明

## ①有机硅胶粘剂的局限性

对金属粘接力普遍较弱：有机硅对金属（即使经过处理）的粘接强度低，难以满足橡胶垫片对牢固粘接的要求（尤其是剥离力）。固化速度慢，影响生产效率。需要加热固化的设备型号增加能耗和工艺复杂性。

工艺性：可能需要更复杂的表面处理(如专用底涂剂)来提高金属粘接力，增加步骤和成本。

②高性能聚氨酯胶粘剂的局限性

耐湿热性风险：聚氨酯在长期湿热环境下可能发生水解降解，导致强度下降甚至失效。

耐高温性局限：通用聚氨酯的长期耐热上限通常较低，对于靠近热源或高温清洗的部件可能不足。

对橡胶粘接挑战：虽然强于有机硅对金属，但其对未经特殊处理的橡胶的粘接力不稳定可靠。

环保/工艺性：分双组分聚氨酯混合操作复杂，对湿度敏感，单组分湿固化型开放时间控制要求高。

③环氧树脂胶粘剂的局限性

极度刚性、缺乏弹性：这是致命缺点。无法缓冲橡胶与金属的热膨胀差异，应力集中极易导致橡胶从胶层边缘撕裂或整个脱粘，尤其是在冷热循环下。完全不适合需要柔韧性的橡胶-金属粘接。

对橡胶粘接困难：对低表面能硅胶的粘接力通常很差，需要强力表面处理。

④氰基丙烯酸酯胶（瞬干胶）的局限性

脆性大、耐冲击和剥离差：完全无法承受任何形变或热应力，极易开裂脱粘。耐温耐漫性差：长期耐热性低（通常<80℃），湿热环境下快速失效。

白化现象：可能影响外观。

对大面积/缝障填充不适用：适合小面积点粘。

⑤丙烯酸胶粘剂（反应型/压敏型）的局限性

柔韧性/弹性不足：多数丙烯酸胶偏硬，缓冲热应力能力不如溶剂型胶粘剂。

耐油脂性：部分丙烯酸胶耐油脂性较低。

对橡胶粘接：需要特殊配方和处理才能可靠粘接橡胶。

## （4）论证结论

基于对橡胶与金属粘接的特殊挑战（表面能差异、热膨胀系数差异大、需要柔韧性）以及橡胶垫片产品应用的严格要求（强度、耐热、耐湿热、耐化），本项目溶剂型胶粘剂凭借其优异的渗透性、优异的表面清洁与活化作用、优异的初粘性与定位能力、独特的柔韧性与弹性、固化速度快、良好的综合耐久性，在当前技术和市场条件下，对于贵公司生产橡胶垫片产品而言，具有显著的不可替代性。其他类型的胶粘剂（如有机硅、聚氨酯、环氧、丙烯酸、氰基丙烯酸酯）在关键性能指标（尤其是柔韧性缓冲热应力的能力）或综合性能平衡方面，无法完全满足要求，或者在成本、工艺适应性上存在明显劣势，因此不具备替代本项目溶剂型胶粘剂的可行性。

## 8、水平衡分析

## （1）冷却塔定期排水

本项目共设置有 1 台冷却塔，生产过程中需用自来水对密炼机、炼胶机、开炼机、硫化机、液体注射硫化机内部进行间接冷却，冷却水循环使用，定期补充因蒸发而损失的水分，并适当排放一定量的水以维持循环系统盐分的平衡。参考《工业循环冷却水处理设计规范》（GB50050-2017），蒸发水量和排污水量计算公式如下：

$$
\mathrm { Q _ { e } { = } k * \ \Delta t * \ \mathrm { Q _ { r } } }
$$

$$
\mathrm { Q _ { \mathrm { b } } \mathrm { = } \frac { \mathrm { Q _ { \mathrm { e } } } } { \mathrm { N - 1 } } \mathrm { - } Q _ { \mathrm { w } } }
$$

式中：Qe一蒸发水量 $\mathrm { ( m ^ { 3 } / h ) }$

Qb一排污水量 $\mathrm { ( m ^ { 3 } / h ) }$

k一蒸发损失系数 $( 1 / { } ^ { \circ } \mathrm { C } )$

∆t 一循环冷却水进塔温度差 $( ^ { \circ } \mathrm { C } )$ ，本项目进塔温度差约 $5 \mathrm { { } ^ { \circ } C } \mathrm { { } }$

Qr 一循环冷却水量 $\mathrm { ( m ^ { 3 } / h ) }$

N 一浓缩倍数，间冷开式系统的设计浓缩倍数不宜小于 5.0，且不应小于

## 3.0，本项目取 5.0；

Qw一风吹损失水量 $\mathrm { ( m ^ { 3 } / h ) }$

本项目冷却塔参照间接开式系统，进塔大气温度平均约 $3 0 \mathrm { { } ^ { \circ } C } .$ ，进塔温度差约 5℃，根据《工业循环冷却水处理设计规范》（GB/T50050-2017）表 5.0.6，冷水塔的蒸发损耗系数 k 取值 0.0015。本项目冷却塔位于室内，基本不存在风吹损失量，本项目忽略风吹损失量。本项目冷却塔使用时间为 8h/d，年工作日300天，根据建设单位提供资料，冷却塔的循环水量为5m3 /h，则总循环水量为12000m3 /a，蒸发水量为 90m3 /a，冷却塔排水量为 22.5m3 /a，新鲜水补充量为蒸发水量、排污水量之和，新鲜水用量为 112.5m3/a。

本项目冷却塔排水不需定期添加药剂，可作为清净下水排入市政雨水管网。

本项目总人数为10人，均不在厂内食宿。根据《用水定额 第3部分：生活》（DB 44/ T 1461.3-2021）中办公楼（无食堂和浴室）的生活用水定额（先进值），员工办公生活用水定额取10m3 /（人·a），则本项目生活用水量为100m3/a，排放系数取0.9，则生活污水产生量为90m3 /a，生活污水经三级化粪池处理后排至均安污水处理厂处理，尾水排至海洲水道。

本项目橡胶制品（橡胶密封垫圈、橡胶轴套、橡胶垫片）生产工艺流程简述如下：

投料：根据不同产品需求，将外购的橡胶、氧化锌、炭黑、钙粉、钙基润滑脂、滑石粉、软化剂、乙酰柠檬酸三丁酯按照对应的比例投加到密炼机中，该过程产生少量粉尘和噪声。

密炼：橡胶原料及对应的配料物料进入密炼机后，通过转子、上下顶栓等机械拌和作用产生复杂的流动方式和高剪切力，使各种原料完全、均匀地分散在胶体中。本项目密炼工序工作温度约 $1 6 0 { \sim } 1 8 0 ^ { \circ } \mathrm { C }$ ，需要通过循环水进行间接冷却，避免胶料自硫化。单批次工作时间约为 8min。该过程主要产生少量有机废气（非甲烷总烃）、恶臭气体、粉尘、间接冷却排水和噪声。

开炼：密炼后的橡胶进入开炼机中，另外加入促进剂进行开炼加工，开炼机的两个辊筒以不同的转速相对回转，胶料放到两辊筒间的上方，在摩擦力的作用下被辊筒带入辊距中。由于辊筒表面的旋转线速度不同，使胶料通过辊距时的速度不同而受到摩擦剪切作用和挤压作用，胶料反复通过辊距而被塑炼。单批次工作时间约为 8min。开炼工作温度约 130\~150℃，需要通过循环水进行间接冷却，避免胶料自硫化。该工序会产生少量非甲烷总烃气体、恶臭气体、粉尘、间接冷却排水和噪声。

硫化：开炼后的胶料进入硫化机中，同时加入硫化剂进行硫化加工，通过发生硫化反应生成具有弹性的橡胶制品，提高橡胶性能。单批次工作时间约为20min。本项目硫化温度约为 140\~180℃。需要配套冷却塔提供冷却水对设备进行间接冷却。其中生产橡胶垫片产品需要先在铁配件上涂上胶粘剂，再将铁配件放入硫化机中与橡胶一起进行硫化，该过程使铁配件牢固结合，硫化后得到完整的橡胶垫片产品（其余产品生产则不需添加胶粘剂）。

本工序会产生少量有机废气、恶臭气体、间接冷却排水、边角料和噪声。

修边：使用橡胶切胶机、修边橡胶脱离机等设备去除胶件多余的边角料。该过程产生少量废边角料、噪声。

包装：将成品通过人工进行打包，该过程产生少量废一般包装物。

成品：包装后得到的橡胶制品成品（橡胶密封垫圈、橡胶轴套、橡胶垫片）入库待售。

修边：使用橡胶切胶机、修边橡胶脱离机等设备去除胶件多余的边角料。该过程产生少量废边角料、噪声。

包装：将成品通过人工进行打包，该过程产生少量废一般包装物。

成品：包装后得到的成品入库待售。

## 3、原有项目污染物排放量

## （1）废气污染物

①挥发性有机物

原有项目审批较早，原有项目批准证未载明挥发性有机物的产排分析，现涉 VOCs 原辅材料产排污核算方法、产排污系数、收集方式及其收集效率、处理工艺及处理效率与原环评审批时均有所不同。现根据企业实际生产情况对VOCs 产排情况进行重新核算。

原项目产生有机废气的工序为炼胶、硫化工序，废气因子以非甲烷总烃表征。原项目审批阶段和实际情况基本一致，炼胶、硫化有机废气经集气罩收集后由 15m 高排气筒 1#排放。原有项目归真情况的有机废气产排源强分析见表

2-18。

根据表 2-18，原项目归真情况非甲烷总烃的排放浓度符合《橡胶制品工业污染物排放标准》（GB27632-2011）表 5 新建企业大气污染物排放限值及表 6现有和新建企业厂界无组织排放浓度限值。原项目于2016年12月15日委托广州中正环境监测服务有限公司对炼胶、硫化工序废气及厂界废气进行监测（检测报告编号：[中正]环监验（2016）第121516 号），根据监测结果，排气筒1#非甲烷总烃处理后有组织排放浓度为 5.38\~6.67mg/m³，无组织排放监测浓度为0.55\~1.12mg/m³，可达到《橡胶制品工业污染物排放标准》（GB27632-2011）表5 新建企业大气污染物排放限值及表 6 现有和新建企业厂界无组织排放浓度限值。

原项目审批阶段未设置大气污染物排放总量控制指标，因此验收阶段未根据检测结果核算总量，则本报告原有项目排放量取归真值为0.030t/a（见下文分析）。

## ②炼胶工序投料粉尘（颗粒物）

原项目炼胶工序的投料过程中会产生少量粉尘，污染因子为颗粒物。投料粉尘经集气罩收集后通过 15m排气筒1#排放。根据广州中正环境监测服务有限公司对佛山市顺德区均安镇天威橡塑有限公司的检测报告（报告编号：[中正]环监验（2016）第121516号）监测数据，颗粒物有组织监测浓度为8.39\~9.25mg/m³，无组织监测浓度为 0.082\~0.142mg/m³，原项目颗粒物排放满足《橡胶制品工业污染物排放标准》（GB27632-2011）表 5新建企业大气污染物排放限值及表 6 现有和新建企业厂界无组织排放浓度限值。

原项目运营期间生活污水来源于员工办公产生的生活污水，根据验收资料（见附件 9），生活污水排放量为 30m3 /a。主要污染因子为CODCr、BOD5、SS、氨氮等，生活污水经三级化粪池处理达到《城镇污水处理厂污染物排放标准》（GB18918-2002）二级标准后，排至附近内河涌。

## 1、水污染物排放总量控制指标

迁扩建前，原项目生活污水排放量为 $3 0 \mathrm { m } ^ { 3 } / \mathrm { a }$ ，经三级化粪池预处理后排至附近内河涌，原项目无水污染物排放总量控制指标。

迁扩建后，本项目生活污水排放量为 $9 0 \mathrm { m } ^ { 3 } / \mathrm { a }$ ，经三级化粪池预处理后通过市政污水管网引至均安污水处理厂处理，处理后的 $\mathrm { C O D } _ { \mathrm { C r } }$ 排放量为 0.004t/a、氨氮排放量为 0.0005t/a，根据《佛山市排污权有偿使用和交易管理办法》（佛府办〔2020〕19号），无水污染物排放总量控制指标。

## 2、大气污染物排放总量控制指标

根据原项目审批情况，迁扩建前，原项目无二氧化硫和氮氧化物的排放，且未设置挥发性有机物大气污染物总量控制指标。

迁扩建后，本项目无二氧化硫和氮氧化物的排放，无需分配二氧化硫和氮氧化物的总量控制指标。根据顺德区生态环境保护委员会办公室关于印发《顺德区重点行业挥发性有机物总量指标管理工作方案（2024 年修订）》的通知（顺环委办〔2024〕3 号）要求，待项目审批时由生态环境部门核定VOCs（含非甲烷总烃）总量来源，废气污染物总量控制指标为挥发性有机物 0.105t/a。根据原项目废气排放量核算结果，“归真总量”为0.030t/a，因此本项目新增挥发性有机物排放总量控制指标 0.075t/a。

## 3、废气治理设施可行性分析

本项目投料、密炼、开炼废气经炼胶车间整室负压收集，硫化（含涂胶）废气经集气罩+围挡收集后，一并通过布袋除尘器+活性炭吸附设施处理后由35m 排气筒DA001 排放。参考《排污许可证申请与核发技术规范 橡胶和塑料制品工业》（HJ 1122-2020），布袋除尘器属于颗粒物废气处理可行性技术，活性炭吸附设施属于有机废气处理的可行性技术。

活性炭吸附：当气体分子运动到固体表面时，由于气体分子与固体表面分子之间相互作用，使气体分子暂时停留在固体表面，形成气体分子在固体表面浓度增大，这种现象称为气体在固体表面上的吸附。被吸附物质称为吸附质，吸附吸附质的固体物质称为吸附剂。而活性炭吸附法是以活性炭作为吸附剂，把废气中有机物溶剂的蒸气吸附到固相表面进行吸附浓缩，从而达到净化废气的方法。活性炭吸附器是一种干式废气处理设备，可以处理多种不同废气，如苯类、酚类、醇类、醚类、酊类等有机废气和臭味。废气在风机的动力作用下，经过收集装置及管道进入主体治理设备——吸附器。吸附器内填充高效活性炭。活性炭的吸附能力在于它具有巨大的比表面积（高达 $6 0 0 { \sim } 1 5 0 0 \mathrm { m } ^ { 2 } / \mathrm { g } )$ ），以及其精细的多孔表面构造。废气经过活性炭时，其中的一种或几种组分浓集在固体表面，从而与其他组分分开，气体得到净化处理。该方法几乎适用于所有的气相污染物，一般是中低浓度的气相污染物，具有去除效率高等优点。根据《佛山市生态环境局关于加强活性炭吸附工艺规范化设计建设与运行管理的通知》（佛环函[2024]70 号）及相关要求，采用活性炭吸附技术的，应选择碘值不低于 800mg/g 的活性炭，并按设计要求足量添加、及时更换。

根据本项目生产特点，生产设施在开停炉（机）等非正常情况，项目不产生废气污染物，故不考虑此非正常情况下废气达标情况。保守估计因废气治理设施故障等原因可能造成部分工艺废气非正常排放，本项目处理设施稳定运行，需定期加强维护维修，一出现故障立即停机。

## 3、废水处置可行性分析

## （1）生活污水依托均安污水处理厂可行性分析

均安污水处理厂位于佛山市顺德区均安镇海洲水道旁边，由佛山市顺德区汇丰源环保工程管理有限公司投资建设。目前已建成一期、二期工程。均安污水处理厂主要纳污范围为新连片区、镇中心、环山西片、镇西片等。一期工程处理规模 2 万t/d。二期工程建成后，现状总处理规模为4万t/d。二期工程深化完善了整个均安污水收集管网，收集面积约18平方公里，主要接纳三华、仓门、新华、鹤峰和均安居委会等建成区的生活污水。本项目位于均安污水处理厂二期的服务范围，且已接通市政污水管网。

本项目生活污水产生量为0.3t/d，仅占均安污水处理厂处理能力（4万t/d）的 0.0008%，可接纳本项目污水量，因此项目生活污水经处理后排入市政管网引至均安污水处理厂集中处理，不会对均安污水处理厂造成较大的冲击。

均安污水处理厂现有污水处理工艺流程为污水经收集后采用粗格栅、细格栅、旋流沉淀、AAO生物反应、二级沉淀、高密度澄清、滤布过滤、紫外消毒等工艺。现状均安污水处理厂出水水质执行相应标准：尾水排放执行广东省地方标准《水污染物排放限值》（DB44/26-2001）第二时段一级标准及《城镇污水处理厂污染物排放标准》（GB18918-2002）一级A标准中的较严值后排入海洲水道。生活污水经三级化粪池处理后排入均安污水处理厂处理是可行的。

## 4、水环境影响分析结论

综上，本项目生活污水经三级化粪池预处理后，排放浓度可以达到均安污水处理厂进水水质要求，通过市政污水管网排入均安污水处理厂处理，尾水最终排入海洲水道；冷却塔定期排水作为清净下水，排至市政雨水管网。本项目生活污水排放满足相应的废水排放要求，依托均安污水处理厂具有环境可行性。本项目废水排放最终对地表水体造成的环境影响不大，其地表水环境影响是可接受的。

## （3）户外声传播衰减计算

户外声传播衰减包括几何发散（Adiv）、大气吸收（Aatm）、地面效应（Agr）、屏障屏蔽（Abar）、其他多方面效应（Amisc）引起的衰减。距声源点r 处的A声级按下式计算：

$$
L _ { \mathrm { p } } \mathrm { ( \bf ~ r ) } = L \mathrm { p } \mathrm { ( \bf ~ r 0 ) } - ( A \mathrm { d i v } + \mathrm { A a t m } + \mathrm { A g r } + \mathrm { A b a r } + \mathrm { A m i s c } )
$$

$\mathrm { r } _ { 0 ^ { - } }$ —参考位置距声源的距离，m；

各声源由于厂区内外其它建筑物的屏障衰减、空气吸收引起的衰减以及由于云雾、温度梯度、风及地面其它效应等引起的衰减量难确定其取值范围，且其引起的衰减量不大，保守起见，本评价预测计算中只考虑厂区内各声源至受声点（预测点）的距离衰减及车间墙体隔音量。

## ⑥废活性炭

本项目使用活性炭吸附装置处理有机废气会产生废活性炭。本项目采用颗粒炭，活性炭吸附比例取值 15%。根据前文工程分析，本项目DA001 需处理非甲烷总烃量为0.046t，理论需要0.307t 活性炭。根据佛山市生态环境局发布的《佛山市生态环境局关于加强活性炭吸附工艺规范化设计建设与运行管理的通知》（佛环函〔2024〕70号），活性炭吸附采用颗粒状活性炭箱的，空塔流速不超过 0.6m/s，停留时间保持 0.5-1s，碘吸附值>800mg/g、比表面积>850m2/g。本项目颗粒炭风量＜0.6m/s，进入活性炭吸附装置的颗粒物浓度小于 1mg/m3，达到吸附处理要求。根据下文计得废活性炭产生量为活性炭填装量+有机废气吸附量为 2.35t/a。废活性炭属于危险废物，废物类别为 HW49 类其他废物，代码为900-039-49。

本项目DA001炭箱所需抽屉数量计算如下：

1）所需过炭面积：

$$
\mathrm { S } \mathrm { = } \mathrm { Q } { \div } \mathrm { v } { \div } 3 6 0 0 \mathrm { = } 8 0 0 0 \mathrm { m } ^ { 3 } / \mathrm { h } { \div } 0 . 6 \mathrm { m } / \mathrm { s } { \div } 3 6 0 0 \mathrm { = } 3 . 7 \mathrm { m } ^ { 2 }
$$

2）炭箱抽屉个数（设计抽屉长×宽=500\*600mm）：

3.7m2÷0.5m÷0.6m≈12.4 个抽屉，取 16 个

3）炭箱装炭量：0.5×0.6×0.3×16=1.44m3

颗粒炭密度按 400kg/m3 计算，则装炭重量为 1.44×400=576kg

活性炭更换周期要求：

活性炭更换周期按照以下公式计算：

$$
{ \mathrm { ~ T ~ } } ( { \mathrm { ~ d ~ } } ) = { \mathrm { M } } ^ { * } { \mathrm { S } } / { \mathrm { C } } / 1 0 ^ { - 6 } / { \mathrm { Q } } / { \mathrm { t } }
$$

T— 更换周期，d；

M——活性炭的用量，kg；（本项目DA001 活性炭用量为576kg）；

S— 动态吸附量，%；（取值15%）

C——活性炭削减的 VOCs 浓度， $\mathrm { m g / m ^ { 3 } } ;$ ；（本项目活性炭吸附装置所吸附的 VOCs 浓度为 2.3875mg/m3）

Q— 风量，单位 m3 /h；（DA001 风量为 8000m3/h）

运行时间，单位 h/d。（运行时间8h/d）

## 4、固体废物环境管理要求

（1）员工生活垃圾定期交由环卫部门清理；

（2）要求项目在室内建设一个占地面积≥10m2的一般工业固废暂存间。建设单位需在暂存场所上空设有防雨淋设施，地面采取防渗措施；根据生产需要合理设置贮存量，尽量减少厂区内物料贮存量；一般固废暂存间需要设置明显环境保护图形标志。

根据《中华人民共和国固体废物污染环境防治法》要求，建设单位应做好以下防治措施：

①建设单位应当建立健全工业固体废物产生、收集、贮存、运输、利用、处置全过程的污染环境防治责任制度，建立工业固体废物管理台账，如实记录产生工业固体废物的种类、数量、流向、贮存、利用、处置等信息，实现工业固体废物可追溯、可查询，并采取防治工业固体废物污染环境的措施。

②禁止向生活垃圾收集设施中投放工业固体废物。

③建设单位委托他人运输、利用、处置工业固体废物的，应当对委托方的主体资格和技术能力进行核实，依法签订书面合同，在合同中约定污染防治要求。

④建设单位应当向所在地生态环境主管部门提供工业固体废物的种类、数量、流向、贮存、利用、处置等有关资料，以及减少工业固体废物产生、促进综合利用的具体措施，并执行排污许可管理制度的相关规定。

（3）要求项目在室内建设一个占地面积≥10m2的危废暂存间。建设单位须根据废物特性设置符合《危险废物贮存污染控制标准》（GB 18597-2023）的要求的危险废物暂存场所，且在暂存场所上空设有防雨淋设施，地面采取防渗措施，危险废物收集后分别临时贮存于废物塑料桶内；根据生产需要合理设置贮存量，尽量减少厂区内的物料贮存量；严禁将危险废物混入生活垃圾；堆放危险废物的地方要有明显的标志，堆放点要防雨、防渗、防漏，按要求进行包装

贮存。

针对危险废物提出环境管理要求如下：

①设置独立的危险废物暂存间并有专人负责管理，危险废物暂存间应做到防风、防雨、防渗漏，门口处设置围堰，内部地面和墙裙做耐腐蚀硬化处理。

②危险废物应采取分类收集，按类别放入相应的容器内，禁止生活垃圾、一般固体废物与危险废物混放，不相容的危险废物分开存放并设有隔离间隔断。

③在收集、运输、贮存危险废物的设施、场所设置规范的警示标志、标识、标牌。贮存点应及时清运贮存的危险废物，实时贮存量不应超过3吨。

④制定危险废物管理计划，清晰描述危险废物的产生环节、种类、危害特性、产生量、利用处置方式等。

⑤按要求如实申报登记危险废物的种类、产生量、贮存、处置等有关情况。

⑥建设单位必须严格执行危险废物转移计划报批和依法运行危险废物转移联单，并通过信息系统登记转移计划和电子转移联单。企业还需健全产生单位内部管理制度，包括落实危险废物产生信息公开制度，建立员工培训和固体废物管理员制度，完善危险废物相关档案管理制度；建立和完善突发危险废物环境应急预案，并报当地环保部门备案。

⑦建设单位须根据管理台账和近年生产计划，制订危险废物管理计划，并报当地环保部门备案。台账应如实记载产生危险废物的种类、数量、利用、贮存、处置、流向等信息，以此作为向当地环保部门申报危险废物管理计划的编制依据。

## 五、地下水和土壤

本项目属于污染影响型，主要影响时段为运营期。本项目的生活污水经三级化粪池预处理后通过市政污水管网引至均安污水处理厂进一步处理；冷却塔排水作为清净下水排入市政雨水管网；危险废物分类暂存于危废暂存间内，危废暂存间按照《危险废物贮存污染控制标准》（GB18597-2023）要求落实好“防雨、防渗、防泄漏”等措施，定期交由有处理资质的单位接收处置，使用的厂房和周边环境地面已做好水泥面硬化防渗措施，对地下水环境和土壤环境不存在污染途径。根据《关于发布<有毒有害大气污染物名录（2018年）>的公告》（公告 2019 年第 4 号）、《土壤环境建设用地土壤污染风险管控标准（试行）》（GB36600-2018）和《土壤环境农用地土壤污染风险管控标准（试行）》（GB15618-2018），本项目产生的废气污染物为颗粒物、有机废气和恶臭气体，不会构成土壤污染。本项目不存在地下水、土壤污染途径，因此，本项目不开展地下水、土壤环境影响评价。

## 六、结论

<table><tr><td>本项目建设合法且符合佛山市和国家的相关产业政策。本项目产生的污染物 （源），可以通过污染防治措施进行削减，达到排放标准的要求，对环境可能产生不 良的影响较小。只要加强环境管理，严格执行“三同时&quot;制度，落实好相关的环境保护 和治理措施，确保污染物达标排放，则本项目在正常运营状况下不会对周边环境产生 大的污染影响。从环保角度分析，本项目的建设是合理可行的。</td><td></td></tr></table>
