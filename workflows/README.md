## 9类审核分类覆盖

```
[0] 材料完整性与一致性     ❌ 无独立工作流
[1] 项目建设内容与工程分析 ✅ 1-国民经济, 2-投资, 5-建设内容
[2] 产污环节与污染源核算   ✅ 9, 10, 17
[3] 污染防治措施可行性     ✅ 18, 19
[4] 环境影响预测与评价结论 ✅ 6-环境质量数据, 7-执行标准
[5] 环境风险与应急措施     ❌ 无独立工作流
[6] 法规/标准/导则符合性   ✅ 4-三线一单, 8-排放标准
[7] 监测计划/总量控制      ❌ 无独立工作流
[8] 图件/附件/格式        ❌ 无独立工作流
```

## 导入 Dify

1. 打开 Dify Studio
2. 创建应用 → 导入 DSL 文件
3. 选择对应的 `.yml` 文件
4. 配置模型供应商密钥后即可使用

## 注意

工作流使用 Dify DSL v0.6.0 格式，兼容 Dify 0.6.x 以上版本。
某些工作流引用了特定的知识库 dataset_id，需在导入后重新关联对应的知识库。
